# ORM

[`github.com/vuka-lang/orm`](https://github.com/vuka-lang/orm) is a
Django-style ORM for Go and Vuka: a model is a plain struct, its manager a
package-level value, its queries lazy, immutable QuerySets. Each field's
column — name, type, default, checks — is declared in one attribute beside
it, and custom value types and attributes plug in the same way. Relations and
prefetching, aggregates, `Case`/`When`, subqueries, text and vector search,
raw SQL, several databases with replicas and routing, mirrored writes, and Go
migration files written by `makemigrations`.

Connections are plain `database/sql`.

**Go:** an ORM names fields as strings — `Where("author_name = ?", x)`,
`Order("-views")` — that the compiler never checks, and a query for one model
takes conditions written for another.

**Vuka adds** models declared with [field attributes](/features/fields) and
queries written with [field references](/features/fields#field-references)<span class="go-only">;
in Go, the same attributes go in a `Schema` method and the references are
generated</span>:

::: vuka
```vuka
type Post struct {
	orm.Base @orm.Meta{Table: "posts", Ordering: []string{"-published"}}
	ID        int64             @orm.PK{Column: "post_id"}
	Title     string            @orm.Char{Max: 200, Trim: true}
	Slug      string            @orm.Slug{Unique: true}
	Status    string            @orm.Char{Max: 20, Default: "draft", Choices: []string{"draft", "published"}}
	Author    orm.FK[User]      @orm.Rel{OnDelete: orm.Cascade, Related: "posts"}
	Tags      orm.M2M[Tag]
	Published Option[time.Time] @orm.Datetime{Index: true}
	Views     int               @orm.Int{Default: 0, Min: 0}
	Created   time.Time         @orm.Datetime{DefaultNow: true}
}

posts := Post.Objects.Filter(Post.Title.Contains("Go"), Post.Author.Name.Eq("ada")).
	OrderBy(Post.Views.Desc()).All(ctx)?                     // []Post

p, err := Post.Objects.Get(ctx, Post.Slug.Eq(slug))   // orm.ErrNotFound when there is none
```
:::

::: go
```go
type Post struct {
	orm.Model[Post]
	ID        int64
	Title     string
	Slug      string
	Status    string
	Author    orm.FK[User]
	Tags      orm.M2M[Tag]
	Published vuka.Option[time.Time]
	Views     int
	Created   time.Time
}

func (p *Post) Schema(s *orm.Schema) {
	s.Model(orm.Meta{Table: "posts", Ordering: []string{"-published"}})
	s.Field(&p.ID, orm.PK{Column: "post_id"})
	s.Field(&p.Title, orm.Char{Max: 200, Trim: true})
	s.Field(&p.Slug, orm.Slug{Unique: true})
	s.Field(&p.Status, orm.Char{Max: 20, Default: "draft", Choices: []string{"draft", "published"}})
	s.Field(&p.Author, orm.Rel{OnDelete: orm.Cascade, Related: "posts"})
	s.Field(&p.Published, orm.Datetime{Index: true})
	s.Field(&p.Views, orm.Int{Default: 0, Min: 0})
	s.Field(&p.Created, orm.Datetime{DefaultNow: true})
}

var Posts = orm.For[Post]()

f := PostFields // typed fields, generated by ormgen
posts, err := Posts.Filter(f.Title.Contains("Go"), f.Author.Name.Eq("ada")).
	OrderBy(f.Views.Desc()).All(ctx) // []Post
if err != nil {
	return err
}

p, err := Posts.Get(ctx, f.Slug.Eq(slug))
switch {
case errors.Is(err, orm.NotFound):
	notFound()
case err != nil:
	return err
default:
	show(p)
}
```
:::

A value outside a field's `Choices`, bounds or length is refused on every
write with an [`orm.Invalid`](/orm/errors) naming the field, before the
database sees it.
<span class="vuka-only">A misspelt field is a compile error, and `Contains` on a
number doesn't compile either: `Post.Title` is the model's typed field.
Terminals return `(T, error)`, so `?` takes them.</span><span class="go-only">A model's `Schema` names each
field by its address, so a rename is checked by the compiler; `PostFields`,
written by `ormgen` (`//go:generate go run github.com/vuka-lang/orm/cmd/ormgen`),
gives typed lookups, and without it every query takes `orm.Q{"title__contains":
"Go"}` strings. Terminals return `(T, error)`.</span>
Everything is plain Go underneath — the attributes are the model's
`Schema` method — so Go and Vuka packages share models and databases.

## Install

```sh
go get github.com/vuka-lang/orm
```

It needs Go 1.27 (it uses generic methods: `q.Values[R](…)`).

## Drivers

Drivers are opt-in blank imports, `database/sql` style; the `orm` package
links none:

| Import | Driver | Dialect |
|---|---|---|
| `github.com/vuka-lang/orm/postgres` | pgx | `postgres` |
| `github.com/vuka-lang/orm/mysql` | go-sql-driver/mysql | `mysql` |
| `github.com/vuka-lang/orm/sqlite` | pure-Go `glebarez/go-sqlite` | `sqlite` |

## A first program

::: vuka
```vuka
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/vuka-lang/orm"
	_ "github.com/vuka-lang/orm/sqlite"
)

type User struct {
	orm.Base
	ID    int64
	Name  string @orm.Char{Max: 100, Unique: true}
	Email string @orm.Char{Max: 200}
}

func run(ctx context.Context) error {
	db := orm.ConnectURL("sqlite:app.db")?
	orm.AddDatabase("main", db, orm.AsDefault())
	orm.CreateTables(ctx, orm.Objects[User]())?    // a real program runs migrations

	ada := User{Name: "ada", Email: "ada@example.com"}
	ada.Save(ctx)?

	users := User.Objects.Filter(User.Name.StartsWith("a")).OrderBy(User.Name.Asc()).All(ctx)?
	fmt.Println(len(users), "users")
	return nil
}

func main() {
	if err := run(context.Background()); err != nil {
		log.Fatal(err)
	}
}
```
:::

::: go
```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/vuka-lang/orm"
	_ "github.com/vuka-lang/orm/sqlite"
)

//go:generate go run github.com/vuka-lang/orm/cmd/ormgen

type User struct {
	orm.Model[User]
	ID    int64
	Name  string
	Email string
}

func (u *User) Schema(s *orm.Schema) {
	s.Field(&u.Name, orm.Char{Max: 100, Unique: true})
	s.Field(&u.Email, orm.Char{Max: 200})
}

var Users = orm.For[User]()

func run(ctx context.Context) error {
	db, err := orm.ConnectURL("sqlite:app.db")
	if err != nil {
		return err
	}
	orm.AddDatabase("main", db, orm.AsDefault())
	if err := orm.CreateTables(ctx, Users); err != nil { // a real program runs migrations
		return err
	}

	ada := User{Name: "ada", Email: "ada@example.com"}
	if err := Users.Create(ctx, &ada); err != nil {
		return err
	}

	users, err := Users.Filter(UserFields.Name.StartsWith("a")).OrderBy(UserFields.Name.Asc()).All(ctx)
	if err != nil {
		return err
	}
	fmt.Println(len(users), "users")
	return nil
}

func main() {
	if err := run(context.Background()); err != nil {
		log.Fatal(err)
	}
}
```
:::

`orm.ConnectURL` picks the dialect from the URL — `postgres://…`,
`mysql://user:pass@tcp(host)/db`, `sqlite:file.db`; `orm.Connect(dialect,
dsn)` and `orm.Open(sqlDB, dialect)` take it apart. A program with several
databases, replicas and a supervised pool declares them instead: see
[Databases](/orm/databases).
