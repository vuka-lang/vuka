# E0347: A deferred method of the wrong shape

A deferred method runs on its own, after the page is sent: it gets the
request's context, canceled when the visitor goes away, and returns its
result and an error, which its part shows as its error fallback. So it
takes one `context.Context` and returns `(T, error)`.

Reported by the compiler, by [`vukavet`](/tools/vukavet) and at start-up.
See [Parts of a Page](/web/parts).

## Wrong

```vuka
@ui.Defer
func (p *Index) Count() int { return 3 }
```

## Right

```vuka
@ui.Defer
func (p *Index) Count(ctx context.Context) (int, error) { return 3, nil }
```
