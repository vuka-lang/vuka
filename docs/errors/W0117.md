# W0117: A ui.Derived field: derived values are expressions

With one state (the `ui.State`/`ui.Assign` merge), derived values are
expressions: a template expression over states is browser-evaluated and
tracked already, and a Go method over synced states is the server form. A
`ui.Derived` field with `@ui.From` keeps working, but new code writes the
expression where it is read.

## Wrong

```html
<script lang="go">
package shop

type Cart struct {
	count ui.State[int]
	price ui.State[int]
	total ui.Derived[int] @ui.From(count * price)
}
</script>

<p>{total}</p>
```

## Right

```html
<script lang="go">
package shop

type Cart struct {
	count ui.State[int]
	price ui.State[int]
}
</script>

<p>{count * price}</p>
```
