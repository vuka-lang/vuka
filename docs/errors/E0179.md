# E0179: A @ui.Keep or @ui.Shared the browser can't keep

[`@ui.Keep("theme")`](/ui/state#keep) stores a `ui.State` in the
browser's localStorage, and `@ui.Shared` sends its writes to the page's
other tabs; both carry the value as JSON. Reported by the compiler:

- the attribute on a field that isn't a `ui.State` (a `ui.Derived`
  follows its states: keep those);
- a value JSON can't hold: a func, a chan, a complex number, at any depth;
- a `@ui.Keep` whose key isn't a constant string, or is empty;
- two fields kept under one key, which would share one stored value.

## Wrong

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Prefs struct {
	theme ui.State[string] @ui.Keep("prefs")
	dense ui.State[bool]   @ui.Keep("prefs")
}
</script>

<main data-theme={theme} class:dense={dense}></main>
```

## Right

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Prefs struct {
	theme ui.State[string] @ui.Keep("theme")
	dense ui.State[bool]   @ui.Keep("dense")
}
</script>

<main data-theme={theme} class:dense={dense}></main>
```
