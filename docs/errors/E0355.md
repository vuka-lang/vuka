# E0355: A stream row isn't one keyed element

The browser matches a [stream](/web/streams)'s rows by their keys — an
insert of a key it holds morphs that row, a delete removes it — so each row
is one element with a `key`, the record's identity. Several elements, text
or a fragment per row have nothing to match, and neither has an element
without a key. Reported by the compiler, `vuka vet` and the editor, and when
a Go component's row renders (`Stream.List`).

## Wrong

```html
<ul>
  for _, m := range messages.Rows() {
    <li>{m.Text}</li>
  }
</ul>
```

## Right

```html
<ul>
  for _, m := range messages.Rows() {
    <li key={m.ID}>{m.Text}</li>
  }
</ul>
```
