# E0126: Bad vuka.File

A `vuka.File` set to a string literal names a file vuka embeds: it must
exist, be a file (not a directory), and be in the package's directory or
below it, named relative to it.

## Wrong

```vuka
@Template("/etc/passwd")
func page() {}
```

## Right

```vuka
@Template("templates/page.html")
func page() {}
```
