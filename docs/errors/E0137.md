# E0137: A forward marker that marks no one element

What a caller writes on a component's tag that no prop takes — its
`class`, HTML, ARIA and data attributes, DOM events, `bind:value`, `ref` —
goes to the component's forward element: the markup's one top-level
element, or the element carrying a bare `forward` attribute
([Fallthrough](/ui/components#fallthrough)). The marker is an error when it
can't name one element:

- two elements are marked;
- the marked element is inside a `for` loop, so it renders once per item;
- it sits in markup inside a Go expression or a markup func;
- it has a value (`forward="input"`): it is written bare;
- the component takes its tag's attributes otherwise: it declares `Attrs`
  (which takes everything, wherever its markup spreads it), its struct is
  declared in a `.go` file beside the template, or the JSX target has no
  `ui.Fallthrough`.

## Wrong

```html
<script lang="go">
package components

type Field struct {
	Label string
}
</script>

<label forward>{Label} <input class="h-10 rounded-md border" forward/></label>
```

## Right

```html
<script lang="go">
package components

type Field struct {
	Label string
}
</script>

<label>{Label} <input class="h-10 rounded-md border" forward/></label>
```
