# E0803: Two declarations take one GraphQL name

Every name of a schema names one thing: one type per name, one field per
name in a type, one operation per name in Query and in Mutation. Names
come from Go — a type's name, a field's or method's in lower camel case, a
function's — so two Go declarations can arrive at one: `User` types of two
packages, a field `URL` and a method `Url`, two packages' `Pets`. The
compiler reports what it sees in a package; the app's build reports names
that meet across packages. The message names both declarations.

## Wrong

```vuka
// admin/users.vuka
@graphql.Query
func Users(ctx context.Context, store *Store) ([]User, error) { … }

// shop/users.vuka
@graphql.Query
func Users(ctx context.Context, store *Store) ([]Customer, error) { … }
```

## Right

```vuka
// shop/users.vuka
@graphql.Query("customers")
func Users(ctx context.Context, store *Store) ([]Customer, error) { … }
```

See [Naming](/web/graphql#naming).
