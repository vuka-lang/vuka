# E0161: ui.FormOf names a field the model lacks

`ui.FormOf[T]("Name", "Email")` is a form editing the fields of `T` it
names: its list is the form's allow-list, the only fields a submit binds.
The names are Go field names, a nested one with dots (`"Address.City"`),
written as strings, so Go's own type-check can't see a misspelt one; the
compiler checks each against `T` and says which isn't a field, with the
one it most likely meant. A form naming no field doesn't render either.

## Wrong

```go
// models.User declares ID, Name, Email and Address.
e.Form = ui.FormOf[models.User]("Name", "Emial")
```

## Right

```go
e.Form = ui.FormOf[models.User]("Name", "Email")
```
