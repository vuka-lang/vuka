# E0195: A widget whose Value or Choices don't fit its field

A widget — a component whose props have a `Model ui.FieldRef`, given
`model={Form.X}` — has the props it declares filled by the form, by name and
type: `Value` with the field's value, `Choices` with the field's choices,
each with its row. A `Value` of another type than the field's (an
`Option`'s value aside), or a `Choices` whose `Row` isn't the type of the
field's rows (an `orm.FK[Category]`'s are `Category`), could never be
filled.

## Wrong

```vuka
type CategoryPicker struct {
    widget.Props
    Value   string
    Choices []widget.Choice[Product]
}

<CategoryPicker model={Form.Category}/> // Category is an orm.FK[Category]
```

## Right

```vuka
type CategoryPicker struct {
    widget.Props
    Value   orm.FK[Category]
    Choices []widget.Choice[Category]
}

<CategoryPicker model={Form.Category}/>
```

A widget for any field declares `Choices []widget.Choice[any]` and no
`Value`, as the built-in ones do.
