# E0719: A page's struct is declared nowhere

A page under `pages/` is a struct and its markup. A `.vuka.html` file whose
markup has no struct above it, and no struct of its name declared beside
it, renders nothing vuka can route: in vuka 1 the folder's `routes_gen.go`
declared one, which vuka no longer writes. Reported at the file.

## Wrong

```html
<!-- pages/about.vuka.html -->
package pages

<h1>About</h1>
```

## Right

```html
<!-- pages/about.vuka.html -->
package pages

type About struct{}
<h1>About</h1>
```
