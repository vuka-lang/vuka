# W0114: A read naming a method that writes

`ui.Read()` makes a [push](/ui/js#push-reads) an HTTP GET. A GET carries no
CSRF token, and with `ui.Cache(d)` the browser may answer it without asking
the server, so the write may not happen at all. The compiler warns when the
method's own body calls the ORM's `Save`, `Create` or `Delete`; it doesn't
look inside the functions the method calls. Reported by the compiler:
`vuka vet`, `vuka build` and the editor show it.

## Wrong

```html
<button onClick={ui.JS.Push(Publish, ui.Value(post.ID), ui.Read()).Into("#status")}>Publish</button>
```

## Right

```html
<button onClick={ui.JS.Push(Publish, ui.Value(post.ID)).Into("#status")}>Publish</button>
```
