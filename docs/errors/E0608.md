# E0608: TypeScript 7 can't build Vue islands

Vue's compiler resolves `defineProps<T>()` of an imported type with
TypeScript's JavaScript API, which TypeScript 7 no longer has, so the Vue
island build fails. Pin TypeScript 6 in the frontend.

## Wrong

```json
// package.json
"devDependencies": { "typescript": "^7.0.0" }
```

## Right

```json
// package.json
"devDependencies": { "typescript": "~6.0.3" }
```
