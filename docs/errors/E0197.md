# E0197: Markup in a func literal that is Go

A func literal takes markup for its body in two places: bound by a
template statement, `row := func(o Order) { … }`, and set on a component's
prop whose type is a func returning `ui.Node`, `row={func(o Order) { … }}`.
Anywhere else — a hole, an event attribute, an element's attribute, a prop
of any other type — the literal is Go, and its body Go statements, so
markup there is this error; so is a literal writing a result other than
`ui.Node`, `func(o Order) string { <li/> }`, wherever it is. See [Markup Funcs](/ui/templates#markup-funcs).

Bind the func on a line of its own and use its name where the literal was,
or declare the prop as a func returning `ui.Node`.

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

type Order struct{ Number string }

type Orders struct{ Open []Order }
</script>

<ul>
  for _, o := range Open {
    {func(o Order) { <li>{o.Number}</li> }}
  }
</ul>
```

## Right

```html
<script lang="go">
package pages

type Order struct{ Number string }

type Orders struct{ Open []Order }
</script>

row := func(o Order) { <li>{o.Number}</li> }

<ul>
  for _, o := range Open {
    {row(o)}
  }
</ul>
```
