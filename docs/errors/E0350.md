# E0350: A deferred call in no element

A deferred method's part is the nearest element around its call. A call
at the top of the markup, outside every element, has no element to be its
part. Put it inside one: the element is what the page shows empty, or as
the fallback, until the method returns.

Reported by the compiler. See [Parts of a Page](/web/parts#what-a-part-is).

## Wrong

```html
<h1>Applications</h1>
{Stats(ctx)} open
```

## Right

```html
<h1>Applications</h1>
<p>{Stats(ctx)} open</p>
```
