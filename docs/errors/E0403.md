# E0403: A handler isn't a function

A route registered from Go (`app.Get(path, h)`) takes a function, of any
shape a decorated handler may have. Reported at boot.

## Wrong

```go
app.Get("/pets", petStore)
```

## Right

```go
app.Get("/pets", petStore.List)
```
