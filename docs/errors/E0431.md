# E0431: A TokenOnly prefix that is not a path

`web.TokenOnly(prefix)` declares the routes under a path prefix a token
API: their cookies are ignored and the cross-origin check is off there.
The prefix must be a path, starting with `/`, without a query.

See [CORS and Token APIs](/web/cross-origin#token-only).

Reported when the app is built.

## Wrong

```go
web.TokenOnly("api")
```

## Right

```go
web.TokenOnly("/api/")
```
