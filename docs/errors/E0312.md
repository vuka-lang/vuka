# E0312: Two islands share a name

An island's name is its Go type's name, and the page finds its component by
it, so two `@ui.Island` types in the module can't share one, even in
different packages.

## Wrong

```vuka
// modules/sales/chart.vuka
@ui.Island
type Chart struct{ … }

// modules/stock/chart.vuka
@ui.Island
type Chart struct{ … }
```

## Right

```vuka
@ui.Island
type SalesChart struct{ … }

@ui.Island
type StockChart struct{ … }
```
