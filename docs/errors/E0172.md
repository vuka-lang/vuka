# E0172: An event calling a method the shape lacks

A call in an `on…` attribute names one of the shape's exported methods,
which the event [pushes](/ui/events#calling-a-method) when it fires. The
name it calls is no method of the shape, nor anything else in scope. The
message names the closest method, or lists them.

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Orders struct {
	ui.Live
	status string
}

func (p *Orders) Choose(s string) { p.status = s }
</script>

<select onChange={Chose(this.value)}>…</select>
```

## Right

```html
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Orders struct {
	ui.Live
	status string
}

func (p *Orders) Choose(s string) { p.status = s }
</script>

<select onChange={Choose(this.value)}>…</select>
```
