# E0005: A dependency doesn't compile

A package this file imports doesn't compile, or couldn't be loaded, so the
file can't be checked. The first report says why; later ones point back at
it. Fix that package (or the import path) and this error goes away.

## Wrong

```vuka
import "example.com/app/billing" // billing has its own compile error
```

## Right

```vuka
import "example.com/app/billing" // once billing compiles
```
