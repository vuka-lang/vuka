# E0005: A dependency doesn't compile

A package this file imports doesn't compile, or couldn't be loaded, so the
file can't be checked. The editor shows it at the import, naming the
package's first error at its source; `vuka build` and `vuka run` show that
package's own errors instead, and count the files that fail because of it
in one line (`-v` lists them). Fix that package (or the import path) and
this error goes away.

## Wrong

```vuka
import "example.com/app/billing" // billing has its own compile error
```

## Right

```vuka
import "example.com/app/billing" // once billing compiles
```
