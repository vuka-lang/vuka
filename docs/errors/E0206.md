# E0206: Bad field attribute

A field attribute is a value (`@Char{Max: 200}`) written after its field,
after the struct tag, on the field's line, on a field of a package-level,
non-generic struct type.

## Wrong

```vuka
type Post struct {
	Title string @Char{Max: 200} `json:"title"`
	@Char{}
	Body string
}
```

## Right

```vuka
type Post struct {
	Title string `json:"title"` @Char{Max: 200}
	Body  string @Char{}
}
```
