# E0162: A call in markup is short of an argument

A call in markup gets one argument it doesn't write: the render's `ctx`,
for a function taking a `context.Context` first (see
[The Render's Context](/ui/templates#implicit-ctx)). Nothing else is
filled in. A call still short of an argument names what is missing.

Markup has no services to pass: a `*CategoryService`, a store, a client is
the page's, taken by its constructor (`NewIndex`, from the container) and
kept in a field the markup reads.

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

import (
	"context"

	"example.com/app/settings"
)

type Index struct{}

func (p *Index) GetCategories(ctx context.Context, svc *settings.CategoryService) ([]settings.Category, error) {
	return svc.List(ctx)
}
</script>

<p>{len(GetCategories())} categories</p>
```

## Right

```html
<script lang="go">
package pages

import (
	"context"

	"example.com/app/settings"
)

type Index struct {
	categories *settings.CategoryService
}

func NewIndex(categories *settings.CategoryService) *Index {
	return &Index{categories: categories}
}

func (p *Index) GetCategories(ctx context.Context) ([]settings.Category, error) {
	return p.categories.List(ctx)
}
</script>

<p>{len(GetCategories())} categories</p>
```
