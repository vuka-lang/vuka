# E0361: A viewport handler that doesn't take the edge row's key

A stream container's `onViewportTop` and `onViewportBottom` send one value:
the key of the row at that edge, as the row's `key` attribute renders it.
Their handler takes it as the type of the rows' key — parsed, as an event's
value is — or as its text, a `string`; or it takes no value. Beside it a
handler may take a `context.Context` and what the app injects, and returns
nothing or an error. A parameter of another type, a form struct (the event
sends no fields), a second value or another result can't be filled or
read. Reported by the compiler, `vuka vet` and the editor.

## Wrong

```go
// the rows are <li key={m.ID}>, an int64
func (c *Thread) Newer(ctx context.Context, last int) (int, error) { … }
```

## Right

```go
func (c *Thread) Newer(ctx context.Context, last int64) error {
    msgs, err := c.store.After(ctx, c.ID, last, 50)
    c.messages.Insert(msgs...)
    return err
}
```
