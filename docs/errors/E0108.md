# E0108: No such ref or attribute value

A JS command names an element by `ref` (`ui.Ref("menu")`), or an attribute
value (`ui.GetAttr("type", "email")`), that the component's markup doesn't
have. The message lists what there is, or suggests the nearest name.

## Wrong

```vuka
func Menu() ui.Node {
	return <nav>
		<ul ref="menu">…</ul>
		<button onClick={ui.JS.Toggle(ui.Ref("mnu"))}>Menu</button>
	</nav>
}
```

## Right

```vuka
func Menu() ui.Node {
	return <nav>
		<ul ref="menu">…</ul>
		<button onClick={ui.JS.Toggle(ui.Ref("menu"))}>Menu</button>
	</nav>
}
```
