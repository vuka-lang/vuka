# E0305: The JSX target can't import islands

Importing a component file needs a JSX target with `RegisterIsland`
(github.com/vuka-lang/ui v0.25 and later). The target the file renders with
is older.

## Wrong

```text
// go.mod
require github.com/vuka-lang/ui v0.20.0
```

## Right

```text
// go.mod
require github.com/vuka-lang/ui v0.30.0
```
