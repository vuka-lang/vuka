# E0169: A struct needing a live connection without ui.Live

Embedding `ui.Live` is the only way for a struct to be live. A decorated hook,
or an exported method its markup sends as an event, needs a live connection, so
the struct must embed it. `vuka fix explicit-live` adds it.

## Wrong

```html
<script lang="go">
type Counter struct{ n int }

func (c *Counter) Inc() { c.n++ }
</script>

<button onClick={Inc}>{n}</button>
```

## Right

```html
<script lang="go">
type Counter struct {
	ui.Live
	n int
}

func (c *Counter) Inc() { c.n++ }
</script>

<button onClick={Inc}>{n}</button>
```

A struct form's handler is the exception: `<ui.Form for={Form} onSubmit={Save}/>`
posts over HTTP on a page that isn't live, so it doesn't need `ui.Live`, whether
its name is exported or not. See
[Forms on Pages That Aren't Live](/ui/forms#http).
