# E0303: Can't read an island component

The component file an import names couldn't be read: it doesn't exist at
that path, or isn't readable. The diagnostic includes the written import
and its resolved file. `./` and `../` paths are relative to the importing
shape; `@/` paths are relative to the main module's `go.mod` directory.

An `@/` import also produces E0303 when the main module root is unknown,
or the path escapes it (`@/../Week.vue`). Compile within a module and keep
the component under its root.

## Wrong

```vuka
import Week "./islands/week.vue"   // the file is Week.vue
```

## Right

```vuka
import Week "./islands/Week.vue"
```
