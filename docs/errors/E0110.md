# E0110: Misplaced ?

`f()?` returns early with the error (or the empty Option) and is otherwise
the value. It goes anywhere an expression does — a statement, an `if`,
`for` or `switch` header, inside a larger expression — with a few
exceptions, each reported with this code:

- **A `case` or a `select` case.** A switch tries its cases one by one
  until one matches, so a call in a case runs only if the cases before it
  didn't; pull it into a statement before the switch, or use `if`/`else`.
  A `select` case's channel operation can't be moved out of the `select`.
- **A `for` loop's post statement**, which runs after every iteration:
  move it into the loop's body.
- **Markup.** Call it in a statement before the markup and write `{x}`.
- **More than one `?` on the right of `&&` or `||`**, or in one loop
  condition: give them statements of their own.
- **A value it doesn't have.** `?` on an `error` alone yields nothing, so
  it ends a statement (`f()?`); one yielding several values is assigned
  (`a, b := f()?`).

It also needs the function to pass on what it fails with: an `error` last
or a `Result` for errors, an `Option` for an Option — or `opt?(err)` to say
which error a `None` is. In `main` and in a function taking a
`*testing.T`, `*testing.B` or `testing.TB`, it needs neither (see
[The ? Operator](/features/try#main-and-tests)). `?(…)` takes a message, a
`func(error) error`, an `error`, or an error enum's variant whose only
field is an `error` (see [Adding Context](/features/try#adding-context)).

## Wrong

```vuka
func parse(s string) int {
	n := strconv.Atoi(s)?
	return n
}

func label(s string) (string, error) {
	switch {
	case strconv.Atoi(s)? > 10:
		return "big", nil
	}
	return "small", nil
}
```

## Right

```vuka
func parse(s string) (int, error) {
	n := strconv.Atoi(s)?
	return n, nil
}

func label(s string) (string, error) {
	if strconv.Atoi(s)? > 10 {
		return "big", nil
	}
	return "small", nil
}
```
