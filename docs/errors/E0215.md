# E0215: An attribute of a package the file doesn't import

A qualified attribute names its package the way Go code does: `@graphql.Query`
is the type `Query` of the package the file imports as `graphql`. A file
writing one without the import gets this error, with the import to add for
the packages attributes come from most — `graphql`, `web`, `auth`, `cron`,
`ui`, `forms`, `orm` — rather than Go's `undefined: graphql`.

## Wrong

```vuka
package shop

import "context"

@graphql.Query
func Pets(ctx context.Context, store *Store) ([]Pet, error) { … }
```

## Right

```vuka
package shop

import (
	"context"

	"github.com/vuka-lang/web/v2/graphql"
)

@graphql.Query
func Pets(ctx context.Context, store *Store) ([]Pet, error) { … }
```
