# E0806: A GraphQL subscription

`@graphql.Subscription` is reserved for subscriptions over the live page's
socket, which a later version serves. Until then a function carrying it is
an error, so a schema never advertises an operation nothing answers.

## Wrong

```vuka
@graphql.Subscription
func OrderPlaced(ctx context.Context, shop int64) (<-chan Order, error) { … }
```

## Right

```vuka
@graphql.Query
func RecentOrders(ctx context.Context, shop int64, store *Store) ([]Order, error) { … }
```

See [Operations](/web/graphql#operations).
