# E0802: A Go type the GraphQL schema can't use

An operation's parameters and result, and the fields and methods of the
types they reach, become the schema's types. A struct is an object (or an
input object, as an argument), a slice a list, a pointer nullable, a basic
type, `time.Time` or a type reading and writing itself as text a scalar,
and a type with constants an enum. A map, a channel, a function, an
unnamed struct, a pointer to a pointer, a list of pointers to scalars and
`time.Duration` have no GraphQL type; the message names the path that
reaches one.

## Wrong

```vuka
type Pet struct {
	Name  string
	Attrs map[string]string // pets.Pet.Attrs is map[string]string
}

@graphql.Query
func Pets(ctx context.Context, store *Store) ([]Pet, error) { … }
```

## Right

```vuka
type Attr struct{ Key, Value string }

type Pet struct {
	Name  string
	Attrs []Attr
	Cache map[string]string `graphql:"-"` // left out of the schema
}
```

See [GraphQL](/web/graphql#types).
