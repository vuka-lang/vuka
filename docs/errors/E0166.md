# E0166: A pointer receiver on a value enum's variant

A value enum's variants are constants: there is nothing to point at, and a
method on them can't change the value. Write the receiver without the `*`.

A method name declared on the variants has its default on the enum with a
value receiver too: a `*PaymentStatus` method of the same name is the same
error.

See [Methods on Variants](/features/enums#methods-on-variants).

Reported by the compiler.

## Wrong

```vuka
enum PaymentStatus {
	Pending
	Settled
}

func (s *PaymentStatus.Pending) Retry() bool { return true }
func (PaymentStatus.Settled) Retry() bool    { return false }
```

## Right

```vuka
enum PaymentStatus {
	Pending
	Settled
}

func (PaymentStatus.Pending) Retry() bool { return true }
func (PaymentStatus.Settled) Retry() bool { return false }
```
