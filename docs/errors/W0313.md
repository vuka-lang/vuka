# W0313: A depends tag names a field the form lacks

`depends:"Country"` on a field with choices (`CityChoices`) says its
choices follow another field: the form gives that field an Update button
for browsers without script, which renders the form again with the new
choices. A name that isn't a field of the form gets no button, and the
form doesn't render (its error names the tag).

## Wrong

```go
type Address struct {
    ui.FormState
    Country string `validate:"required"`
    City    string `validate:"required" depends:"Contry"`
}
```

## Right

```go
type Address struct {
    ui.FormState
    Country string `validate:"required"`
    City    string `validate:"required" depends:"Country"`
}
```
