# E0410: A constructor has the wrong shape

`web.Provide` takes constructors, `func(deps…) T` or `func(deps…) (T,
error)`, and ready values (anything not a function). `nil` and functions of
other shapes aren't either. Reported at boot.

## Wrong

```go
web.Provide(func() (*DB, *Cache, error) { … })
```

## Right

```go
web.Provide(OpenDB, NewCache)
```
