# W0104: An exported template has no doc comment

An exported template is part of its package's API, as an exported Go
function is, and has a doc comment: `//` lines right above its `func`
header, starting with its name. A `View` or `Render` method is documented
by its type. Reported by `vuka vet` and `vukavet`.

## Wrong

```html
package layouts

func Admin(title string, children ui.Node)
<main><h1>{title}</h1>{children}</main>
```

## Right

```html
package layouts

// Admin is the frame of the admin pages: the title over the page.
func Admin(title string, children ui.Node)
<main><h1>{title}</h1>{children}</main>
```
