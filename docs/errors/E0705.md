# E0705: A path parameter's type can't be in a URL

A path parameter is parsed from the URL and written into it by the page's URL function: it is an integer, a string, `web.Rest`, or a type with `MarshalText` and `UnmarshalText`.

## Wrong

```go
type Params struct{ Org float64 }
```

## Right

```go
type Params struct{ Org int }
```
