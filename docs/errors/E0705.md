# E0705: A path parameter's type can't be in a URL

A parameter's type says which segments match and how its typed URL
function writes it back: a string, an integer kind, `web.Rest`, or a type
with `UnmarshalText` (to read it) and `MarshalText` (to write it). A
struct, a slice, a float or a map is none of those. Reported at the field.

## Wrong

```go
package invoice

type Params struct {
	Invoice []int
}
```

## Right

```go
package invoice

type Ref struct{ Year, N int }

func (r Ref) MarshalText() ([]byte, error) { return fmt.Appendf(nil, "%d-%d", r.Year, r.N), nil }

func (r *Ref) UnmarshalText(b []byte) error {
	_, err := fmt.Sscanf(string(b), "%d-%d", &r.Year, &r.N)
	return err
}

type Params struct {
	Invoice Ref
}
```
