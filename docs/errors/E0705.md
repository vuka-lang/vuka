# E0705: A path parameter's type can't be in a URL

A parameter's type says which segments match and how the package `urls`
writes it back: a string, an integer kind, `web.Rest`, or a type with
`UnmarshalText` (to read it) and `MarshalText` (to write it). A struct, a
slice, a float or a map is none of those. A named type is declared outside
`pages/`: `urls` imports no page package, so a type declared in one can't
appear in its methods. Reported at the field, or at `Params` for a type
declared in a page package.

## Wrong

```go
package invoice

type Params struct {
	Invoice []int
}
```

## Right

```go
package refs // a package outside pages/

type Ref struct{ Year, N int }

func (r Ref) MarshalText() ([]byte, error) { return fmt.Appendf(nil, "%d-%d", r.Year, r.N), nil }

func (r *Ref) UnmarshalText(b []byte) error {
	_, err := fmt.Sscanf(string(b), "%d-%d", &r.Year, &r.N)
	return err
}
```

```go
package invoice

import "example.com/shop/refs"

type Params struct {
	Invoice refs.Ref
}
```
