# E0707: A folder route collides with a declared route

A page under `pages/` gets the path of its folder, and the module declares a route of the same method on that path too, with a decorator or a `web.Routes` / app call.

## Wrong

```go
// pages/orgs/org/index.go serves GET /orgs/{org}
web.Routes.Get("/orgs/{id}", ShowOrg)
```

## Right

```go
web.Routes.Get("/api/orgs/{id}", ShowOrg)
```
