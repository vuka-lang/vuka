# E0203: An attribute must start its own line

An attribute before a declaration (`@doc`, `@deprecated`, a typed attribute,
a decorator) is written on its own line. Several attributes may share a
line, but the first of them starts it, and the declaration follows on the
next line.

## Wrong

```vuka
func helper() {} @doc("Lists the users")
func listUsers() []User { … }
```

## Right

```vuka
func helper() {}

@doc("Lists the users")
func listUsers() []User { … }
```
