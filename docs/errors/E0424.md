# E0424: An undefined name near a context processor variable

A template names something that isn't a field, a local, a declaration of
the package or a context processor variable, and it is a letter or two
from one: a typo. The diagnostic suggests the variable and the processor
giving it. Reported by the compiler and the editor.

## Wrong

```html
<span>{usr.Name}</span>
```

## Right

```html
<span>{user.Name}</span>
```

See [context processors](/web/context-processors).
