# E0107: An event handler doesn't fit

An `on…` attribute takes a function: a live view's method, or JS commands
(`ui.JS…`). The value given isn't one, or the handler takes parameters the
event doesn't pass.

## Wrong

```vuka
<button onClick={"save"}>Save</button>
```

## Right

```vuka
<button onClick={p.Save}>Save</button>
```
