# E0140: a template file has no type to be the Render of

The markup at the top of a `.vuka.html` file, before its first `func` line,
is the `Render` of the type the file is named after: `sales.vuka.html` is
`Sales`'s, `order_row.vuka.html` `OrderRow`'s. The package declares no such
type.

## Wrong

```html
<!-- sales.vuka.html, and no type Sales in the package -->
<section>{Title}</section>
```

## Right

Declare the type, its fields the component's props:

```go
// sales.go
type Sales struct{ Title string }
```

or start the file with a header naming what the markup is:

```html
func SalesBox(title string)
<section>{title}</section>
```
