# E0504: A field of a model the query doesn't join

A query reads its own model's table and the tables its `Join`s add. A typed
field of another model — `Product.Status` in a query of categories that
joins no products — names a table the statement doesn't have, and the
query fails ("Product isn't joined"). A `Join`'s conditions may name the
query's model and the tables joined before it, not one joined after it.
Reported by the query when it runs and by [vukavet](/tools/vukavet) where
the field is written.

## Wrong

```go
Category.Objects.
	Filter(Product.Status.Eq("active")).
	Values[string](Category.Name)
```

## Right

```go
Category.Objects.
	Join(ProductCategory.On(ProductCategory.CategoryID.EqCol(Category.ID))).
	Join(Product.On(ProductCategory.Product.Eq(Product.ID))).
	Filter(Product.Status.Eq("active")).
	Distinct().
	Values[string](Category.Name)
```
