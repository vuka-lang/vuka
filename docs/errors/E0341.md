# E0341: A timing attribute off a page's or component's method

`@ui.Defer` says when a method of a page or component runs: after the page's
first bytes are sent, its part — the markup calling it — following in the
same response. It goes only on a method of a struct a `.vuka.html` file
renders (or, in Go, of a type rendering itself). On a plain function, or on
a method of a service, there is no markup whose part it could be.

Defer the page's method that calls the service instead. Reported by the
compiler, and by [`vukavet`](/tools/vukavet) for
`vuka.RegisterFunc(fn, ui.Defer(""))` in Go. See [Parts of a Page](/web/parts).

## Wrong

```vuka
// applications/service.vuka
@ui.Defer
func (s *Service) Stats(ctx context.Context) (Stats, error) { … }
```

## Right

```html
<!-- pages/index.vuka.html -->
<script lang="go">
package pages

import (
	"context"

	"example.com/app/applications"
)

type Index struct {
	apps *applications.Service
}

@ui.Defer
func (p *Index) Stats(ctx context.Context) (applications.Stats, error) { return p.apps.Stats(ctx) }
</script>

<p>{Stats(ctx).Open} open</p>
```
