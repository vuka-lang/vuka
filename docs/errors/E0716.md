# E0716: A Go file the folder's package can't hold

The go command builds no `[id]` folder and no route group `(admin)`: an
import path can hold neither a bracket nor a parenthesis. vuka compiles
such a folder where the go command sees it, `param_id/` or
`group_admin/`, its `.vuka` and `.vuka.html` files' Go and its own `.go`
files together, as one package. A private folder below `pages/` holding
Vuka source, `_parts`, is compiled the same way, as `private_parts/`.

Two things can't be: a `.go` file whose package clause names another
package than the folder's other files (only the external test package,
`name_test`, may differ), and a `.go` file named for a parameter, `[id].go`,
which the go command reads nowhere. Reported at the file.

## Wrong

```text
pages/orgs/[org]/index.vuka.html   package org
pages/orgs/[org]/edit.go           package edit
pages/api/pets/[id].go
```

## Right

```text
pages/orgs/[org]/index.vuka.html   package org
pages/orgs/[org]/edit.go           package org
pages/api/pets/[id].vuka
```
