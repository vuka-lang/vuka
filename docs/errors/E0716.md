# E0716: A Go file is in a bracketed folder

An import path can't hold a bracket, so the go command builds no `[id]`
folder and reads no `[id].go` file. vuka compiles the folder for it: its
Go goes where the go command sees it, `param_id/`, generated from the folder's
`.vuka` and `.vuka.html` files. A `.go` file there would be read by
nothing, and breaks `go list ./...`, so it is this error. Its source is
Go already, so renaming it `.vuka` is the whole fix.

## Wrong

```text
pages/orgs/[org]/guard.go
pages/api/pets/[id].go
```

## Right

```text
pages/orgs/[org]/guard.vuka
pages/api/pets/[id].vuka
```
