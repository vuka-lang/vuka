# E0311: Island component is ambiguous

A bare `@ui.Island` found more than one file for the type
(`islands/Chart.vue` and `islands/Chart.tsx`), and the extension decides the
framework, so vuka won't guess.

## Wrong

```vuka
// web/islands/Chart.vue and web/islands/Chart.tsx both exist
@ui.Island
type Chart struct{ Series []float64 }
```

## Right

```vuka
@ui.Island("islands/Chart.vue")
type Chart struct{ Series []float64 }
```
