# E0301: Malformed island import

A component file is imported into a `.vuka` file under a name, which is the
tag it is used by. A blank or dot import of a component names nothing.

## Wrong

```vuka
import _ "./islands/Counter.vue"
```

## Right

```vuka
import Counter "./islands/Counter.vue"
```
