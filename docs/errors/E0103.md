# E0103: Two JSX targets

The file imports two packages that both declare `VukaJSX`, so vuka can't
tell which renders the file's JSX. A file renders with one target.

## Wrong

```vuka
import (
	"github.com/vuka-lang/ui"
	"example.com/app/mytarget"
)
```

## Right

```vuka
import "github.com/vuka-lang/ui"
```
