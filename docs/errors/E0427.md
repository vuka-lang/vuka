# E0427: A web.Var read the app doesn't give

`web.Var[T](ctx, "name")` reads a context processor variable explicitly:
in Go, and in packages of other modules — a component library — which
read nothing by name. `vuka vet` checks each read of the packages a main
links in against that main's `web.ContextProcessors(…)`: here no listed
processor gives the name, or gives it with another type. Reported at the
`web.ContextProcessors` call, naming the read's file and line.

## Wrong

```go
// a library's component
me := web.Var[*users.User](ctx, "currentUser")
```

## Right

```go
me := web.Var[*users.User](ctx, "me")
```

See [context processors](/web/context-processors#reading-a-variable-in-go).
