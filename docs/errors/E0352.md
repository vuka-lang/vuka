# E0352: A Suspense wait list names an unavailable binding

`<ui.Suspense for={categories, stats}>` names preceding `:=` bindings in
scope. A misspelling includes a suggested name when one is close. Each
binding belongs to one boundary's wait list.

## Wrong

```html
categories := GetCategories()
<ui.Suspense for={categries}>
  <p>{len(categories)} categories</p>
</ui.Suspense>
```

## Right

```html
categories := GetCategories()
<ui.Suspense for={categories}>
  <slot:fallback>Loading categories…</slot:fallback>
  <p>{len(categories)} categories</p>
</ui.Suspense>
```

Move the declaration above the boundary, correct the name, or remove it
from the second boundary's list. See [Parts of a Page](/web/parts#suspense).
