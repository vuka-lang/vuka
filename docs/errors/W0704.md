# W0704: A page's Load that never runs

Layouts and guards have a `Load`, which vuka calls before the page renders.
A page doesn't: a `Load` method on a page's struct is an ordinary method, so
unless your own code calls it, nothing does, and what it would set stays empty.

## Wrong

```html
<script lang="go">
// pages/orders/index.vuka.html
type Index struct {
	orders []Order
	store  *Store
}

func (p *Index) Load(ctx context.Context) error {
	p.orders = p.store.List(ctx)
	return nil
}
</script>

<ul>…</ul>
```

## Right

Load in the markup, which runs on each render of a page that isn't live:

```html
<script lang="go">
type Index struct {
	store *Store
}
</script>

<>
  orders := store.List(ctx)
  <ul>…</ul>
</>
```

On a live page, use a hook:

```go
@ui.Mount
func (p *Index) mount(ctx context.Context) error {
	p.orders = p.store.List(ctx)
	return nil
}
```

What guards a whole folder, such as a redirect, goes in a `guard.vuka` or the
folder's `_layout`, whose `Load` does run.
