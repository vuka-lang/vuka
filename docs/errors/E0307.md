# E0307: Not an island component

The body of `<ui.Island>` must be an island component: a struct type marked
`@ui.Island`, or a component file imported by name.

## Wrong

```vuka
func Chart(series []float64) ui.Node { … }

<ui.Island><Chart series={p.sales} /></ui.Island>
```

## Right

```vuka
@ui.Island
type Chart struct {
	Series []float64 `json:"series"`
}

<ui.Island><Chart series={p.sales} /></ui.Island>
```
