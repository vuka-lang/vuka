# E0184: A form type method of the wrong shape

A struct embedding `ui.FormFor[T]` is a form type, and some of its methods
are the form's: `Init` runs when the form is created and on every `Load`,
and `Clean` and `Clean<Field>` check the form. `Init` takes a ctx, then any
dependencies, and returns an error; a Clean method returns an error, nil
when the form passes.

## Wrong

```vuka
type ProductForm struct {
    ui.FormFor[Product]
}

func (f *ProductForm) Init() {
    f.Status = "draft"
}

func (f *ProductForm) CleanPrice(ctx context.Context) bool {
    return f.Price >= 0
}
```

## Right

```vuka
func (f *ProductForm) Init(ctx context.Context) error {
    if f.IsNew() {
        f.Status = "draft"
    }
    return nil
}

func (f *ProductForm) CleanPrice(ctx context.Context) error {
    if f.Price < 0 {
        return forms.Errorf("Enter a price of 0 or more")
    }
    return nil
}
```
