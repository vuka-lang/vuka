# E0363: A form in a stream row that checks as the visitor types

A `<ui.Form for>` in a stream row checks its fields as it is submitted. Its
checks run on a fresh form the session binds from what the submit sends, so
there is no form on the server to check a field against as the visitor
types, and an `onChange` handler would be one the server keeps for the row.
Reported by the compiler, `vuka vet` and the editor, and by the render of a
component written in Go.

## Wrong

```html
<ui.Form for={renameOf(t)} onSubmit={ui.JS.Push(Rename, t.ID)} onChange={ui.JS.Push(Check, t.ID)}/>
```

## Right

```html
<ui.Form for={renameOf(t)} onSubmit={ui.JS.Push(Rename, t.ID)}/>
```

The submit runs every rule and `Clean` method, and the report places each
error at its field without rendering the row.
