# E0320: Bad @ui.Island arguments

`@ui.Island` takes an optional path and strategy as string literals (the
vuka command reads them from the source), then options: `ui.Layout(…)` and
`ui.Strategy("…")`. It goes on a type. Reported by the build, `vuka vet`
and, for what only shows at run time, at boot.

## Wrong

```vuka
@ui.Island(path, "load", "extra")
type Chart struct{ … }
```

## Right

```vuka
@ui.Island("charts/Revenue.vue", ui.Strategy("load"))
type Chart struct{ … }
```
