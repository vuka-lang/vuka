# E0164: A variant method missing variants

A value enum's variants are values, so a method declared on its variants,
`func (PasswordError.Mismatch) Error() string`, becomes one method on the
enum that switches on the value. That method needs an answer for every
variant: each variant declares it, or the enum declares a default,
`func (e PasswordError) Error() string`, for the variants without their
own. A value that is no variant (`PasswordError(9)`) reaches the default, or
panics when there is none.

The same code reports a receiver naming a variant the enum doesn't have.

See [Methods on Variants](/features/enums#methods-on-variants).

Reported by the compiler.

## Wrong

```vuka
enum PasswordError {
	CurrentRequired
	Mismatch
	ChangeFailed
}

func (PasswordError.CurrentRequired) Error() string { return "Current password is required" }
```

## Right

```vuka
enum PasswordError {
	CurrentRequired
	Mismatch
	ChangeFailed
}

func (PasswordError.CurrentRequired) Error() string { return "Current password is required" }

// Error is the message of the variants without their own.
func (e PasswordError) Error() string { return "Failed to change password" }
```
