# E0124: Code that can't run in the browser

A client-side expression (one reading a `ui.State`, kept current in the
browser) is translated to JavaScript, and only state reads, literals and a
small set of operators translate. A function call or another operator has
to run on the server.

## Wrong

```html
<!-- tabs.vuka.html -->
type Tabs struct {
	tab ui.State[string]
}
<p>{strings.ToUpper(tab)}</p>
```

## Right

```html
<!-- tabs.vuka.html -->
type Tabs struct {
	tab ui.State[string]
}
<p>{tab}</p>   <!-- kept current in the browser; or compute the text on the server -->
```
