# E0163: A statement's name used outside its scope

A statement in markup, `n := Count()`, binds its names as a Go statement
does: from the statement to the end of the block it is in — an `if`, `for`
or `switch` body, or the whole template. Markup after that block doesn't
see them.

A part's bindings are narrower: their element is their scope. That is a
binding listed in `<ui.Suspense for={…}>`, and one of a deferred method
inside a boundary; using one after the element holding its statement is
this error too. (A deferred method's binding outside a boundary makes its
element the part, and is [E0344](/errors/E0344) when used outside it.)

Move the statement up, before the block or into an element holding every
use, or bind the name again where it's needed. See
[Bindings](/ui/templates#bindings).

Reported by the compiler.

## Wrong

```html
<main>
  if More {
    n := Store.Count()
    <p>{n}</p>
  }
  <footer>{n} in all</footer>
</main>
```

```html
<main>
  <div>
    n := Store.Count()
    <ui.Suspense for={n}><p>{n}</p></ui.Suspense>
  </div>
  <footer>{n} in all</footer>
</main>
```

## Right

```html
<main>
  n := Store.Count()
  if More {
    <p>{n}</p>
  }
  <footer>{n} in all</footer>
</main>
```
