# E0163: A statement's name used after its element

A statement in markup, `n := Count()`, binds its names from the statement
to the end of the element it is in. Markup after that element doesn't see
them: the element is the statement's scope, as a block is in Go.

Move the statement up, into the element holding every use, or bind the name
again where it's needed. See [Bindings](/ui/templates#bindings).

Reported by the compiler.

## Wrong

```html
<main>
  <section>
    n := Store.Count()
    <p>{n} orders</p>
  </section>
  <footer>{n} in all</footer>
</main>
```

## Right

```html
<main>
  n := Store.Count()
  <section>
    <p>{n} orders</p>
  </section>
  <footer>{n} in all</footer>
</main>
```
