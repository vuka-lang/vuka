# E0726: A link gives a route the wrong parameters

After its name, `route` takes the path parameters of the route, in the
order the path has them, then an optional `query{…}`. The link gives more
or fewer of them, or one whose type the parameter can't take: a number for
a number, a string or the parameter's text type for a string or text one.
The message names the route's path and its parameters in order, as in
`users.edit (/users/[user]/edit) takes user int64`. Reported at the name.

## Wrong

```html
<a href={route("orgs.users.edit", user.ID)}>Edit</a>
```

## Right

```html
<a href={route("orgs.users.edit", org.ID, user.ID)}>Edit</a>
```
