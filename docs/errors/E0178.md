# E0178: A @ui.Notify that can't call its handler

[`@ui.Notify(OnTab)`](/ui/state#notify) on a `ui.State` field calls the
live component's method `OnTab` with each value the browser writes to the
state, over the page's live connection. Reported by the compiler:

- the attribute on a field that isn't a `ui.State` (a `ui.Derived` follows
  its states: notify one of those);
- on a component that isn't live;
- naming no method of the struct (the message suggests the nearest one);
- naming a method that doesn't take the state's value as its one argument,
  after an optional `context.Context`.

## Wrong

```html
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Index struct {
	ui.Live
	tab ui.State[string] @ui.Notify(OnTab)
}

func (p *Index) OnTab(n int) {}
</script>

<button onClick={tab = "all"}>All</button>
```

## Right

```html
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Index struct {
	ui.Live
	tab ui.State[string] @ui.Notify(OnTab)
}

func (p *Index) OnTab(tab string) {}
</script>

<button onClick={tab = "all"}>All</button>
```
