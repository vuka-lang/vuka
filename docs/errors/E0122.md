# E0122: Can't infer a type argument

`None`, `Err`, `Some` and other generic values take their type from where
they go: a typed variable, a return, a parameter. Here nothing gives it.

## Wrong

```vuka
x := Err(errors.New("not found"))
```

## Right

```vuka
x := Err[User](errors.New("not found"))
```
