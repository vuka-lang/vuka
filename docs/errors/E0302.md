# E0302: Island imported twice

One island name is imported from two files. A tag names one component.

## Wrong

```vuka
import (
	Picker "./islands/Picker.vue"
	Picker "./islands/DatePicker.vue"
)
```

## Right

```vuka
import (
	Picker     "./islands/Picker.vue"
	DatePicker "./islands/DatePicker.vue"
)
```
