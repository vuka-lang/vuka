# E0603: A frontend dependency is missing

The frontend needs packages that aren't installed: Vite, or a framework's
packages for its islands (`vue` and `@vitejs/plugin-vue` for `.vue`).

## Wrong

```sh
$ vuka build
vue islands need vue, @vitejs/plugin-vue in web …
```

## Right

```sh
$ (cd web && npm i -D vue @vitejs/plugin-vue)
$ vuka build
```
