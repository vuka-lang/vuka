# E0145: A template has an element's name

A lowercase tag naming an HTML, SVG or MathML element is that element, so a
template of the package named `header`, `nav`, `label` or `select` could
never be used as a tag. It is an error where the template is declared;
`vukavet` reports it too.

## Wrong

```html
package layouts

func Page(title string)
<main><header title={title}/></main>

func header(title string)
<h1>{title}</h1>
```

## Right

```html
package layouts

func Page(title string)
<main><pageTitle title={title}/></main>

func pageTitle(title string)
<h1>{title}</h1>
```
