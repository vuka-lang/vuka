# E0401: A route is declared twice

Two handlers declare the same method and path, so a request can't tell them
apart. Both places are shown. Reported at boot.

## Wrong

```vuka
@web.Get("/pets")
func ListPets(store *PetStore) []Pet { … }

@web.Get("/pets")
func AdminPets(store *PetStore) []Pet { … }
```

## Right

```vuka
@web.Get("/pets")
func ListPets(store *PetStore) []Pet { … }

@web.Get("/admin/pets")
func AdminPets(store *PetStore) []Pet { … }
```
