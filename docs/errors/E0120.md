# E0120: Conflicting overloads

Overloads of a function are told apart by their parameter types. Two
overloads with the same parameters, a generic function overloaded, or a
`.go` file declaring a name the `.vuka` source overloads can't be resolved.

## Wrong

```vuka
func area(r float64) float64 { … }
func area(r float64) float64 { … }
```

## Right

```vuka
func area(r float64) float64 { … }
func area(w, h float64) float64 { … }
```
