# E0148: A template file has Go and no markup

The markup of a `.vuka.html` file starts at the first line beginning with
`<` outside the Go above it — not inside a function's body or a string. The
file has no such line: it is Go alone.

## Wrong

```html
<!-- page.vuka.html -->
package pages

type Page struct {
	Title string
}

func (p Page) Upper() string { return strings.ToUpper(p.Title) }
```

## Right

Write the markup below the Go:

```html
<!-- page.vuka.html -->
package pages

type Page struct {
	Title string
}
<h1>{Title}</h1>
```

or, when nothing renders, make it a `.go` file.
