# E0174: A struct declared in a template and in its script file

A template's struct is declared in one place: its `<script lang="go">`,
or the [script file](/ui/templates#script-file) beside it (`orders.go`,
`orders.vuka`), leaving the template its markup. This template's script
declares the struct the file beside it declares too.

Keep one. The editor's *Move the script to orders.go* and *Move the script
from orders.go into this file* actions move it either way.

Reported by the compiler.

## Wrong

```go
// orders.go
package pages

type Orders struct{ Title string }
```

```html
<!-- orders.vuka.html -->
<script lang="go">
package pages

type Orders struct{ Title string }
</script>

<h1>{Title}</h1>
```

## Right

```go
// orders.go
package pages

type Orders struct{ Title string }
```

```html
<!-- orders.vuka.html -->
<h1>{Title}</h1>
```
