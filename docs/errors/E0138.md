# E0138: A tag passes an attribute on and the component has no forward element

An attribute on a component's tag that no prop takes falls through to the
component's forward element: its markup's one top-level element, or the
element marked `forward` ([Fallthrough](/ui/components#fallthrough)). A
component with no such element has nowhere to put it:

- its markup has several roots and none is marked;
- its root isn't an element: a hole (`{Children}`), a `<slot:x>`, an `if`
  or a `for`;
- its forward element is another component's tag: what a tag passes on
  reaches an element, so mark one inside, or set the attribute on the inner
  tag in the component's markup.

## Wrong

```html
<script lang="go">
package components

type Section struct {
	Title    string
	Children ui.Node
}
</script>

<h2>{Title}</h2>
<div>{Children}</div>
```

```html
<components.Section title="Orders" class="mt-6">…</components.Section>
```

## Right

```html
<script lang="go">
package components

type Section struct {
	Title    string
	Children ui.Node
}
</script>

<h2>{Title}</h2>
<div forward>{Children}</div>
```
