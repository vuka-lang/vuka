# E0502: A nil Schema attribute

`s.Model` and `s.Field` take attributes as values; one of them is nil, which
says nothing about the model. Reported by every query of the model,
`orm.Check` and [vukavet](/tools/vukavet).

## Wrong

```go
func (p *Post) Schema(s *orm.Schema) {
	s.Field(&p.Slug, orm.Slug{Unique: true}, nil)
}
```

## Right

```go
func (p *Post) Schema(s *orm.Schema) {
	s.Field(&p.Slug, orm.Slug{Unique: true})
}
```
