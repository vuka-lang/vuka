# E0105: Can't lower a JSX element

Vuka couldn't turn an element into Go, almost always because the type of
the component or of an attribute is unknown — another error (an undefined
name, an import that doesn't load) hides it. Fix the errors around it and
this one goes.

## Wrong

```vuka
return <Profle user={u} />   // Profle is undefined
```

## Right

```vuka
return <Profile user={u} />
```
