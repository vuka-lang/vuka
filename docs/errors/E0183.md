# E0183: A field setting given by its tag and by an attribute

A form field's label, hint, placeholder, control and rules come from its
attributes (`@ui.Label("…")`, `@orm.Char{Max: 100}`) or from its tags
(`label:"…"`, `validate:"max=100"`). Both keep working, but one setting
has one source: a field whose tag and attribute both set it — whichever
would win — is an error at the attribute.

## Wrong

```vuka
type Signup struct {
    Email string `label:"Email" validate:"required"` @ui.Label("Email address")
}
```

## Right

```vuka
type Signup struct {
    Email string `validate:"required"` @ui.Label("Email address")
}
```
