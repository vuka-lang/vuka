# E0351: A boundary's markup is misplaced

A `<ui.Suspense>` boundary takes an optional `for={a, b}` list of bindings and two slots: a
`<slot:fallback>`, shown until everything the boundary's markup reaches has
returned, and a `<slot:error>`, shown when any of it fails. A second one,
or an attribute other than `for` on the tag, is reported; a slot it doesn't
have is [E0106](/errors/E0106).

Reported by the compiler. See [Parts of a Page](/web/parts#suspense).

## Wrong

```html
<ui.Suspense pending="…">
  <slot:fallback><ui.Skeleton lines={3}/></slot:fallback>
  <h3>{len(GetCategories())} categories</h3>
</ui.Suspense>
```

## Right

```html
<ui.Suspense>
  <slot:fallback><ui.Skeleton lines={3}/></slot:fallback>
  <slot:error>Couldn't load categories.</slot:error>
  <h3>{len(GetCategories())} categories</h3>
</ui.Suspense>
```
