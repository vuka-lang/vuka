# W0116: A step after a Push that runs before its reply

The steps written after a [`Push`](/ui/js#push-lifecycle) run at once,
while the push is on its way: `ui.JS.Push(Save).Hide("#form")` hides the
form before the server has saved anything, and keeps it hidden when the
save fails. `vuka vet` warns of a `Hide`, `Navigate`, `Patch`, `Reload`
or a toast (`Then(ui.ShowToast(…))`) written straight after a `Push` — after its
`Into`, `Timeout` and hooks — which read as if they waited for the reply.
`.Success(…)` runs them once the push has succeeded. Reported by
`vuka vet`.

## Wrong

```html
<button onClick={ui.JS.Push(Save).Hide("#form")}>Save</button>
<button onClick={ui.JS.Push(Remove, ui.Value(o.ID)).Navigate("/orders")}>Delete</button>
```

## Right

```html
<button onClick={ui.JS.Push(Save).Success(ui.JS.Hide("#form"))}>Save</button>
<button onClick={ui.JS.Push(Remove, ui.Value(o.ID)).Success(ui.JS.Navigate("/orders"))}>Delete</button>
```
