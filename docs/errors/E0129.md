# E0129: Attributes and a hand-written schema method

A struct embedding `orm.Base` or `ui.Live` declares its attributes in one
method, `Schema` or `LiveSchema`. Vuka writes that method from the
attributes on the struct's fields and the hooks on its methods, so the
type can't declare it too.

## Wrong

```vuka
type Post struct {
	orm.Base
	Title string @orm.Char{Max: 200}
}

func (p *Post) Schema(s *orm.Schema) {
	s.Model(orm.Meta{Table: "posts"})
}
```

## Right

```vuka
type Post struct {
	orm.Base @orm.Meta{Table: "posts"}
	Title string @orm.Char{Max: 200}
}
```
