# E0330: An island page under @web.Live isn't live

`@web.Live` on an `@ui.Island` struct (in Go, `web.Routes.Live(path, NewT,
ui.Island())`) makes a live page backed by its component, which needs
`ui.Live` embedded. Without it the page is stateless, and `@web.Get`
(`web.Routes.Get`) routes it. Reported at boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
@web.Live("/orders")
@ui.Island
type Orders struct {
	Rows []Order
}
```
:::

::: go
```go
type Orders struct {
	Rows []Order
}

func NewOrders() *Orders { return &Orders{} }

func init() { web.Routes.Live("/orders", NewOrders, ui.Island()) }
```
:::

## Right

::: vuka
```vuka
@web.Live("/orders")
@ui.Island
type Orders struct {
	ui.Live
	Rows []Order
}
```
:::

::: go
```go
type Orders struct {
	ui.Live
	Rows []Order
}

func NewOrders() *Orders { return &Orders{} }

func (o *Orders) Render() ui.Node { return ui.IslandPage(o) }

func init() { web.Routes.Live("/orders", NewOrders, ui.Island()) }
```
:::
