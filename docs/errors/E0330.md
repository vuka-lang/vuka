# E0330: An island page under @web.Live isn't live

`@web.Live` on an `@ui.Island` struct makes a live page backed by its
component, which needs `ui.Live` embedded. Without it the page is stateless,
and `@web.Get` routes it. Reported at boot, and by
[vukavet](/tools/vukavet).

## Wrong

```vuka
@web.Live("/orders")
@ui.Island
type Orders struct {
	Rows []Order
}
```

## Right

```vuka
@web.Live("/orders")
@ui.Island
type Orders struct {
	ui.Live
	Rows []Order
}
```
