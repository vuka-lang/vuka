# E0331: A page backed by a component isn't a GET

A type routed as a page serves its component on a GET; its component's
sets and calls are posted to the same path by the framework. Another verb
can't route the type. Reported at boot.

## Wrong

```vuka
@web.Post("/orders")
@ui.Island
type Orders struct{ Rows []Order }
```

## Right

```vuka
@web.Get("/orders")
@ui.Island
type Orders struct{ Rows []Order }
```
