# E0324: A deferred field has no loader

A field tagged `defer:"group"` is loaded after the first render by the
group's loader, a method `Load<Group>()` or `Load<Group>(ctx
context.Context)` returning nothing or an error (`defer:""` on `CV` is the
group `CV`, loaded by `LoadCV`). The type has no such method. Reported by
`vuka vet`, the editor, and at boot.

## Wrong

```vuka
@web.Live("/applicants/{id}")
@ui.Island
type ApplicantDetail struct {
	ui.Live
	Name string
	CV   *CV `defer:"profile"`
}
```

## Right

```vuka
@web.Live("/applicants/{id}")
@ui.Island
type ApplicantDetail struct {
	ui.Live
	Name string
	CV   *CV `defer:"profile"`
}

func (p *ApplicantDetail) LoadProfile(ctx context.Context) error { … }
```
