# E0324: A deferred field has no loader

A field tagged `defer:"group"` is loaded after the first render by the
group's loader, a method `Load<Group>()` or `Load<Group>(ctx
context.Context)` returning nothing or an error (`defer:""` on `CV` is the
group `CV`, loaded by `LoadCV`). The type has no such method<span class="go-only"> — in Go, no `l.Loads(group, fn)`
in its `LiveSchema` either</span>. Reported by
`vuka vet`, the editor, and at boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
@web.Live("/applicants/{id}")
@ui.Island
type ApplicantDetail struct {
	ui.Live
	Name string
	CV   *CV `defer:"profile"`
}
```
:::

::: go
```go
type ApplicantDetail struct {
	ui.Live
	Name string
	CV   *CV
}

func (p *ApplicantDetail) LiveSchema(l *ui.LiveSchema) {
	l.Field(&p.CV, ui.Defer("profile"))
}

func init() { web.Routes.Live("/applicants/{id}", NewApplicantDetail, ui.Island()) }
```
:::

## Right

::: vuka
```vuka
@web.Live("/applicants/{id}")
@ui.Island
type ApplicantDetail struct {
	ui.Live
	Name string
	CV   *CV `defer:"profile"`
}

func (p *ApplicantDetail) LoadProfile(ctx context.Context) error { … }
```
:::

::: go
```go
type ApplicantDetail struct {
	ui.Live
	Name string
	CV   *CV
}

func (p *ApplicantDetail) LiveSchema(l *ui.LiveSchema) {
	l.Field(&p.CV, ui.Defer("profile"))
	l.Loads("profile", p.loadProfile)
}

func (p *ApplicantDetail) loadProfile(ctx context.Context) error { return nil }

func init() { web.Routes.Live("/applicants/{id}", NewApplicantDetail, ui.Island()) }
```
:::
