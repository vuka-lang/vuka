# E0167: A variant method every value enum generates

Every value enum generates `String`, `Valid`, `MarshalText`,
`UnmarshalText`, `Scan` and `Value`: its name (or value) as text, JSON and
the database depend on them. A variant can't declare one of them, since
the enum's one method of the name is the generated one.

For another text per variant, declare a method of another name.

See [Methods on Variants](/features/enums#methods-on-variants).

Reported by the compiler.

## Wrong

```vuka
enum PaymentStatus {
	Pending
	Settled
}

func (PaymentStatus.Pending) String() string { return "waiting for the bank" }
func (PaymentStatus.Settled) String() string { return "paid" }
```

## Right

```vuka
enum PaymentStatus {
	Pending
	Settled
}

func (PaymentStatus.Pending) Label() string { return "waiting for the bank" }
func (PaymentStatus.Settled) Label() string { return "paid" }
```
