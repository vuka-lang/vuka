# E0407: No provider for a dependency

A handler, cron, service or constructor needs a type the container doesn't
have. The chain says who needs it. Reported at boot.

## Wrong

```go
func OpenDB() (*DB, error) { … }

app := web.New()   // ListPets takes a *DB
```

## Right

```go
func OpenDB() (*DB, error) { … }

app := web.New(web.Provide(OpenDB))
```
