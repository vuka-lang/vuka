# E0601: The frontend isn't built

`web.Frontend` serves a frontend's built files, and there are none: the
build output (`dist/`) is missing. `vuka build` runs `vite build` first;
`vuka run` serves the dev server instead. Reported at boot.

## Wrong

```sh
$ go build . && ./app     # dist/ was never built
```

## Right

```sh
$ vuka build && ./app
```
