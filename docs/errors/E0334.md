# E0334: Two Update methods take URL parameters

On a live patch, the `Update` taking a struct embedding `web.URLParams`
receives the new URL. Two of them leave the framework no way to choose.
Reported at boot.

## Wrong

```vuka
func (o *Orders) Update(p ByStatus) error { … }   // ByStatus and ByQuery
func (o *Orders) Update(p ByQuery) error { … }    // both embed web.URLParams
```

## Right

```vuka
type OrdersURL struct {
	web.URLParams
	Status string `url:"status"`
	Q      string `url:"q"`
}

func (o *Orders) Update(p OrdersURL) error { … }
```
