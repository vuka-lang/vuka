# E0187: model on a hidden input (retired error)

This was briefly a compile error on main. It is now the warning
[W0115](./W0115), so that apps that compiled before keep compiling: the
compiler no longer reports E0187.

## Wrong

```vuka
<form for={Form}>
  <input type="hidden" model={Form.OwnerID}/>
</form>
```

## Right

```vuka
type OrderForm struct {
    ui.FormState
    Note    string
    OwnerID int `form:"-"`
}
```

and the submit handler sets `OwnerID` from the session.
