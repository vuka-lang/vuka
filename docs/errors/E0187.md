# E0187: model on a hidden input

A form's fields are what the visitor sees and changes. A hidden input
carrying a field (an id, an owner) would take whatever the browser sends
back: the page reads such values from its route or its session instead,
and the form leaves the field out (`form:"-"`).

## Wrong

```vuka
<form for={Form}>
  <input type="hidden" model={Form.OwnerID}/>
</form>
```

## Right

```vuka
type OrderForm struct {
    ui.FormState
    Note    string
    OwnerID int `form:"-"`
}
```

and the submit handler sets `OwnerID` from the session.
