# E0362: A form in a stream row that doesn't submit to a method taking it

The server forgets a stream's rows, so a `<ui.Form for>` in a row keeps no
state and no handler for the row: its submit is a `Push` of a method of the
stream's owner, the row's key among the push's arguments and the form's
fields filling the method's last parameter, the form's struct. The session
binds them into a fresh form, runs its checks and, when they fail, answers
with the form's report, which the browser puts in place on that row's form.
A row's form with no `onSubmit`, an `onSubmit` that pushes no method, or one
pushing a method that doesn't take the form's struct has nothing to submit
to. Reported by the compiler, `vuka vet` and the editor, and by the render
of a component written in Go.

## Wrong

```html
for _, t := range tasks.Rows() {
  <li key={t.ID}>
    <ui.Form for={renameOf(t)}/>
  </li>
}
```

## Right

```go
type Rename struct {
    ui.FormState
    Name string `validate:"required,max=80"`
}

func renameOf(t models.Task) *Rename { return &Rename{Name: t.Name} }

func (p *Tasks) Rename(ctx context.Context, id int64, f Rename) error {
    task, err := p.store.Rename(ctx, id, f.Name)
    if err != nil {
        return err
    }
    p.tasks.Insert(task)
    return nil
}
```

```html
for _, t := range tasks.Rows() {
  <li key={t.ID}>
    <ui.Form for={renameOf(t)} onSubmit={ui.JS.Push(Rename, t.ID)}/>
  </li>
}
```
