# E0193: A value an ActionOf[T] prop can't hold

A prop declared [`ui.ActionOf[T]`](/ui/events#typed-handler-props) holds a
handler the component calls with a `T`: a method of the page or a closure
taking one `T`, besides a `context.Context` and what the app injects. The
tag is checked against that: a method taking another type, or more than
one value, fails the build instead of the click.

A call, `onSelect={Select(o)}`, is the handler's result, run while the page
renders; statements, `onSelect={open = false}`, are browser commands; and a
quoted value is text. None of them takes the component's `T`. A prop that
takes any of those is a `ui.Action`.

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

import (
	"context"

	"example.com/app/components"
	"github.com/vuka-lang/ui/v2"
)

type Orders struct {
	ui.Live
	List []components.Order
}

func (p *Orders) Select(ctx context.Context, id int) error { return nil }
</script>

<components.OrderTable orders={List} onSelect={Select} />
```

## Right

```html
<script lang="go">
package pages

import (
	"context"

	"example.com/app/components"
	"github.com/vuka-lang/ui/v2"
)

type Orders struct {
	ui.Live
	List []components.Order
}

func (p *Orders) Select(ctx context.Context, o components.Order) error { return nil }
</script>

<components.OrderTable orders={List} onSelect={Select} />
```

`OrderTable` declares `OnSelect ui.ActionOf[Order]` and calls it on a row's
click, `<tr onClick={OnSelect(o)}>`.
