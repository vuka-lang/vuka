# E0605: An asset file isn't there

A `web.Style` or `web.Script` names a file (or a pattern) that matches
nothing next to the declaring file. The message suggests the nearest file
of its kind.

## Wrong

```vuka
@web.Live("/", web.Style("styles/ap.css"))
type Home struct{ ui.Live }
```

## Right

```vuka
@web.Live("/", web.Style("styles/app.css"))
type Home struct{ ui.Live }
```
