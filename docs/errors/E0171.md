# E0171: An asChild tag whose children aren't one element

A bare `asChild` on a component's tag makes the tag's child the
component's root: the child takes the component's forward element's
class, attributes and handlers, and keeps its own
([asChild](/ui/components#aschild)). The child is one element, written in
the tag. It is an error when the tag has:

- no children, or only text;
- several elements, or an element and text beside it;
- a hole or a block (`{link}`, `if …`) in the child's place;
- another component's tag: asChild takes an element in this release —
  write the element that component renders, or set the attributes on it.

## Wrong

```vuka
<design.Button asChild variant="outline">
  Report
</design.Button>
```

## Right

```vuka
<design.Button asChild variant="outline">
  <a href="/reports/42">Report</a>
</design.Button>
```
