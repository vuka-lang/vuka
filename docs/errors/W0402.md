# W0402: The request read in markup

The markup calls `web.Request(ctx)`, and `main` lists
`web.RequestContext`, whose variable `request` holds what a template reads
of the request: its path, query, parameters and route. `request` is
tracked: a staying layout showing `request.Path` renders that spot again
on each navigation and stays, where one calling `web.Request` reloads.
Reported by `vuka vet`.

## Wrong

```html
<small>{web.Request(ctx).URL.Path}</small>
```

## Right

```html
<small>{request.Path}</small>
```

See [context processors](/web/context-processors).
