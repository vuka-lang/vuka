# E0727: A link gives a query key its page does not keep

`query{"page": 2}` after a link's path parameters gives its query. Each key
must be one the target page reads: the key of one of its `@ui.URL("key")`
fields. The page keeps no field under the key. Reported at the key, with
the keys the page keeps.

## Wrong

```html
<a href={route("orders", query{"pag": 2})}>Next</a>
```

## Right

```html
<a href={route("orders", query{"page": 2})}>Next</a>
```
