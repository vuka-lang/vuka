# W0706: A urls chain vuka fix routes can't name

`vuka fix routes` writes a `urls` chain that names a page and is made into
its link at once — `urls.Users.User(id).Edit.URL(ctx)` or `.Path()` — as
`route("users.edit", id)` or `routePath(…)`, in Go `web.Route(ctx,
"users.edit", id)`. A chain kept in a variable or passed to a function, a
query given as a variable, or a `Path()` with no ctx in scope can't be
named where it stands: it keeps working as it is, and the fixer says where
it is. Rewrite it by hand where the link is made.

## Wrong

```
orgs := urls.Orgs // kept: which page it links to is decided later
return orgs.Org(id).URL(ctx)
```

## Right

```
return web.Route(ctx, "orgs.org", id)
```
