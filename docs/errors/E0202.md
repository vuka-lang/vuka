# E0202: Attribute in the wrong place

Attributes go in three places: before a top-level declaration, before a
parameter of a top-level function, and after a field of a package-level
struct. Not inside a function body, before a result or receiver, or in a
function literal.

## Wrong

```vuka
func main() {
	@doc("the count")
	x := 1
}
```

## Right

```vuka
@doc("the count")
var x = 1

func main() {}
```
