# E0111: Malformed match

A `match` statement is `match subject {` followed by `case pattern:` clauses
(and an optional `case _:`). The statement couldn't be read.

## Wrong

```vuka
match r
case Ok(v): use(v)
```

## Right

```vuka
match r {
case Ok(v):
	use(v)
case Err(err):
	log(err)
}
```
