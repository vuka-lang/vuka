# E0208: Malformed decorator declaration

`decorator` declares a decorator: `decorator logged(c) { c.Next() }`, or a
composed one, `decorator Fast = @logged @timed`, listing attributes and
decorators that each start with `@`. Declaration attributes like `@doc`
can't be composed.

## Wrong

```vuka
decorator Fast = logged timed
```

## Right

```vuka
decorator Fast = @logged @timed
```
