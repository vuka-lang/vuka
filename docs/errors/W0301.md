# W0301: A live page routed as one that isn't live

The `@ui.Island` struct embeds `ui.Live`, which makes it a live page, but
it is routed with `@web.Get` (or another verb), which is for a not-live
page. It still works as a live page; `@web.Live` says so. Reported by
`vuka vet` and the editor.

## Wrong

```vuka
@web.Get("/orders")
@ui.Island
type Orders struct {
	ui.Live
	Rows []Order
}
```

## Right

```vuka
@web.Live("/orders")
@ui.Island
type Orders struct {
	ui.Live
	Rows []Order
}
```
