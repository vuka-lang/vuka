# W0109: More than one ? in one expression

Each `?` may return from the function. An expression holding several —
`price(item)? * qty(cart)?`, `send(render(load(id)?)?)?` — has several ways
out on one line: a stack trace or a coverage report points at the line, not
at which call failed, and a reader has to find each `?` to see them.

The code compiles as written, the calls in Go's order, each checked as it
returns. `vuka vet` reports it; giving each `?` a statement of its own keeps
one way out per line. A single `?` in an
expression or a header is not reported.

## Wrong

```vuka
func total(item string, n int) (int, error) {
	return price(item)? * qty(n)?, nil
}
```

## Right

```vuka
func total(item string, n int) (int, error) {
	p := price(item)?
	q := qty(n)?
	return p * q, nil
}
```
