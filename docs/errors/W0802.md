# W0802: A GraphQL list without a limit

An operation or a field method returning a list lets a client ask for all of
it: every row of a table, in one response. `vuka vet` warns about one that
takes no `first`, `last` or `limit` argument and no `graphql.Page`. The
argument bounds what it returns, and the query's
[complexity](/web/graphql#limits) counts its subtree that many times.

## Wrong

```vuka
@graphql.Query
func Pets(ctx context.Context) ([]Pet, error) {
	return Pet.Objects.All(ctx)
}
```

## Right

```vuka
@graphql.Query
func Pets(ctx context.Context, first int) ([]Pet, error) {
	return Pet.Objects.Limit(min(first, 100)).All(ctx)
}

// or, page by page:
@graphql.Query
func PetsPage(ctx context.Context, page graphql.Page) (graphql.Connection[Pet], error) {
	return graphql.Paginate(ctx, Pet.Objects.OrderBy("name"), page)
}
```

See [Pagination](/web/graphql#pagination).
