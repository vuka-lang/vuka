# E0419: web.Params doesn't fit the handler

`web.Params` names a handler's parameters in order — reflection can't see
their names — so its scalar parameters bind from the path or the query by
name. It gives more names than the handler has parameters, or one name
twice, so a name binds nothing or two parameters claim one value. Reported
by [vukavet](/tools/vukavet).

## Wrong

```go
func ShowPet(id int, store *PetStore) (Pet, error) { … }

app.Get("/pets/{id}", ShowPet, web.Params("id", "store", "tab"))
```

## Right

```go
func ShowPet(id int, tab string, store *PetStore) (Pet, error) { … }

app.Get("/pets/{id}", ShowPet, web.Params("id", "tab", "store"))
```
