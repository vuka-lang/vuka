# E0419: A dependency field the URL binds too

A page's unexported field of a type the app provides is a dependency:
web injects it as it builds the page, for a folder page, its method
handlers, its layouts and guards, and a page-backed island
([dependency fields](/web/dependency-injection#dependency-fields)). This
field would also bind from the URL — it is named like one of the route's
path parameters, tagged `url:`, or given a URL by its `LiveSchema` — so
it can't say which it is. Reported at start-up.

## Wrong

```html
// pages/stores/[store]/index.vuka.html
type Index struct {
	store *store.Store // also the path parameter {store}
}
```

## Right

```html
// pages/stores/[store]/index.vuka.html
type Index struct {
	Store int          // the path parameter {store}
	db    *store.Store // the dependency
}
```
