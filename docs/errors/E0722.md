# E0722: Two routes on one URL through a route group

A route group, a folder in parentheses such as `(console)`, adds nothing
to the URL: the pages inside it are at the paths they would have without
it. Two pages, or two endpoints of one method, end up at the same URL when
the only thing between them is a group — one inside a group and one beside
it, or one in each of two groups. Reported at one of them, naming both
files.

## Wrong

```text
pages/admin/
  (console)/
    _layout.vuka.html          Shell: the admin area's shell
    auth/login.vuka.html       Login — /admin/auth/login
  auth/
    login.vuka.html            Login — /admin/auth/login
```

## Right

```text
pages/admin/
  (console)/
    _layout.vuka.html          Shell: the admin area's shell
    index.vuka.html            Index — /admin
  auth/
    login.vuka.html            Login — /admin/auth/login, outside the shell
```
