# E0327: Changed has the wrong signature

A page's `Changed` (in Go, the `l.OnChange` hook) runs after its component sets bound fields. It takes
nothing, a `context.Context`, or a context and a `ui.Changed` (which fields
the update set), and returns nothing or an error. Reported at boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
func (o *Orders) Changed(q string) error { … }
```
:::

::: go
```go
// In Go the hook is l.OnChange, whose func(ctx, ui.Changed) error the
// compiler checks; a method named Changed is the form of earlier releases:
func (o *Orders) Changed(q string) error { return nil }
```
:::

## Right

::: vuka
```vuka
func (o *Orders) Changed(ctx context.Context, changed ui.Changed) error {
	if changed.Has("Q") {
		return o.search(ctx)
	}
	return nil
}
```
:::

::: go
```go
func (o *Orders) LiveSchema(l *ui.LiveSchema) { l.OnChange(o.changed) }

func (o *Orders) changed(ctx context.Context, changed ui.Changed) error {
	if changed.Has("Q") {
		return o.search(ctx)
	}
	return nil
}
```
:::
