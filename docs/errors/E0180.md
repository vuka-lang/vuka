# E0180: A show or transition attribute that doesn't fit

An element's [`show={…}`](/ui/state#show) hides it while its value
doesn't hold, and its `transition={…}` animates the change. Reported by
the compiler:

- `show` with a value that isn't a bool, a `ui.State[bool]` or an
  expression of states reading as one (the message suggests a
  comparison);
- `show` with no value;
- a `transition` holding a `ui.ShowTransition` on an element with no
  `show`.

## Wrong

```html
<script lang="go">
package components

import (
	"time"

	"github.com/vuka-lang/ui/v2"
)

type Menu struct {
	tab ui.State[string]
}
</script>

<ul show={tab} transition={ui.Fade(150 * time.Millisecond)}>…</ul>
```

## Right

```html
<script lang="go">
package components

import (
	"time"

	"github.com/vuka-lang/ui/v2"
)

type Menu struct {
	tab ui.State[string]
}
</script>

<ul show={tab != ""} transition={ui.Fade(150 * time.Millisecond)}>…</ul>
```
