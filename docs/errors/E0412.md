# E0412: A cron is declared twice

A cron's name is its function's (`jobs.cleanUp` outside `main`), and two
crons have the same one, so `crontest` and the toolbar can't tell them
apart. Reported at boot.

## Wrong

```go
app.Cron("cleanUp", "@every 1h", cleanSessions)
app.Cron("cleanUp", "@every 1d", cleanUploads)
```

## Right

```go
app.Cron("cleanSessions", "@every 1h", cleanSessions)
app.Cron("cleanUploads", "@every 1d", cleanUploads)
```
