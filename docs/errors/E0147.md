# E0147: A template file declares several structs, and none is named after it

A `.vuka.html` file can declare helper structs beside the one its markup
renders. When it declares several, the markup renders the struct named after
the file: `orders.vuka.html` renders `Orders`. The file declares several and
none has that name, so the file doesn't say which one its markup renders. The
error names the struct expected, and is at the second struct.

A file declaring one struct renders it, whatever it is called:
`pages/index.vuka.html` can render `Home`.

## The file's name and its struct

The name's letters and digits are compared with the struct's, ignoring case
and everything else:

| File | Renders |
|---|---|
| `orders.vuka.html` | `Orders` |
| `order-row.vuka.html`, `order_row.vuka.html` | `OrderRow` |
| `index.vuka.html` | `Index` |
| `_layout.vuka.html` | `Layout` |
| `[id].vuka.html` | `Id` or `ID` |
| `[path...].vuka.html` | `Path` |

Two structs matching one file, `Id` and `ID`, are this error too. So are several
structs in a file whose name no struct can take, like `404.vuka.html`.

## Wrong

```html
<!-- orders.vuka.html -->
<script lang="go">
package pages

type List struct {
	Rows []Row
}

type Row struct {
	ID int
}
</script>

<ul>…</ul>
```

## Right

Name the struct the markup renders after the file. The others are helpers:
types of the package, as they would be in a `.go` file. They and their methods
aren't components, routes or live, and the markup's bare names are the rendered
struct's.

```html
<!-- orders.vuka.html -->
<script lang="go">
package pages

type Orders struct {
	Rows []Row
}

type Row struct {
	ID int
}
</script>

<ul>…</ul>
```

A struct with markup of its own goes in its own `.vuka.html` file.

## A form

A form the page holds, a struct embedding `ui.FormState`, is data, never the
struct the markup renders. A file with one other struct renders that one,
whatever the file is called:

```html
<!-- join.vuka.html -->
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Join struct {
	ui.Live
	Form Signup
}

type Signup struct {
	ui.FormState
	Email string `validate:"required,email"`
}
</script>

<ui.Form for={Form}/>
```
