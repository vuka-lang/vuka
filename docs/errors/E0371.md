# E0371: A variant or its value is unknown

[`ui.Variants`](/ui/classes#variants) picks a component's classes by the
values its `Class` method is given, name then value. A name that isn't a
variant, or a value the variant doesn't have, has no classes: a misspelt
name, a tag's attribute giving the prop a value the component doesn't
style, or a default naming a value since renamed. The render fails with the
nearest name. vukavet's `variants` check reports it in the source: in the
`Defaults`, in a constant passed to `Class`, and in a tag's attribute setting
a prop the component passes to `Class`.

## Wrong

```go
var alert = ui.Variants{
	Base:     "rounded-lg border px-4 py-3",
	Variants: map[string]map[string]string{"tone": {"error": "bg-red-50", "info": "bg-gray-50"}},
	Defaults: map[string]string{"tone": "information"},
}
```

```html
<components.Alert tone="eror">The card was declined.</components.Alert>
```

## Right

```go
var alert = ui.Variants{
	Base:     "rounded-lg border px-4 py-3",
	Variants: map[string]map[string]string{"tone": {"error": "bg-red-50", "info": "bg-gray-50"}},
	Defaults: map[string]string{"tone": "info"},
}
```

```html
<components.Alert tone="error">The card was declined.</components.Alert>
```
