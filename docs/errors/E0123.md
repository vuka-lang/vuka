# E0123: A Class tagged vuka:"class" that no class attribute uses

A component's caller writes `class="…"` on its tag. By default it falls
through to the component's forward element, merged with the element's own
classes ([Fallthrough](/ui/components#fallthrough)). A component that
computes with the caller's classes declares `Class string` tagged
`vuka:"class"` instead: its use in a class attribute is merged with the
caller's classes last, so a caller's `class="rounded-none"` replaces the
component's `rounded-md`.

A tagged `Class` that no class attribute uses drops the caller's classes
without a word — the warning [W0602](/errors/W0602) gives an untagged one,
here an error.

## Wrong

```html
<script lang="go">
package components

type Badge struct {
	Tone  string
	Class string `vuka:"class"`
}
</script>

<span class="inline-flex rounded-md" data-tone={Tone}>{Tone}</span>
```

## Right

```html
<script lang="go">
package components

type Badge struct {
	Tone  string
	Class string `vuka:"class"`
}
</script>

<span class={"inline-flex rounded-md " + Class} data-tone={Tone}>{Tone}</span>
```
