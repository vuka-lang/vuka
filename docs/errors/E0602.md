# E0602: Node.js or the package manager isn't installed

A frontend (Vite) or framework islands (Vue, React, Svelte) are built with
Node.js and the project's package manager, which aren't on `PATH`.
`VUKA_FRONTEND=off` builds without the frontend.

## Wrong

```sh
$ vuka build
frontend: npm isn't installed …
```

## Right

```sh
$ brew install node      # or your platform's Node.js 20+
$ vuka build
```
