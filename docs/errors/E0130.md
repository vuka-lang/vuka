# E0130: A hook written as a composite literal

A hook attribute on a method — `@ui.Mount`, `@ui.OnChange`,
`@ui.Loads("lists")` — is a call of the page's `LiveSchema`, with the
method as its last argument. Its arguments go in parentheses.

## Wrong

```vuka
@ui.Loads{Group: "lists"}
func (d *Dashboard) loadLists(ctx context.Context) error { … }
```

## Right

```vuka
@ui.Loads("lists")
func (d *Dashboard) loadLists(ctx context.Context) error { … }
```
