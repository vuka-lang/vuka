# E0725: A link names no route

`route("users.edit", id)` and `routePath(…)` link to a folder route by its
name: its folders under `pages/` joined with dots, parameter and group
folders left out (`pages/users/[user]/edit` is `users.edit`), a page file
adding its own segment (`pages/orders/new.vuka.html` is `orders.new`). Two
paths that differ only in their parameters keep them (`orders` and
`orders.order`). No route has the name the link gives. Reported at the name,
with the closest name there is; `vuka routes` lists the paths.

## Wrong

```html
<a href={route("user.edit", user.ID)}>Edit</a>
```

## Right

```html
<a href={route("users.edit", user.ID)}>Edit</a>
```
