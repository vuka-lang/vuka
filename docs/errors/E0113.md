# E0113: match isn't exhaustive

A `match` must cover every value of its subject. The message names the
values no case matches, and its help the cases to add. In the editor the
quick fix **Add missing cases** adds them at the end of the match: a missing
`Err(_)` returns the error when the function can, the others get a `// TODO`
to fill in.

## Wrong

```vuka
func describe(r Result[int]) string {
	match r {
	case Ok(n):
		return fmt.Sprint(n)
	}
}
```

## Right

```vuka
func describe(r Result[int]) string {
	match r {
	case Ok(n):
		return fmt.Sprint(n)
	case Err(err):
		return err.Error()
	}
}
```
