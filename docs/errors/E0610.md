# E0610: npm is older than 11

npm 10, which Node.js 20 and 22 ship, crashes resolving the packages of a
new app's frontend from scratch (`Cannot read properties of null (reading
'edgesOut')`). vuka stops before running it when the frontend has no
`package-lock.json`, or when `vuka add` adds packages to it. Installing
from the lockfile `vuka new` writes (`npm ci`) works with npm 10, so then
vuka only warns.

## Wrong

```sh
$ npm --version
10.8.2
$ vuka add island Chart --react
frontend: npm 10.8.2 can't install web/ …
```

## Right

```sh
$ npm install -g npm@11
$ vuka add island Chart --react
```
