# E0185: A form type and its T sharing a field or a method

A form type, a struct embedding `ui.FormFor[T]`, reaches `T`'s fields
through itself: `Form.Name` is `Form.Value.Name`. A field the form type
declares itself is not a form field, so one named as a field of `T` would
hide it. A form method — `Clean`, `Clean<Field>`, `<Field>Choices` — has one
place: on the form type or on `T`, not both.

## Wrong

```vuka
type Product struct {
    Name  string
    Price int64
}

func (p Product) Clean() error { return nil }

type ProductForm struct {
    ui.FormFor[Product]
    Name string // the page's own state
}

func (f *ProductForm) Clean(ctx context.Context) error { return nil }
```

## Right

```vuka
type ProductForm struct {
    ui.FormFor[Product]
    Draft string
}

func (f *ProductForm) Clean(ctx context.Context) error { return nil }
```

with `Product`'s `Clean` removed, or the form type's.
