# E0006: A .templ file doesn't compile

A `.templ` file in the package couldn't be parsed or generated. Its Go is
part of the package, so the package's `.vuka` files aren't checked until it
compiles.

## Wrong

```templ
templ Hello(name string) {
	<p>Hello, { name }
}
```

## Right

```templ
templ Hello(name string) {
	<p>Hello, { name }</p>
}
```
