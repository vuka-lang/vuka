# E0139: An attribute the component's forward element can't take

What a component's tag passes on goes to its forward element
([Fallthrough](/ui/components#fallthrough)). Two things it can't take:

- `bind:value` when the forward element isn't a form control — an
  `input`, `select` or `textarea`: the binding writes the control's value
  and reads what is typed into it;
- an attribute the element sets in a way a caller's can't replace: its own
  event handler (`onClick={Toggle()}`), its `style`, its own `bind:value`
  or `value`, and what the compiler reads (`ref`, `for`, `model`). A
  plain attribute the element sets (`role="region"`) is the caller's to
  replace and isn't an error.

## Wrong

```html
<script lang="go">
package components

type Toggle struct {
	Label string
	on    ui.State[bool]
}
</script>

<button onClick={on = !on}>{Label}</button>
```

```html
<components.Toggle label="Dark mode" onClick={Save()} />
```

## Right

```html
<script lang="go">
package components

type Toggle struct {
	Label    string
	OnChange ui.Action
	on       ui.State[bool]
}
</script>

<button onClick={on = !on; OnChange}>{Label}</button>
```

```html
<components.Toggle label="Dark mode" onChange={Save()} />
```
