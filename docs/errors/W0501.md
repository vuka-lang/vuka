# W0501: A Count a later join can repeat

`orm.Count(col)` is SQL's `COUNT(col)`: it counts joined rows. A join after
the counted table that can match several rows — a relation holding many,
or a `Join` whose conditions don't pick its model by `ID` — repeats each
counted row once per match, and the count grows with it. `orm.Count(col,
orm.Distinct)` counts each value once. Reported by
[vukavet](/tools/vukavet).

## Wrong

```go
Author.Objects.
	Join(Post.On(Post.Author.Eq(Author.ID)), orm.Left).
	Join(Comment.On(Comment.Post.Eq(Post.ID)), orm.Left).
	Values[AuthorActivity](Author.Name, orm.Count(Post.ID), orm.Count(Comment.ID))
```

## Right

```go
Author.Objects.
	Join(Post.On(Post.Author.Eq(Author.ID)), orm.Left).
	Join(Comment.On(Comment.Post.Eq(Post.ID)), orm.Left).
	Values[AuthorActivity](Author.Name, orm.Count(Post.ID, orm.Distinct), orm.Count(Comment.ID))
```
