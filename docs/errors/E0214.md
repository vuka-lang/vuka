# E0214: Bad @export

`@export("Name")` adds a wrapper named `Name` for Go code to call (an
overload or a function with Vuka-only types). It goes on functions and
methods, and names an identifier other than the function's own.

## Wrong

```vuka
@export("area")
func area(r float64) float64 { … }
```

## Right

```vuka
@export("CircleArea")
func area(r float64) float64 { … }
```
