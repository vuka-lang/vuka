# W0115: model on a hidden input

A hidden input bound with `model` sends whatever the browser holds back to
the form, and the visitor can change it as easily as any visible field. For
a value the visitor must not choose, that is a hole:

```vuka
<form for={Form}>
  <input type="hidden" model={Form.OwnerID}/>
</form>
```

An id or an owner comes from the route or the session instead, and the form
leaves the field out:

```vuka
type OrderForm struct {
    ui.FormState
    Note    string
    OwnerID int `form:"-"`
}
```

and the submit handler sets `OwnerID` from the session. A file the visitor
picks is a `ui.File` field, which uploads it and checks its size and type.

## When it's fine

A hidden input whose value the page's own script writes — a key a script
gets back after staging an upload, a flag a script sets — carries nothing
the visitor couldn't send anyway, and the form checks it like any field.
`vuka vet` and the editor show the warning; builds don't.

This was the error [E0187](./E0187) for a short time on main; it is a
warning so that apps that compiled before keep compiling.
