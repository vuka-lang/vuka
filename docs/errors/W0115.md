# W0115: A struct live without saying so

A struct is live if it embeds `ui.Live`, declares a decorated hook, or its
markup sends one of its exported methods as an event. Only the first says so.
With the other two, one letter decides whether a page opens a socket and holds
server memory for every visitor: `onSubmit={Save}` is live and `onSubmit={save}`
isn't.

Embed `ui.Live` so the struct says it's live, and a search finds every live
part of an app. `vuka fix explicit-live` adds it everywhere, and nothing else
changes, because the compiler was adding it for you.

A future major version will make `ui.Live` the only way to be live.

## Wrong

```html
<script lang="go">
type Counter struct{ n int }

func (c *Counter) Inc() { c.n++ }
</script>

<button onClick={Inc}>{n}</button>
```

## Right

```html
<script lang="go">
type Counter struct {
	ui.Live
	n int
}

func (c *Counter) Inc() { c.n++ }
</script>

<button onClick={Inc}>{n}</button>
```

If the page needn't be live, make a form's handler unexported, and it posts
over HTTP:

```html
<script lang="go">
type SignIn struct{ Form Credentials }

func (p *SignIn) save(ctx context.Context, f Credentials) error { … }
</script>

<ui.Form for={Form} onSubmit={save}/>
```
