# E0198: A markup func's parameters don't fit

A markup func's parameters are a Go parameter list: each value it takes
named with its type, `func(o Order, i int)`. A list that doesn't parse, or
a name written without its type, `func(o)`, is this error: Go would read
the lone name as a type. See [Markup Funcs](/ui/templates#markup-funcs).

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

type Order struct{ Number string }

type Orders struct{ Open []Order }
</script>

row := func(o) { <li>{o.Number}</li> }

<ul>
  for _, o := range Open {
    {row(o)}
  }
</ul>
```

## Right

```html
<script lang="go">
package pages

type Order struct{ Number string }

type Orders struct{ Open []Order }
</script>

row := func(o Order) { <li>{o.Number}</li> }

<ul>
  for _, o := range Open {
    {row(o)}
  }
</ul>
```
