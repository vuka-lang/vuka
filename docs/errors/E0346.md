# E0346: A deferred method on a live page

`@ui.Defer` streams a part after a page that isn't live. A live page has
its own way to show itself first and fill in afterwards: it loads in its
`@ui.Mount` hook, renders, and pushes changes over its connection with
`Update` — a field marked `@ui.Defer("group")` loads after its first render.
A method of a live page marked `@ui.Defer` is refused.

Reported by the compiler, by [`vukavet`](/tools/vukavet) and at start-up.
See [Parts of a Page](/web/parts) and [Live Pages](/web/live).

## Wrong

```html
<script lang="go">
package pages

import (
	"context"

	"github.com/vuka-lang/ui/v2"
)

type Board struct {
	ui.Live
}

@ui.Defer
func (p *Board) Stats(ctx context.Context) (int, error) { return 3, nil }
</script>

<p>{Stats(ctx)} open</p>
```

## Right

```html
<script lang="go">
package pages

import (
	"context"

	"github.com/vuka-lang/ui/v2"
)

type Board struct {
	ui.Live
	open int
}

@ui.Mount
func (p *Board) mount(ctx context.Context) error {
	p.open = 3
	return nil
}
</script>

<p>{open} open</p>
```
