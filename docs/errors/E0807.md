# E0807: A GraphQL schema the specification refuses

Once every name is decided — the app's `graphql.Naming`, the attributes of
every package — the schema is checked as the GraphQL specification
requires before the app serves it: valid names, input and output types in
their places, enum values and fields of every type. The message lists each
problem. It is what is left after the compiler's checks, most often a name
an attribute or a `graphql.Naming` function gives that GraphQL doesn't
allow.

## Wrong

```go
// A naming convention producing names GraphQL can't take.
web.GraphQL("/graphql", graphql.Naming{Fields: strings.ToUpper})
```

## Right

```go
web.GraphQL("/graphql", graphql.Naming{Fields: graphql.SnakeCase})
```

See [Naming](/web/graphql#naming).
