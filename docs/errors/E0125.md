# E0125: ui.State used with the wrong type

A `ui.State[T]` is a value the browser keeps current. It goes to a prop
that takes a `ui.State` of the same `T`, and its operations need their kind
of state: `Toggle` a `ui.State[bool]`, `Inc` a number, `Set` a `T`. A key
can't read one.

## Wrong

```vuka
func Label(text bool) ui.Node { … }

open := ui.State(false)
return <Label text={!open} />
```

## Right

```vuka
func Label(text bool) ui.Node { … }

open := ui.State(false)
return <Label text={!open.Get()} />   // or: func Label(text ui.State[bool])
```
