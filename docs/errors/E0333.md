# E0333: An island page's Mount has the wrong signature

A stateless page backed by a component runs `Mount` on each request and
each call. It takes nothing or a `context.Context`; its dependencies are the
struct's injected fields. Reported at boot.

## Wrong

```vuka
func (o *Orders) Mount(ctx context.Context, db *DB) error { … }
```

## Right

```vuka
type Orders struct {
	Rows []Order
	db   *DB
}

func (o *Orders) Mount(ctx context.Context) (err error) {
	o.Rows, err = o.db.Orders(ctx)
	return err
}
```
