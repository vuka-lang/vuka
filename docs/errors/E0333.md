# E0333: An island page's Mount has the wrong signature

A stateless page backed by a component runs `Mount` on each request and
each call. It takes nothing or a `context.Context`; its dependencies are the
struct's injected fields. Reported at boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
func (o *Orders) Mount(ctx context.Context, db *DB) error { … }
```
:::

::: go
```go
func (o *Orders) Mount(ctx context.Context, db *DB) error { return nil }
```
:::

## Right

::: vuka
```vuka
type Orders struct {
	Rows []Order
	db   *DB
}

func (o *Orders) Mount(ctx context.Context) (err error) {
	o.Rows, err = o.db.Orders(ctx)
	return err
}
```
:::

::: go
```go
type Orders struct {
	Rows []Order
	db   *DB
}

func (o *Orders) Mount(ctx context.Context) (err error) {
	o.Rows, err = o.db.Orders(ctx)
	return err
}

func NewOrders(db *DB) *Orders { return &Orders{db: db} }

func init() { web.Routes.Get("/orders", NewOrders, ui.Island()) }
```
:::
