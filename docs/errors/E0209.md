# E0209: A decorator composes itself

A composed decorator lists other decorators; following the list leads back
to the decorator itself, so it would apply forever.

## Wrong

```vuka
decorator A = @logged @B
decorator B = @A
```

## Right

```vuka
decorator A = @logged @B
decorator B = @timed
```
