# E0104: The JSX target can't be used

The JSX target is imported in a way vuka can't render with: a blank import
(`_ "…"`) gives no name to call, or the target implements a newer JSX
contract than this vuka knows (update vuka), or an older one.

## Wrong

```vuka
import _ "github.com/vuka-lang/ui/v2"
```

## Right

```vuka
import "github.com/vuka-lang/ui/v2"
```
