# E0701: Two pages on one path

Two page types end up at the same path and method. A page's path is its
folder's and the kebab-case of its name (`Index` none), so `ResetPassword`
and a `reset-password/` folder's `Index` are both `/reset-password`; a
page and a method handler of another page on its path collide the same way.
Reported at the second page's type, naming the first.

## Wrong

```text
pages/account/
  reset_password.go          type ResetPassword — /account/reset-password
  reset-password/index.go    type Index         — /account/reset-password
```

## Right

```text
pages/account/
  reset-password/index.go    type Index — /account/reset-password
```
