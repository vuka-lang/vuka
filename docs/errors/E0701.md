# E0701: Two pages serve one path

A folder route's path comes from its folder and its type: `Index` serves the folder's own path, any other page adds its kebab-case name. Two pages, or two method handlers, ended up with the same method and path: a page `New` beside a folder `new/` holding an `Index`, for one.

## Wrong

```
pages/orgs/new.go        type New     → GET /orgs/new
pages/orgs/new/index.go  type Index   → GET /orgs/new
```

## Right

```
pages/orgs/new/index.go  type Index   → GET /orgs/new
```
