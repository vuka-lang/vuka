# E0002: Type error

The Go type checker refused an expression in a `.vuka` file. Vuka checks
the Go it generates with Go's own type checker and reports the error at the
place in your source, spelt as you wrote it. The message is Go's.

## Wrong

```vuka
func count(names []string) int {
	return len(names) + "1"
}
```

## Right

```vuka
func count(names []string) int {
	return len(names) + 1
}
```
