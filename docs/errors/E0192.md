# E0192: A func prop given a call that runs while the page renders

A call of one of the page's exported methods in an `on…` attribute is a
[push](/ui/events#calling-a-method), made when the event fires — but only
where the attribute takes a handler: an element's event, or a component's
prop of type `ui.Action`, `ui.JSChain` or [`ui.ActionOf[T]`](/ui/events#typed-handler-props).
A prop declared as a plain func takes a Go value, so `onRun={Run(t.Name)}`
would call `Run` while the page renders and hand its result to the prop.
The same holds inside a component: `onClick={OnRun(ctx, Name)}` on an
element calls the func field while the markup renders.

Declare the prop as an action, which takes the call as a push and is
called with its value inside the component, or pass the method itself.

Reported by the compiler.

## Wrong

```html
<script lang="go">
package components

import "context"

type Transitions struct {
	Names []string
	OnRun func(ctx context.Context, transition string) error
}
</script>

<ul>
  for _, n := range Names {
    <li><button onClick={OnRun(ctx, n)}>{n}</button></li>
  }
</ul>
```

## Right

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Transitions struct {
	Names []string
	OnRun ui.ActionOf[string]
}
</script>

<ul>
  for _, n := range Names {
    <li><button onClick={OnRun(n)}>{n}</button></li>
  }
</ul>
```

The page gives the method that runs the transition: `<components.Transitions
names={names} onRun={Run}/>`, with `func (p *Orders) Run(ctx
context.Context, transition string) error`.
