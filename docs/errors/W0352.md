# W0352: A Suspense on a live page waits for nothing

On a live page, `<ui.Suspense>` waits for the `@ui.Loads` groups of the
`@ui.Defer` fields its body reads. This boundary reads none, so there is
nothing to wait for: it renders at once and its `<slot:fallback>` never
shows.

## Wrong

```html
<ui.Suspense>
  <slot:fallback><ui.Skeleton lines={3}/></slot:fallback>
  <p>Figures</p>
</ui.Suspense>
<p>{len(tiles)} tiles</p>
```

## Right

```html
<ui.Suspense for={tiles}>
  <slot:fallback><ui.Skeleton lines={3}/></slot:fallback>
  <p>{len(tiles)} tiles</p>
</ui.Suspense>
```

See [Parts of a Page](/web/parts#suspense-live).
