# W0112: An on… handler in templ.Attributes binds no event

templ renders a `templ.Attributes` value by its type: strings, booleans and
numbers become attributes, and a function becomes nothing. A handler put in
one, `templ.Attributes{"onClick": Save}`, is dropped without a word, and
the click does nothing.

On a component whose props struct has an `Attributes templ.Attributes`
field (templUI's, shadcn-templ's), the tag binds handlers itself: write
`onClick={Save}` on the tag, or keep it in the tag's `attributes={…}`,
and it renders as the live event it is (see
[templ component libraries](/ui/templ#component-libraries)). The warning
is for a `templ.Attributes` literal that reaches templ another way: a
component's own parameter, or a props struct without that field. Reported
by the compiler: `vuka vet`, `vuka build` and the editor show it.

## Wrong

```html
<widget.Chip label="New" attrs={templ.Attributes{"onClick": Dismiss}} />
```

## Right

```html
<span onClick={Dismiss}><widget.Chip label="New" attrs={templ.Attributes{}} /></span>
<widget.Button onClick={Dismiss}>Dismiss</widget.Button>
```
