# E0411: A cron is wrong

A cron's spec is a cron expression (`0 7 * * 1-5`, with an optional
`CRON_TZ=…`) or `@every 10m`, and it decorates a function taking a
`context.Context` and provided types, returning nothing or an error.
Reported at boot.

## Wrong

```vuka
@web.Cron("every 10 minutes")
func cleanUp(ctx context.Context) {}
```

## Right

```vuka
@web.Cron("@every 10m")
func cleanUp(ctx context.Context) {}
```
