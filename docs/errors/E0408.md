# E0408: A type is provided twice

Two constructors (or values) provide the same type, so the container can't
choose. Both are named. Reported at boot.

## Wrong

```go
app := web.New(web.Provide(OpenDB, OpenTestDB))   // both return *DB
```

## Right

```go
app := web.New(web.Provide(OpenDB))
```
