# E0430: A CORS declaration that cannot work

`web.CORS(prefix, web.CORSConfig{…})` lets other origins call the routes
under a prefix. Build refuses a declaration a browser would never honour,
or one that would open more than it says:

- no `Origins`, or `web.AnyOrigin` together with other origins;
- an origin that isn't exactly what a browser sends in its `Origin`
  header: `scheme://host[:port]`, without a path or a trailing slash;
- a wildcard origin (`https://*.example.com`): origins match exactly;
- `null`, the origin any sandboxed frame or file sends;
- `Credentials` with `web.AnyOrigin`, which browsers refuse;
- `Credentials` under a `web.TokenOnly` prefix, whose cookies are taken
  off;
- a method `"*"`, a prefix that isn't a path, the same prefix twice.

See [CORS and Token APIs](/web/cross-origin).

Reported when the app is built.

## Wrong

```go
web.CORS("/api/", web.CORSConfig{
	Origins:     []string{web.AnyOrigin},
	Credentials: true,
})
```

## Right

```go
web.CORS("/api/", web.CORSConfig{
	Origins:     []string{"https://shop.example"},
	Credentials: true,
})
```
