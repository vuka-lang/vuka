# W0310: A form field has a placeholder and no label

A placeholder is an example of what goes in a field, and it disappears as
the visitor types; it is never the field's name. A field with a
`placeholder:` tag and no `label:` tag is labelled with its Go name in
words, which is rarely what the placeholder was standing in for: say what
the field is with `label:`.

## Wrong

```go
type Signup struct {
    ui.FormState
    Email string `placeholder:"Your work email"`
}
```

## Right

```go
type Signup struct {
    ui.FormState
    Email string `label:"Work email" placeholder:"name@company.com"`
}
```
