# E0704: A bracketed name names no path parameter

A folder or file whose name is in brackets is a path parameter, named by
what is inside: `[employer]` is `{employer}`, `[path...]` takes the rest of
the path. The name is a Go identifier, the whole name is bracketed, and a
path binds each parameter once: `[1st]`, `[a-b]`, `x[id]` and a `[org]`
below another `[org]` are each this error, at the folder or the file.

## Wrong

```text
pages/orgs/[org-id]/index.vuka.html
pages/orgs/[org]/members/[org].vuka.html
```

## Right

```text
pages/orgs/[org]/index.vuka.html
pages/orgs/[org]/members/[member].vuka.html
```
