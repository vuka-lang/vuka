# E0704: A Params struct doesn't fit its folder

A folder declaring `type Params struct` is the path parameter named after the folder. Its `Params` has exactly one field of its own, named like the folder, and embeds the `Params` of the nearest parameter folder above it, and nothing else; the folder's name is a Go identifier not bound above already.

## Wrong

```go
// pages/orgs/org/permits/permit/params.go
type Params struct {
	ID int
}
```

## Right

```go
// pages/orgs/org/permits/permit/params.go
type Params struct {
	org.Params
	Permit int
}
```
