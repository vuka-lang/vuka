# E0704: A parameter folder's Params is malformed

A folder's `Params` names the folder's one path parameter: it is a struct
with exactly one field of its own, named like the folder, case aside —
`employer/` has `Employer` (so the folder's name is a Go identifier). Below
another parameter folder it also embeds the nearest one's `Params`, and
embeds nothing else, so its pages get every parameter of their path. No
field of its own, two, a field of another name, a parameter already bound
above, a missing or foreign embedding: each is this error, at the field or
the type.

## Wrong

```go
// pages/employers/employer/params.go
package employer

type Params struct {
	ID   int
	Name string
}
```

```go
// pages/employers/employer/permits/permit/params.go
package permit

type Params struct {
	Permit int
}
```

## Right

```go
// pages/employers/employer/params.go
package employer

type Params struct {
	Employer int
}
```

```go
// pages/employers/employer/permits/permit/params.go
package permit

import "example.com/hr/pages/employers/employer"

type Params struct {
	employer.Params
	Permit int
}
```
