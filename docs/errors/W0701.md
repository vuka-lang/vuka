# W0701: No main package serves the folder routes

`pages/route.go` holds the module's folder routes as one option,
`pages.Routes()`, and registers them on the app given it. The module has
pages and a main package, and no main passes it to `web.New`, so none of
them is served. `vuka routes` and `vuka vet` report it.

## Wrong

```go
package main

import (
	_ "example.com/hr/pages"
	"github.com/vuka-lang/web"
)

func main() { web.New().Run("") }
```

## Right

```go
package main

import (
	"example.com/hr/pages"
	"github.com/vuka-lang/web"
)

func main() { web.New(pages.Routes()).Run("") }
```
