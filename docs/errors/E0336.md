# E0336: A LiveSchema hook that doesn't fit

`l.Mount`, `l.OnChange` and `l.Loads` take a method of the page (they
may be unexported). A hook can't be nil, a deferred group is a name, as
`ui.Defer` gives it, and a group has one loader. The app refuses the page
at start-up; [`vukavet`](/tools/vukavet) reports it from the source.

## Wrong

```go
func (d *Dashboard) LiveSchema(l *ui.LiveSchema) {
	l.Field(&d.Rows, ui.Defer("lists"))
	l.Loads("the lists", d.loadLists)
}
```

## Right

```go
func (d *Dashboard) LiveSchema(l *ui.LiveSchema) {
	l.Field(&d.Rows, ui.Defer("lists"))
	l.Loads("lists", d.loadLists)
}
```
