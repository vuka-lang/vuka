# E0336: A live page hook that doesn't fit

`l.Mount`, `l.OnChange` and `l.Loads` take a method of the page (they
may be unexported). A hook can't be nil, a deferred group is a name, as
`ui.Defer` gives it, and a group has one loader. The app refuses the page
at start-up; [`vukavet`](/tools/vukavet) reports it from the source.

A constructor declaring the hooks on the page's `ui.Live` —
`p.OnMount((*Page).mount)`, `p.Loads("rows", …)`, `p.OnChange(…)` — passes a
method expression of the page (`(*Page).mount`, not `p.mount`: the runtime
runs the hook on the page it holds) of an unexported method (the browser
calls the exported ones) whose signature fits the hook. The hooks
are the type's, so every constructor declares the same ones, and a hook is
declared in one place: the constructor or `LiveSchema`. The page reports a
mistake as it mounts.

## Wrong

```go
func (d *Dashboard) LiveSchema(l *ui.LiveSchema) {
	l.Field(&d.Rows, ui.Defer("lists"))
	l.Loads("the lists", d.loadLists)
}
```

## Right

```go
func (d *Dashboard) LiveSchema(l *ui.LiveSchema) {
	l.Field(&d.Rows, ui.Defer("lists"))
	l.Loads("lists", d.loadLists)
}
```

```go
func NewDashboard() *Dashboard {
	d := &Dashboard{}
	d.OnMount(d.mount) // E0336: a method value, not (*Dashboard).mount
	return d
}
```

```go
func NewDashboard() *Dashboard {
	d := &Dashboard{}
	d.OnMount((*Dashboard).mount)
	return d
}
```
