# E0804: A GraphQL name starting with __

The GraphQL specification reserves names starting with two underscores
for introspection (`__schema`, `__type`, `__typename`): no type, field,
argument or operation of a schema may take one.

## Wrong

```vuka
@graphql.Query("__version")
func Version() string { return build.Version }
```

## Right

```vuka
@graphql.Query("version")
func Version() string { return build.Version }
```

See [Naming](/web/graphql#naming).
