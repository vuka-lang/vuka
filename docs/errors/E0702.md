# E0702: Folder routes no router can tell apart

Two parameter folders sit side by side, or two folder routes match the same paths with neither more specific than the other (Go's ServeMux refuses such a pair): a request couldn't say which of them it names.

## Wrong

```
pages/orgs/org/params.go    type Params struct{ Org int }
pages/orgs/other/params.go  type Params struct{ Other int }
```

## Right

```
pages/orgs/org/params.go    type Params struct{ Org int }
pages/orgs/org/other/...
```
