# E0702: Two routes match the same paths

Two routes on one method match some of the same URLs and neither is more
specific, so no request could say which it means. A fixed segment beats a
parameter and a parameter a catch-all, so most overlaps resolve; these
don't. The usual cause is two sibling folders that both declare `Params`:
`/employers/{employer}` and `/employers/{name}` match every same URL.
Reported at the second route (or `params.go`), naming the first.

## Wrong

```text
pages/employers/
  employer/params.go     type Params struct{ Employer int }
  name/params.go         type Params struct{ Name string }
```

## Right

```text
pages/employers/
  employer/params.go         type Params struct{ Employer int }
  by-name/name/params.go     type Params struct{ Name string }   — /employers/by-name/{name}
```
