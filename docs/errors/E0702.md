# E0702: Two routes match the same paths

Two routes on one method match some of the same URLs and neither is more
specific, so no request could say which it means. A fixed segment beats a
parameter and a parameter a catch-all, so most overlaps resolve; these
don't. The usual cause is two parameters side by side, two bracketed
folders or files in one folder: `/employers/{employer}` and
`/employers/{name}` match every same URL. Reported at the second, naming
the first.

## Wrong

```text
pages/employers/
  [employer]/index.vuka.html
  [name].vuka.html
```

## Right

```text
pages/employers/
  [employer]/index.vuka.html          /employers/{employer}
  by-name/[name].vuka.html            /employers/by-name/{name}
```
