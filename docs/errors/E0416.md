# E0416: A .env file doesn't parse

A `.env` file is `KEY=value` lines, `#` comments, optional quotes and
`${VAR}` references. A line couldn't be read. The file and line are shown.
Reported at boot.

## Wrong

```sh
DATABASE_URL=postgres://${DB_HOST/pets
```

## Right

```sh
DATABASE_URL=postgres://${DB_HOST}/pets
```
