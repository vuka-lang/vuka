# E0332: @web.Get on a type without @ui.Island

`@web.Get` on a type serves the type's component, so the type must be an
island: `@ui.Island` (bare, or naming the file). A handler that writes the
page itself is a function.

## Wrong

```vuka
@web.Get("/orders")
type Orders struct{ Rows []Order }
```

## Right

```vuka
@web.Get("/orders")
@ui.Island
type Orders struct{ Rows []Order }
```
