# E0309: An island's attributes don't fit

An island tag's attributes are checked against the component's props (its
`@ui.Island` struct, or the props read from its file): an unknown
attribute, a value of the wrong type or outside a string union, or a
function prop given something other than a function.

## Wrong

```vuka
// Picker.vue: defineProps<{ title: string; kind: 'day' | 'week' }>()
<Picker titel="Dates" kind="month" />
```

## Right

```vuka
<Picker title="Dates" kind="week" />
```
