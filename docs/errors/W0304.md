# W0304: A page built without the constructor that declares its hooks

The type's hooks are declared by its constructor (`p.OnMount((*Page).mount)`),
and this literal builds one without it. The hooks are the type's, set by the
first constructor that runs, so this value has them only once a constructor
ran somewhere: a routed page always has, a component a template places as
`<Counter …/>` (`&Counter{…}`) may not. Build it with the constructor, or
declare the hooks in `LiveSchema`, which needs none. Tests aren't reported.
Reported by [`vukavet`](/tools/vukavet).

## Wrong

```go
func NewCounter() *Counter {
	c := &Counter{}
	c.OnMount((*Counter).mount)
	return c
}

var start = &Counter{N: 1}
```

## Right

```go
func (c *Counter) LiveSchema(l *ui.LiveSchema) { l.Mount(c.mount) }

var start = &Counter{N: 1}
```
