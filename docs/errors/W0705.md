# W0705: A query field urls can't name

A page whose component keeps fields in the query with `@ui.URL("name")`
gets a struct in `urls` with a field for each, and its `URL` takes it. A
field's type must be one `urls` can write: a type `@ui.URL` keeps (a
string, a number, a bool, a type with `UnmarshalText`, or a slice or
pointer of one), declared where `urls` can import it. A type declared in a
page package, an unexported one, and one of a package that imports `urls`
can't be. The field is left out of the struct, and the page still reads its
parameter from the URL as always. Reported at the field.

## Wrong

```html
<script lang="go">
// pages/adverts/view.vuka.html
package adverts

type Sort string // declared in a page package

type View struct {
	ui.Live
	Sort Sort @ui.URL("sort")
}
</script>
```

## Right

Declare the type outside `pages/`:

```go
// package listing
type Sort string
```
