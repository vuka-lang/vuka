# W0705: A pushed method that also answers an HTTP method

`Post`, `Put`, `Patch` and `Delete` on a page answer those HTTP methods on its
path. A [push](/ui/js#push) naming one calls it from the page as well, and the
app has a route you may not have meant to add: anyone can send `DELETE` to the
page's URL, without the signed step a push carries.

Rename the method, unless you mean it to answer both. A method a page's markup
sends as an event, rather than a push, is [E0709](/errors/E0709).

## Wrong

```html
<script lang="go">
type Index struct{}

func (p *Index) Delete(ctx context.Context) error { … }
</script>

<button onClick={ui.JS.Push(p.Delete)}>Remove</button>
```

## Right

```html
<script lang="go">
type Index struct{}

func (p *Index) Remove(ctx context.Context) error { … }
</script>

<button onClick={ui.JS.Push(p.Remove)}>Remove</button>
```
