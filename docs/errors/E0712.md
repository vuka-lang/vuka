# E0712: The fields binding a path parameter disagree on its type

Every struct below a bracketed folder may bind its parameter with a field
of its name, and those fields are one type: the URL has one segment, and
`urls` writes it one way. The folder's `_layout.vuka.html` speaks first;
otherwise the first field found does. Reported at a field of another type,
naming the first.

## Wrong

```text
pages/orgs/[org]/_layout.vuka.html    type Layout struct{ Org int; Children ui.Node }
pages/orgs/[org]/edit.vuka.html       type Edit struct{ Org string }
```

## Right

```text
pages/orgs/[org]/_layout.vuka.html    type Layout struct{ Org int; Children ui.Node }
pages/orgs/[org]/edit.vuka.html       type Edit struct{ Org int }
```
