# E0711: Nothing binds a path parameter

A bracketed folder or file names a parameter, and its type comes from the
fields that bind it: the exported field of its name, case aside, of the
page, endpoint, guard or layout below it (`ID int64` for `[id]`), or a
method func's parameter of its name. None of them has one, so the
parameter has no type, and `urls` can't write it. A page at a parameter
file, `[id].vuka.html`, declares its struct above its markup for the same
reason. Reported at the folder or the file.

## Wrong

```html
<!-- pages/pets/[id].vuka.html -->
<script lang="go">
package pets
</script>

<h1>A pet</h1>
```

## Right

```html
<!-- pages/pets/[id].vuka.html -->
<script lang="go">
package pets

type Pet struct {
	ID int64 `validate:"min=1"`
}
</script>

<h1>Pet {ID}</h1>
```
