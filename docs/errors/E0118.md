# E0118: Static initialization cycle

Statics are initialized in dependency order. These depend on each other
(directly, or through the functions and methods their values call), so no
order works.

## Wrong

```vuka
type Post struct {
	static A = Post.B + 1
	static B = Post.A * 2
}
```

## Right

```vuka
type Post struct {
	static A = 1
	static B = Post.A * 2
}
```
