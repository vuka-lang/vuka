# E0003: Syntax error

The file isn't valid Go once vuka's own constructs are rewritten: a brace,
parenthesis or keyword is missing or misplaced. The position is in your
source.

## Wrong

```vuka
func greet(name string) string {
	return "hello " + name
```

## Right

```vuka
func greet(name string) string {
	return "hello " + name
}
```
