# E0003: Syntax error

The file isn't valid Go once vuka's own constructs are rewritten: a brace,
parenthesis or keyword is missing or misplaced. The position is in your
source.

## Wrong

```vuka
func greet(name string) string {
	return "hello " + name
```

## Right

```vuka
func greet(name string) string {
	return "hello " + name
}
```

Each top-level declaration is read on its own, so a broken one is one
error and the declarations after it are checked as written: a function
missing its `}` doesn't make every declaration below it an error too.

## An import without a path

An `import` with no quoted path after it — a leftover `import`, `import
orm`, a path missing its closing quote, or an `import (` block without its
`)` — is one error at the `import`. When the file uses a package it no
longer imports (`orm.Base`, `@orm.PK`), the help names the import to add:
the path the package's other files import that name by, else the standard
library's, else the toolchain package of a module `go.mod` requires.

```vuka
package shop

import

type Product struct {
	orm.Base @orm.Meta{Table: "products"}
	ID int64 @orm.PK
}
```

```text
error[E0003]: import has no path
 --> shop/product.vuka:3:1
  |
3 | import
  | ^^^^^^
  |
  = help: add the path: import "github.com/vuka-lang/orm/v2" (the file uses orm)
```

The packages that import one with a syntax error don't build either; a
build counts them in its last line rather than reporting what they can't
find in it ([When a Build Fails](/tools/cli#build-errors)).
