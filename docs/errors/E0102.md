# E0102: JSX needs a target

JSX renders through a target package: the one that declares `VukaJSX`,
usually `github.com/vuka-lang/ui`. The file has JSX and imports no target,
or the target it imports doesn't load.

## Wrong

```vuka
package pages

func Hello() ui.Node {
	return <p>Hello</p>
}
```

## Right

```vuka
package pages

import "github.com/vuka-lang/ui"

func Hello() ui.Node {
	return <p>Hello</p>
}
```
