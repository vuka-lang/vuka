# E0418: @web.Service or @web.Controller on a non-struct

`@web.Service` and `@web.Controller` declare a type the container
constructs and injects into: a struct, whose fields are its dependencies.
In Go, `web.Routes.Service` and `Controller` take its constructor, a
`func(deps…) *T` or `(*T, error)` with `T` a struct.
Reported at boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
@web.Service
type Names []string
```
:::

::: go
```go
type Names []string

func NewNames() Names { return Names{"ada"} }

func init() { web.Routes.Service(NewNames) }
```
:::

## Right

::: vuka
```vuka
@web.Service
type Names struct {
	list []string `inject:"-"`
}
```
:::

::: go
```go
type Names struct{ list []string }

func NewNames() *Names { return &Names{list: []string{"ada"}} }

func init() { web.Routes.Service(NewNames) }
```
:::
