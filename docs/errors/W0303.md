# W0303: A live page hook found by its name

`Mount`, `Changed` and `Load<Group>` are found by their names in earlier
releases. They still work for one minor release; a hook attribute says
which hook a method is, lets it be unexported (so the browser can't call
it) and checks its signature. `vuka fix hooks` adds the attributes.
Reported by `vuka vet`.

## Wrong

```vuka
func (o *Orders) Mount(ctx context.Context) error { … }
func (o *Orders) LoadLists(ctx context.Context) error { … }
```

## Right

```vuka
@ui.Mount
func (o *Orders) mount(ctx context.Context) error { … }

@ui.Loads("lists")
func (o *Orders) loadLists(ctx context.Context) error { … }
```
