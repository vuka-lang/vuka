# W0303: A live page loader found by its name

`Load<Group>` is found by its name in earlier releases. It still works for
one minor release; a group's name in the method can drift from its
`@ui.Defer` attribute, and `@ui.Loads` says which group a method loads, lets
it be unexported (so the browser can't call it) and checks its signature.
`vuka fix hooks` adds the attributes. Reported by `vuka vet`.

`Mount` and `Changed` found by their names are ordinary hooks and aren't
reported: the browser can't call them, and their signatures are checked
(E0329, E0327).

## Wrong

```vuka
func (o *Orders) LoadLists(ctx context.Context) error { … }
```

## Right

```vuka
@ui.Loads("lists")
func (o *Orders) loadLists(ctx context.Context) error { … }
```
