# E0713: A parameter is both a file and a folder

`[id].vuka.html` is the page at `/pets/{id}`, and a `[id]/` folder beside
it is that segment's folder, holding its layout, its pages and its
endpoints: two places for one segment. A segment with a folder keeps its
page in the folder, as its `index`. Reported at the file, naming the
folder.

## Wrong

```text
pages/pets/
  [id].vuka.html
  [id]/edit.vuka.html
```

## Right

```text
pages/pets/[id]/
  index.vuka.html      /pets/{id}
  edit.vuka.html       /pets/{id}/edit
```
