# E0360: A viewport event on an element that isn't a stream's container

`onViewportTop` and `onViewportBottom` fire when a stream container's
first or last row comes into view, and send that row's key: the edge the
browser holds, which the server doesn't track. Only a stream's container —
the element whose only content is the loop over the stream's `Rows()` — has
edge rows, so on any other element the event would never fire. Reported by
the compiler, `vuka vet` and the editor.

## Wrong

```html
<section onViewportBottom={Newer}>
  <ul>
    for _, m := range messages.Rows() {
      <li key={m.ID}>{m.Text}</li>
    }
  </ul>
</section>
```

## Right

```html
<section>
  <ul onViewportBottom={Newer}>
    for _, m := range messages.Rows() {
      <li key={m.ID}>{m.Text}</li>
    }
  </ul>
</section>
```
