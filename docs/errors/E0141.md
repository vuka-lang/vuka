# E0141: A template has two scripts or two scoped stylesheets

The `<script lang="ts">` after a template's markup is its component's
script, and the `<style scoped>` its stylesheet: one of each per template.
This one has two of a kind.

## Wrong

```html
<div class="chart"></div>

<script lang="ts">
export default component<Chart>((el) => { … })
</script>

<script lang="ts">
export default component<Chart>((el) => { … })
</script>
```

## Right

```html
<div class="chart"></div>

<script lang="ts">
export default component<Chart>((el) => { …; … })
</script>
```
