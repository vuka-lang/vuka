# E0604: An asset declaration can't be read

`web.Style`, `web.Script`, `web.CSS` and `web.JS` are read from the source
by the vuka command, so they take string literals, and they belong to a
page: an argument of `@web.Live`, `web.Layout`, `web.LiveLayout` or
`web.New`.

## Wrong

```vuka
var sheet = "app.css"

@web.Live("/", web.Style(sheet))
type Home struct{ ui.Live }
```

## Right

```vuka
@web.Live("/", web.Style("app.css"))
type Home struct{ ui.Live }
```
