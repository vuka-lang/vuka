# E0308: Bad hydration directive

An island takes one `client:*` directive saying when it hydrates:
`client:load`, `client:idle`, `client:visible` or `client:media={"query"}`.

## Wrong

```vuka
<Chart series={p.sales} client:soon client:load />
```

## Right

```vuka
<Chart series={p.sales} client:visible />
```
