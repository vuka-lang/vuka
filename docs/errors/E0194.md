# E0194: An action called outside an event, or with a value it does not take

A component's [`ui.ActionOf[T]`](/ui/events#typed-handler-props) prop runs
when an event fires: called in an element's `on…` attribute,
`onClick={OnSelect(o)}`, it is the push of the handler the prop holds, given
`o`. It takes one value, a `T`, which may be an element's read such as
`this.value`. Anywhere else — a hole, a non-event attribute, the
component's Go — there is no event to run it, and the call is an error.

A `ui.Action` takes no value: it is what the event does, forwarded as it
is, `onClick={On}`.

Reported by the compiler.

## Wrong

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

// Order is declared in order.go, beside this file.
type OrderTable struct {
	Orders   []Order
	OnSelect ui.ActionOf[Order]
	On       ui.Action
}
</script>

<table>
  for _, o := range Orders {
    <tr onClick={OnSelect(o.ID)}>
      <td>{o.Number}</td>
      <td><button onClick={On()}>Refresh</button></td>
    </tr>
  }
</table>
```

## Right

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

// Order is declared in order.go, beside this file.
type OrderTable struct {
	Orders   []Order
	OnSelect ui.ActionOf[Order]
	On       ui.Action
}
</script>

<table>
  for _, o := range Orders {
    <tr onClick={OnSelect(o)}>
      <td>{o.Number}</td>
      <td><button onClick={On}>Refresh</button></td>
    </tr>
  }
</table>
```
