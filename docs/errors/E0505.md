# E0505: Values columns that don't fit the struct

Given typed columns — fields, aggregates, expressions — `Values[R]` fills
`R`'s fields by position: the first column into the first field, and so on.
A struct with more or fewer fields than columns, or a column of text read
into a number (or a number into text, or a time into either), can't be
filled. Reported by the query when it is built and by
[vukavet](/tools/vukavet).

## Wrong

```go
type CategoryProducts struct {
	ID    int64
	Name  string
	Count int64
}

Category.Objects.Values[CategoryProducts](Category.Name, Category.ID)
```

## Right

```go
Category.Objects.
	Join(Category.Links, orm.Left).
	Values[CategoryProducts](Category.ID, Category.Name, orm.Count(ProductCategory.ID))
```
