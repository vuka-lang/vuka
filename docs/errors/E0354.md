# E0354: A stream's Rows read outside its loop

A [stream](/web/streams)'s `Rows()` is the rows queued since the last
reply — what the next render sends — not what the browser shows: after an
`Insert` it holds one row, after a reply none. Read anywhere but its
container's loop (in markup, a method, a hook) it says nothing about the
list. Counts come from where the records are, kept in fields beside the
stream and changed by the same code that changes the records; what only the
browser knows the container's `data-vk-rows` and `data-vk-empty` say.
Reported by the compiler, `vuka vet` and the editor.

## Wrong

```html
<p>{len(messages.Rows())} messages</p>
```

## Right

```html
<p>{total} messages</p>
```

with `total` a field the mount hook and the `Update` inserting a message
set.
