# E0176: A ui.Derived declared wrong

A [`ui.Derived`](/ui/state#derived) field is a value the browser computes
from the struct's states. Its `@ui.From(…)` says from what: an expression
markup could bind, reading the states by their bare names, other Derived
fields and constants. Reported by the compiler:

- a `ui.Derived` field without a `@ui.From`, or with two;
- a `@ui.From` on a field that isn't a `ui.Derived`;
- a `@ui.From` reading no state: a value that never changes is a constant;
- a `@ui.From` reading a prop or server state, which the browser doesn't
  keep: compare with it in the markup instead;
- a name that is no field of the struct and no name of the package (the
  message suggests the nearest field);
- Derived fields reading each other in a cycle: the message names the
  path, `a → b → a`;
- a `@ui.From` on a struct with type parameters.

An operator the browser can't run (`/`, a call) is
[E0124](/errors/E0124), and writing a Derived is
[E0177](/errors/E0177).

## Wrong

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Cart struct {
	Limit int
	count ui.State[int]
	price ui.State[int]
	total ui.Derived[int]
	over  ui.Derived[bool] @ui.From(total > Limit)
}
</script>

<p>{total}</p>
```

## Right

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Cart struct {
	Limit int
	count ui.State[int]
	price ui.State[int]
	total ui.Derived[int] @ui.From(count * price)
}
</script>

<p class:over={total > Limit}>{total}</p>
```
