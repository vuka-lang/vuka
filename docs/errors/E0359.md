# E0359: A live component in a stream row

A live component's instance — its state, its last render — is held by the
session for as long as it is rendered. In a [stream](/web/streams)'s row
that is for every row ever shown, since the server doesn't see the browser
trim: what a stream exists to avoid. Render a stateless shape in the row
instead, and do per-row server work in the owner's methods, pushed with
the row's key; per-row state belongs in the record or in the browser
(`ui.State`). Reported by the compiler, `vuka vet` and the editor, and when
a row renders one.

## Wrong

```html
<ul>
  for _, u := range users.Rows() {
    <UserRow key={u.ID} user={u} />
  }
</ul>
```

## Right

```html
<ul>
  for _, u := range users.Rows() {
    <li key={u.ID}>
      <UserCard user={u} />
      <button onClick={ui.JS.Push(Disable, u.ID)}>Disable</button>
    </li>
  }
</ul>
```

with `UserCard` a stateless shape and `Disable` a method of the page.
