# E0114: Unreachable case

Cases are tried in order, and the earlier ones already match everything
this one does, so it never runs.

## Wrong

```vuka
match o {
case _:
	return 0
case Some(x):
	return x
}
```

## Right

```vuka
match o {
case Some(x):
	return x
case _:
	return 0
}
```
