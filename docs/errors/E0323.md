# E0323: Bad defer: tag

`defer:` leaves a field out of the first render; the loader of its group
(`Load<Group>`) sends it after. A group is a Go name (`defer:"stats"` is
loaded by `LoadStats`; `defer:""` is a group of the field alone). A deferred
field is the server's to load, so the component can't set it (`bind:`) and
the URL can't fill it (`url:`). Reported by `vuka vet`, the editor, and at
boot.

## Wrong

```vuka
type Dashboard struct {
	ui.Live
	Stats []Stat `defer:"the stats"`
	Q     string `bind:"q" defer:""`
}
```

## Right

```vuka
type Dashboard struct {
	ui.Live
	Stats []Stat `defer:"stats"`
	Q     string `bind:"q"`
}

func (d *Dashboard) LoadStats(ctx context.Context) error { … }
```
