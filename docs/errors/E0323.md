# E0323: Bad defer: tag

`defer:` (in Go, `ui.Defer` in the page's `LiveSchema`) leaves a field out
of the first render; the loader of its group (`Load<Group>`, or `l.Loads`)
sends it after. A group is a Go name (`defer:"stats"` is
loaded by `LoadStats`; `defer:""` is a group of the field alone). A deferred
field is the server's to load, so the component can't set it (`bind:`) and
the URL can't fill it (`url:`). Reported by `vuka vet`, the editor, and at
boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
type Dashboard struct {
	ui.Live
	Stats []Stat `defer:"the stats"`
	Q     string `bind:"q" defer:""`
}
```
:::

::: go
```go
type Dashboard struct {
	ui.Live
	Stats []Stat
	Q     string
}

func (d *Dashboard) LiveSchema(l *ui.LiveSchema) {
	l.Field(&d.Stats, ui.Defer("the stats"))
	l.Field(&d.Q, ui.Bind{}, ui.Defer("q"))
}
```
:::

## Right

::: vuka
```vuka
type Dashboard struct {
	ui.Live
	Stats []Stat `defer:"stats"`
	Q     string `bind:"q"`
}

func (d *Dashboard) LoadStats(ctx context.Context) error { … }
```
:::

::: go
```go
type Dashboard struct {
	ui.Live
	Stats []Stat
	Q     string
}

func (d *Dashboard) LiveSchema(l *ui.LiveSchema) {
	l.Field(&d.Stats, ui.Defer("stats"))
	l.Loads("stats", d.loadStats)
	l.Field(&d.Q, ui.Bind{})
}

func (d *Dashboard) loadStats(ctx context.Context) error { return nil }
```
:::
