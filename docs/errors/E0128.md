# E0128: A value doesn't fit its template hole

A `ui.Template` hole takes what its place allows: a child takes nodes, text
and components; text in `title`, `textarea` and `script` takes a string or
number; an attribute's value what a JSX attribute takes (an `on…` attribute a
handler, `class` a `ui.Class`, `style` a `ui.Style`); part of a value a
string or number; and a hole where an attribute goes a `ui.Attr`,
`[]ui.Attr` or `templ.Attributes`. The value's type can't fill its hole, so
the render fails. Reported by [vukavet](/tools/vukavet) where the type is
known, and when the template renders.

## Wrong

```go
var field = ui.Template(`<input class="{{0}}" onInput="{{1}}"/>`)

func Field(attrs []ui.Attr, onInput func(string)) ui.Node {
	return field.Render(attrs, "update()")
}
```

## Right

```go
var field = ui.Template(`<input class="input" {{0}} onInput="{{1}}"/>`)

func Field(attrs []ui.Attr, onInput func(string)) ui.Node {
	return field.Render(attrs, onInput)
}
```
