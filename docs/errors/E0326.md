# E0326: Two handles share a name

A page backed by a component gives its component one handle per exported
field (its json name, first letter lower-cased: `Q` → `live.q`) and per
callable method (`Cancel` → `live.cancel`). Two fields, or a field and a
method, would have the same handle. Reported by `vuka vet`, the editor, and
at boot, and by
[vukavet](/tools/vukavet).

## Wrong

```vuka
type Orders struct {
	ui.Live
	Cancel bool
}

func (o *Orders) Cancel(ctx context.Context, id int64) error { … }
```

## Right

```vuka
type Orders struct {
	ui.Live
	CanCancel bool
}

func (o *Orders) Cancel(ctx context.Context, id int64) error { … }
```
