# E0353: A stream's loop isn't its container's only content

A [stream](/web/streams)'s rows are rendered by a loop over its `Rows()`
that is the only content of an element, the container. The browser owns
the container's children — it keeps the rows the server forgot — so
anything rendered beside the rows would be lost or duplicated. The loop
can't sit beside other markup, in a fragment or a component's children, or
inside another loop (each iteration would be a container of its own), and
a stream has one loop. Reported by the compiler, `vuka vet` and the editor.

## Wrong

```html
<ul>
  <li class="head">Messages</li>
  for _, m := range messages.Rows() {
    <li key={m.ID}>{m.Text}</li>
  }
</ul>
```

## Right

```html
<h3>Messages</h3>
<ul>
  for _, m := range messages.Rows() {
    <li key={m.ID}>{m.Text}</li>
  }
</ul>
```
