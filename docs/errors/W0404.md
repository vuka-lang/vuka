# W0404: A static file linked by hand

An attribute of the markup (`src`, `href`, `srcset`, `poster`, `data`)
names a file under an `app.Static` mount by its path. Written with
`web.Asset`, the path is checked at build time ([E0429](/errors/E0429)) and,
in a binary `vuka build` made, becomes the file's content-hashed name,
cached by the browser for good instead of revalidated on every page view.

The editor's quick fix rewrites one attribute; `vuka fix static-paths`
rewrites a whole module.

See [Static Files](/web/static-files).

Reported by `vuka vet` and the editor.

## Wrong

```html
<img src="/static/images/logo.png" alt="Logo" />
```

## Right

```html
<img src={web.Asset("/static/images/logo.png")} alt="Logo" />
```
