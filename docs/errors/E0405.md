# E0405: A handler parameter can't be bound

A handler's parameters are bound by name: scalars from the path or query,
one struct from the request body or form, `*http.Request`,
`context.Context`, and provided types from the container. This parameter is
none of them: a scalar without a name (plain Go: name it with `web.Params`),
a second struct, or a type nothing provides. Reported at boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
@web.Post("/pets")
func AddPet(p Pet, owner Owner) Result[Pet] { … }
```
:::

::: go
```go
func ShowPet(id int, store *PetStore) (Pet, error) { return store.Find(id) }

func init() {
	web.Routes.Get("/pets/{id}", ShowPet) // id has no name: reflection can't see it
}
```
:::

## Right

::: vuka
```vuka
@web.Post("/pets")
func AddPet(p Pet, owners *Owners) Result[Pet] { … }
```
:::

::: go
```go
func ShowPet(id int, store *PetStore) (Pet, error) { return store.Find(id) }

func init() {
	web.Routes.Get("/pets/{id}", ShowPet, web.Params("id", ""))
}
```
:::
