# E0127: Render doesn't fill a template's holes

A `ui.Template` has holes `{{0}}`, `{{1}}`, … and `Render` takes one value
for each, in order. It is given more or fewer, so the render fails with the
template's place and nothing is shown. Reported by
[vukavet](/tools/vukavet), and when the template renders.

## Wrong

```go
var orderRow = ui.Template(`<tr><td>{{0}}</td><td>{{1}}</td></tr>`)

func OrderRow(o Order) ui.Node {
	return orderRow.Render(o.Ref)
}
```

## Right

```go
var orderRow = ui.Template(`<tr><td>{{0}}</td><td>{{1}}</td></tr>`)

func OrderRow(o Order) ui.Node {
	return orderRow.Render(o.Ref, money(o.Total))
}
```
