# W0307: Two components keeping one URL parameter

A component's field marked `@ui.URL("page")` is kept in the page's
`?page=` parameter. Two instances of it on one page keep the same
parameter: each fills from the other's value, and an event in one writes
over the other's. A `urlKey` on a tag keeps that instance's parameters
under a name of its own, `?requests.page=`. Reported by
[`vukavet`](/tools/vukavet) for the components one markup renders, by
type, with or without the same `urlKey`.

## Wrong

```html
<main>
  <Table title="Requests" />
  <Table title="Users" />
</main>
```

## Right

```html
<main>
  <Table title="Requests" urlKey="requests" />
  <Table title="Users" urlKey="users" />
</main>
```
