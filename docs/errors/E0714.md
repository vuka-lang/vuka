# E0714: A Params struct makes no parameter folder

In vuka 1 a folder declaring `type Params struct` was a path parameter,
and its pages embedded `Params`. A parameter is a bracketed name now:
`[employer]/` is `{employer}`, and its type is the field of its name on the
structs that read it. A `Params` in a pages package binds nothing, so it is
this error, at the type.

## Wrong

```go
// pages/employers/employer/params.go
package employer

type Params struct {
	Employer int
}
```

## Right

```html
<!-- pages/employers/[employer]/index.vuka.html -->
package employer

type Index struct {
	Employer int
}
<h1>Employer {Employer}</h1>
```
