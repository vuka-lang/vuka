# E0345: Two timing attributes on one method

A timing attribute says when a method runs: `@ui.Defer` after the page's
first bytes. One method has one: two — `@ui.Defer` and `@ui.Defer("lists")`
— say two things, and the second is reported. Keep the one you mean.

Reported by the compiler, by [`vukavet`](/tools/vukavet) and at start-up
(`vuka.RegisterFunc((*Index).Stats, ui.Defer(""), ui.Defer("lists"))`). See
[Parts of a Page](/web/parts).

## Wrong

```vuka
@ui.Defer
@ui.Defer("lists")
func (p *Index) Recent(ctx context.Context) ([]string, error) { … }
```

## Right

```vuka
@ui.Defer("lists")
func (p *Index) Recent(ctx context.Context) ([]string, error) { … }
```
