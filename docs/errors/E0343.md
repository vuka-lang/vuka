# E0343: A deferred method called from Go

A deferred method runs after the page is sent, its result going to its
part. Go that calls it — another method, a hook, a handler, a statement in
the markup — needs the result now, before the page is sent, which is what
`@ui.Defer` says it isn't. Call it from the markup only: its holes, its
attributes, its blocks' headers.

To use the result in Go too, don't defer the method; or move what reads it
into the markup, where it becomes part of the part. Reported by the
compiler, and by [`vukavet`](/tools/vukavet) for a direct call in Go. See
[Parts of a Page](/web/parts).

## Wrong

```html
<script lang="go">
package pages

import "context"

type Index struct{}

@ui.Defer
func (p *Index) Stats(ctx context.Context) (int, error) { return 3, nil }

func (p *Index) Summary(ctx context.Context) string {
	n, _ := p.Stats(ctx)
	return fmt.Sprint(n, " open")
}
</script>

<p>{Summary(ctx)}</p>
```

## Right

```html
<script lang="go">
package pages

import "context"

type Index struct{}

@ui.Defer
func (p *Index) Stats(ctx context.Context) (int, error) { return 3, nil }
</script>

<p>{Stats(ctx)} open</p>
```
