# E0329: Bad ui.Live embedding or Mount

A live view embeds `ui.Live` by value (not `*ui.Live`), and its `Mount`, if
it has one, takes nothing or a `context.Context` (its dependencies are the
struct's injected fields) and returns nothing or an error. Reported at boot, and by
[vukavet](/tools/vukavet).

## Wrong

```vuka
type Counter struct {
	*ui.Live
	n int
}

func (c *Counter) Mount(start int) {}
```

## Right

```vuka
type Counter struct {
	ui.Live
	n int
}

func (c *Counter) Mount(ctx context.Context) error { c.n = 1; return nil }
```
