# E0329: Bad ui.Live embedding

A live view embeds `ui.Live` by value, not `*ui.Live`: the session attaches
its instance to the embedded value. A route registering a live page takes
its constructor, a function returning a pointer to the page's struct.
Reported at boot, and by [vukavet](/tools/vukavet).

## Wrong

```vuka
type Counter struct {
	*ui.Live
	n int
}
```

## Right

```vuka
type Counter struct {
	ui.Live
	n int
}
```
