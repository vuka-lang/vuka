# E0325: Loading names a group the component doesn't defer

`Loading("group")`, `LoadErr("group")` and `<ui.Await key="group">` read
the state of one of the
component's [deferred groups](/ui/stateful#deferred-fields): the group a
field marked `@ui.Defer("group")` loads in. The component defers no field
to the group named, so it would never load — a misspelt name, or a field
whose `@ui.Defer` names another group. The compiler reports a
`<ui.Await>` whose key names such a group, with the nearest group the
component defers; one it can't check, in `Loading` or `key={name}`, fails
the render with the message. A group's name is matched as `@ui.Loads` matches it: `"stats"` and
`"Stats"` are one group.

## Wrong

```vuka
type Dashboard struct {
	ui.Live
	stats Stats @ui.Defer("stats")
}

@ui.Loads("stats")
func (d *Dashboard) loadStats(ctx context.Context) error { … }
```

```html
<ui.Await key="stat">
  <Tiles stats={stats} />
</ui.Await>
```

## Right

```html
<ui.Await key="stats">
  <Tiles stats={stats} />
</ui.Await>
```
