# E0325: A loader has the wrong signature

A deferred group's loader takes nothing or a `context.Context` and returns
nothing or an `error`; it fills the group's fields on the page. Its other
dependencies are the struct's injected fields. Reported by `vuka vet`, the
editor, and at boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
func (d *Dashboard) LoadStats(ctx context.Context, db *DB) ([]Stat, error) { … }
```
:::

::: go
```go
// In Go, l.Loads takes a func(ctx context.Context) error, so the compiler
// refuses a loader of another shape:
func (d *Dashboard) LiveSchema(l *ui.LiveSchema) {
	l.Loads("stats", d.loadStats) // loadStats(ctx, db *DB) ([]Stat, error)
}
```
:::

## Right

::: vuka
```vuka
type Dashboard struct {
	ui.Live
	Stats []Stat `defer:"stats"`
	db    *DB
}

func (d *Dashboard) LoadStats(ctx context.Context) (err error) {
	d.Stats, err = d.db.Stats(ctx)
	return err
}
```
:::

::: go
```go
type Dashboard struct {
	ui.Live
	Stats []Stat
	db    *DB
}

func (d *Dashboard) LiveSchema(l *ui.LiveSchema) {
	l.Field(&d.Stats, ui.Defer("stats"))
	l.Loads("stats", d.loadStats)
}

func (d *Dashboard) loadStats(ctx context.Context) (err error) {
	d.Stats, err = d.db.Stats(ctx)
	return err
}
```
:::
