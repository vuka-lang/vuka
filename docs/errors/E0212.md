# E0212: Decorated init

`init` takes no arguments and returns nothing, so the only decorator that
fits it is a function of type `func(func()) func()`.

## Wrong

```vuka
decorator logged(c) { c.Next() }

@logged
func init() {}
```

## Right

```vuka
func once(f func()) func() { return f }

@once
func init() {}
```
