# E0321: Bad ui.Layout

`ui.Layout(…)` in `@ui.Island` is the layout of the page the type backs. A
layout is a `func(page ui.Node) ui.Node`, or a `func(ctx context.Context,
page ui.Node) ui.Node` that reads the request. Reported at boot.

## Wrong

```vuka
func Page(title string) ui.Node { … }

@ui.Island(ui.Layout(layouts.Page))
type Orders struct{ ui.Live }
```

## Right

```vuka
func Page(title string) func(page ui.Node) ui.Node { … }

@ui.Island(ui.Layout(layouts.Page("Orders")))
type Orders struct{ ui.Live }
```
