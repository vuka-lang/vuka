# E0344: A deferred method's result passed to a component

A part is markup of the page or component whose method it waits for. A
deferred method's result passed to a child component's prop would make the
child wait for its parent's method: the child's markup isn't the parent's
to send later. Defer the method in the child, which then shows its own part.

A binding of a deferred method's result, `categories := GetCategories()`,
makes the element it is in the part: the name is used inside that element,
not after it, and not passed to a child component's prop.

Reported by the compiler. See [Parts of a Page](/web/parts).

## Wrong

```html
<script lang="go">
package pages

import (
	"context"

	"example.com/app/components"
)

type Index struct{}

@ui.Defer
func (p *Index) Stats(ctx context.Context) (int, error) { return 3, nil }
</script>

<components.Card open={Stats(ctx)}/>
```

## Right

```html
<!-- components/card.vuka.html -->
<script lang="go">
package components

import "context"

type Card struct{}

@ui.Defer
func (c *Card) Open(ctx context.Context) (int, error) { return 3, nil }
</script>

<p>{Open(ctx)} open</p>
```
