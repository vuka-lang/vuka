# E0703: Something is below a catch-all folder

A folder whose `Params` field is a `web.Rest` takes the rest of the path,
slashes included, so nothing can follow it: a subfolder, or a page other
than its `Index`, would never be reached. Reported at the subfolder or the
page.

## Wrong

```text
pages/files/file/
  params.go            type Params struct{ File web.Rest } — /files/{file...}
  index.go
  history/index.go     /files/{file...}/history: never matched
```

## Right

```text
pages/files/file/
  params.go            type Params struct{ File web.Rest }
  index.go             /files/{file...}
pages/history/file/
  params.go            type Params struct{ File web.Rest }
  index.go             /history/{file...}
```
