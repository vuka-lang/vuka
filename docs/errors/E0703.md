# E0703: A catch-all folder has more below it

A parameter folder whose `Params` field is a `web.Rest` takes the rest of the path, `{path...}`. Nothing can follow it: it has no subfolders, and no page but its `Index`.

## Wrong

```
pages/files/path/params.go     type Params struct{ Path web.Rest }
pages/files/path/raw.go        type Raw …
```

## Right

```
pages/files/path/params.go     type Params struct{ Path web.Rest }
pages/files/path/index.go      type Index …
pages/raw/path/index.go        type Index …
```
