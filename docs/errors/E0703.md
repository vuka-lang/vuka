# E0703: Something is below a catch-all folder

A `[name...]` folder takes the rest of the path, slashes included, so
nothing can follow it: a subfolder, or a page other than its `index`, would
never be reached. Reported at the subfolder or the page.

## Wrong

```text
pages/files/[file...]/
  _layout.vuka.html
  index.vuka.html          /files/{file...}
  history/index.vuka.html  /files/{file...}/history: never matched
```

## Right

```text
pages/files/[file...]/
  _layout.vuka.html
  index.vuka.html          /files/{file...}
pages/history/[file...].vuka.html   /history/{file...}
```
