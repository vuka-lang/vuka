# E0168: An Options command that cannot call its method

`ui.JS.Options(target, handler, args…)` loads a select's options from
`handler`, a method of the page or of a component on it, which the page
calls over HTTP. The compiler registers each method an Options command
names, and checks the command against it:

- the handler is a method value of a type of the package, `p.CitiesOf`: not
  a closure, a function, or another package's method;
- the method returns `[]ui.Option` or `[]ui.OptionGroup`, and maybe an
  `error`;
- a `context.Context`, when it takes one, comes first;
- the command passes one argument for each parameter that isn't a pointer
  or an interface, in order: those are the arguments, the pointers and
  interfaces the dependencies the app injects;
- each argument fits its parameter: a Go value of its type, an element's
  value (`ui.This.Value()`, a string) for a string, number or bool, a read
  of a checked state (`ui.This.Checked()`) for a bool.

See [Loading Options](/ui/js#options).

Reported by the compiler.

## Wrong

```vuka
func (p *Checkout) CitiesOf(ctx context.Context, country string, geo *Geo) ([]ui.Option, error) {
	return geo.Cities(ctx, country)
}
```

```html
<select name="country" onChange={ui.JS.Options(ui.Sel("#city"), CitiesOf)}>…</select>
```

## Right

```html
<select name="country" onChange={ui.JS.Options(ui.Sel("#city"), CitiesOf, ui.This.Value())}>…</select>
```
