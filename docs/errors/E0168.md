# E0168: A Push or Options step that cannot call its handler

`ui.JS.Push(handler, args…)` calls a handler on the server, and
`ui.JS.Options(target, handler, args…)` is its shorthand for a select's
options. The compiler registers each method a page that isn't live calls
over HTTP, and checks each step against its handler:

- for `Options` and for a read (`ui.Read()`, `ui.Cache(d)`), the handler is
  a method value of a concrete type of the package, `p.CitiesOf`: not a
  closure, a function, or another package's method;
- it returns nothing, an `error`, or one result and maybe an `error`. A
  result is `[]ui.Option`, `[]ui.OptionGroup`, a `ui.Node`, a string,
  number, bool or `time.Time`, a struct, or `ui.Commands`; `Options` takes
  the first two only;
- `.Into(target)` follows a handler that returns a result;
- `ui.Append()` and `ui.Prepend()` go in `Into`, not among the arguments;
- a `context.Context`, when it takes one, comes first;
- it isn't variadic, takes no channel or function, and takes one struct at
  most;
- the step passes one argument for each parameter that isn't a pointer or
  an interface, in order — those are the arguments, the pointers and
  interfaces the dependencies the app injects. A struct parameter may go
  without one, and takes the enclosing form's fields; a handler taking one
  value may go without one, and takes the element's value;
- each argument fits its parameter: a Go value of its type, an element's
  value (`ui.This.Value()`, text) for a string, number or bool, a read of a
  checked state (`ui.This.Checked()`) for a bool.

See [Pushing to the Server](/ui/js#push).

Reported by the compiler.

## Wrong

```vuka
func (p *Shop) Price(ctx context.Context, sku string, qty int, prices *Prices) (string, error) {
	return prices.Of(ctx, sku, qty)
}

func (p *Shop) Forget(id int64) error { return nil }
```

```html
<input name="qty" onInput={ui.JS.Push(Price, ui.This.Value(), ui.Read()).Into("#price")} />
<button onClick={ui.JS.Push(Forget, ui.Value(item.ID)).Into("#items")}>Forget</button>
```

## Right

```html
<input name="qty" onInput={ui.JS.Push(Price, item.SKU, ui.This.Value(), ui.Read()).Into("#price")} />
<button onClick={ui.JS.Push(Forget, ui.Value(item.ID))}>Forget</button>
```
