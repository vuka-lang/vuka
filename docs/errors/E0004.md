# E0004: The Vuka runtime is too old

The code vuka generates calls the runtime package `github.com/vuka-lang/vuka`.
This compiler generates calls the module's required runtime version doesn't
have, so the module needs a newer runtime. `vuka version` shows the versions
that belong together.

## Wrong

```text
// go.mod
require github.com/vuka-lang/vuka v0.20.0
```

## Right

```text
// go.mod: the runtime of the same release as the vuka command
require github.com/vuka-lang/vuka v0.32.0
```
