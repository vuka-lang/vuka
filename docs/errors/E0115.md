# E0115: Malformed enum

An `enum` declaration is `enum Name { A, B }`, optionally with an
underlying string or integer type and values (all of them or none), or with
variants holding data (`Circle{R float64}`, no underlying type). Variant
names start with a capital letter, are unique, and can't be a name every
enum generates (`Values`, `Parse…`, `String`, `Valid`).

## Wrong

```vuka
enum Status { Draft, Sent, Draft }

enum Kind float64 { A, B }
```

## Right

```vuka
enum Status { Draft, Sent, Archived }

enum Kind int { A, B }
```
