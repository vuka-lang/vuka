# E0204: Attribute without a declaration

An attribute describes the declaration that follows it. Nothing follows
this one (end of file), or what follows isn't a declaration.

## Wrong

```vuka
@doc("dangling")
```

## Right

```vuka
@doc("Lists the users")
func listUsers() []User { … }
```
