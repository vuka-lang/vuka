# W0351: A Suspense wait list names a binding it never shows

`<ui.Suspense for={stats}>` lists `stats`, but the boundary never reads it.
Bindings are lazy, so this binding does not run or delay the boundary.
Remove it from `for`, or render its value inside the boundary.

## Wrong

```html
stats := CategoryStats()
<ui.Suspense for={stats}><p>Categories</p></ui.Suspense>
```

## Right

```html
stats := CategoryStats()
<ui.Suspense for={stats}><p>{stats.Open} open</p></ui.Suspense>
```

See [Parts of a Page](/web/parts#suspense).
