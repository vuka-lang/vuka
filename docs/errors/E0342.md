# E0342: A deferred method no markup calls

A deferred method's part is the markup that calls it. A method marked
`@ui.Defer` that its struct's markup never calls has no part, so there is
nothing to send later: the attribute does nothing, which is a mistake —
a call removed from the markup, or the attribute on the wrong method.

In Go, the same holds of a method registered with `ui.Defer` that no
`ui.Part` of its type names. Reported by the compiler and by
[`vukavet`](/tools/vukavet). See [Parts of a Page](/web/parts).

## Wrong

```html
<script lang="go">
package pages

import "context"

type Index struct{}

@ui.Defer
func (p *Index) Stats(ctx context.Context) (int, error) { return 3, nil }
</script>

<h1>Applications</h1>
```

## Right

```html
<script lang="go">
package pages

import "context"

type Index struct{}

@ui.Defer
func (p *Index) Stats(ctx context.Context) (int, error) { return 3, nil }
</script>

<h1>Applications</h1>
<p>{Stats(ctx)} open</p>
```
