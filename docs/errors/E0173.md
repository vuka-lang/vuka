# E0173: A modifier an attribute cannot take

An `on…` attribute takes modifiers after its name —
`onInput.debounce.300ms`, `onKeydown.ctrl.enter`, `onSubmit.prevent`,
`onClick.stop`, `onClick.once`, `onClick.optimistic` — and `bind:value` takes `.debounce` and
`.throttle`. The compiler refuses:

- a name that is no modifier, with the closest one when it is likely
  misspelt (`.debounse`);
- a duration Go doesn't read (`.debounce.3s0`), or one with no `.debounce`
  or `.throttle` before it;
- two paces on one attribute;
- a key filter on an event that isn't a key's (`onClick.enter`), or a
  modifier key with no key after it (`onKeydown.ctrl`);
- on `bind:value`, anything but a pace;
- `.optimistic` on a handler writing no state before a push: it predicts
  the chain's state writes (`onClick.optimistic={liked = !liked; Like(id)}`);
- on a component's tag, modifiers for a prop that takes a handler (a func)
  rather than browser commands.

See [Event Modifiers](/ui/events#modifiers).

Reported by the compiler.

## Wrong

```html
<input onInput.debounse={Search(this.value)} />
<input onKeydown.ctrl={Send(this.value)} />
<input bind:value.prevent={Q} />
```

## Right

```html
<input onInput.debounce={Search(this.value)} />
<input onKeydown.ctrl.enter={Send(this.value)} />
<input bind:value.debounce.500ms={Q} />
```
