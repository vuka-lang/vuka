# E0805: A GraphQL declaration that doesn't fit

An operation is a function — not a method, not generic, in a `.vuka` file
rather than a page's script — of the shape `func Name(ctx, args…, deps…)
(T, error)`: its result a value (or a value and an error, or a
`vuka.Result[T]`), its parameters the context, arguments named by their
parameters' names and dependencies the app provides. The message says
which part doesn't fit: a method, a variadic or unnamed parameter, no
result, `@graphql.Arg` naming no parameter, two operation attributes on
one function, `@graphql.Value` on a group of constants.

## Wrong

```vuka
@graphql.Mutation
func (s *Store) AddPet(ctx context.Context, names ...string) error { … }
```

## Right

```vuka
@graphql.Mutation
func AddPet(ctx context.Context, in NewPet, store *Store) (*Pet, error) { … }
```

See [Operations](/web/graphql#operations).
