# E0805: A GraphQL declaration that doesn't fit

An operation is a function — not a method, not generic, in a `.vuka` file
rather than a page's script — of the shape `func Name(ctx, args…, deps…)
(T, error)`: its result a value (or a value and an error, or a
`vuka.Result[T]`), its parameters the context, arguments named by their
parameters' names and dependencies the app provides. The message says
which part doesn't fit: a method, a variadic or unnamed parameter, no
result, `@graphql.Arg` naming no parameter, two operation attributes on
one function, `@graphql.Value` on a group of constants.

An argument's attributes — `@graphql.AsID`, `@graphql.AsInt`,
`@graphql.AsString`, `@graphql.Arg("name")` — go before the parameter they
are about, and are about that one only: before a parameter they name none
(`@graphql.AsInt("lastID") lastID int` is an error, `@graphql.AsInt lastID
int` is right), `@graphql.Arg` takes the argument's name only, and the
parameter must be an argument, not the context, a dependency or a page.
One written both before a parameter and above the function, naming it, is
an error too: keep the one before it.

## Wrong

```vuka
@graphql.Mutation
func (s *Store) AddPet(ctx context.Context, names ...string) error { … }
```

```vuka
@graphql.Query
func Orders(ctx context.Context, @graphql.AsInt("lastID") lastID int, @graphql.AsInt store *Store) ([]Order, error) { … }
```

## Right

```vuka
@graphql.Mutation
func AddPet(ctx context.Context, in NewPet, store *Store) (*Pet, error) { … }

@graphql.Query
func Orders(ctx context.Context, @graphql.AsInt lastID int, store *Store) ([]Order, error) { … }
```

See [Operations](/web/graphql#operations).
