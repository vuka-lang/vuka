# E0718: A file is in the way of pages/route.go

vuka writes every folder route into one file, `pages/route.go`, whose
`Routes` the app passes to `web.New`. vuka 1 wrote `pages/pages_gen.go`,
registering the routes as the package loaded, and a `routes_gen.go` in
folders with template-only pages or pages without a constructor; either
on disk would register routes twice or declare what route.go builds. A
`pages/route.go` written by hand would be overwritten. Each is this error,
at the file.

## Wrong

```text
pages/pages_gen.go
pages/employers/routes_gen.go
```

## Right

```text
pages/route.go             (vuka gen -inplace writes it)
```
