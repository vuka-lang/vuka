# E0165: Variant methods that disagree

The methods of one name on a value enum's variants become one method on
the enum, so they have one signature: the same parameters and results, the
receiver aside. The default on the enum has it too. A variant declares a
method of a name once, and the enum declares one default of it.

The error names both declarations.

See [Methods on Variants](/features/enums#methods-on-variants).

Reported by the compiler.

## Wrong

```vuka
enum OrderState {
	Placed
	Paid
}

func (OrderState.Placed) Next() OrderState       { return OrderState.Paid }
func (OrderState.Paid) Next() (OrderState, bool) { return OrderState.Paid, false }
```

## Right

```vuka
enum OrderState {
	Placed
	Paid
}

func (OrderState.Placed) Next() (OrderState, bool) { return OrderState.Paid, true }
func (OrderState.Paid) Next() (OrderState, bool)   { return OrderState.Paid, false }
```
