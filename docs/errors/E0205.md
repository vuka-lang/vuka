# E0205: Bad parameter attribute

A parameter attribute is a value (a typed attribute such as `@Path("id")`
or `@Body`), written before the parameter, in a top-level function.
Declaration attributes (`@doc`) and decorators (functions) don't go on
parameters.

## Wrong

```vuka
func show(id @Path("id") int) {}

func list(@logged n int) {}
```

## Right

```vuka
func show(@Path("id") id int) {}

@logged
func list(n int) {}
```
