# E0357: An exported or bound stream

A [stream](/web/streams) is the page's own: the rows it queues are sent and
forgotten. An exported stream is a prop, which a parent sets on each render —
but a parent can't own rows the server forgets. A stream marked `@ui.Bind`
or `@ui.URL` would be the browser's or the URL's, which can't hold them
either. Keep the stream an unexported field, and bind or route a field
beside it — a filter whose `Update` resets the stream. Reported by the
compiler, `vuka vet`, the editor, and when the component mounts.

## Wrong

```go
type Feed struct {
	ui.Live
	Events ui.Stream[models.Event]
}
```

## Right

```go
type Feed struct {
	ui.Live
	events ui.Stream[models.Event]
}
```
