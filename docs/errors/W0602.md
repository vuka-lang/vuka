# W0602: A component drops its caller's attributes or classes

A component's tag takes more than the component declares: an attribute it
has no field for — `onClick`, `id`, `aria-label`, `data-*` — falls through
to its `Attrs` field, and its `Class` adds the caller's classes. Both only
work when the component passes them on: `Attrs` spread on the element its
events belong to (its root when it has none), and `Class` given last to the
class merge (`cn`, or a `ui.Variants`' `Class(…, "class", Class)`), so a
caller's `class="rounded-none"` wins over the component's own. A component
that doesn't swallows them silently: the click handler never runs, the
class never applies.

vuka's registry is checked for it as it is built, and `vuka vet` warns of
it in the app's vendored components (the `.vuka.html` files of `[ui]`'s
components directory), as they are edited.

## Wrong

```vuka
<span class={cn(Class, "inline-flex rounded-md")}>
  <button onClick={ui.On(On)} {Attrs...}>{Children}</button>
</span>
```

## Right

```vuka
<span class={cn("inline-flex rounded-md", Class)}>
  <button onClick={ui.On(On)} {Attrs...}>{Children}</button>
</span>
```

See [Components That Pass On](/ui/vendored#forwarding).
