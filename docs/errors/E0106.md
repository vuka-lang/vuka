# E0106: A component's attributes don't fit

A component tag passes attributes its function or struct doesn't take: an
unknown attribute, one of the wrong type, a missing required one, children
to a component without a `Children` field, or a type that isn't a component
at all (a component is a function returning `ui.Node`, or a stateful type
implementing `ui.Stateful`).

## Wrong

```vuka
func Badge(label string, tone string) ui.Node { … }

return <Badge lable="New" tone={3} />
```

## Right

```vuka
func Badge(label string, tone string) ui.Node { … }

return <Badge label="New" tone="info" />
```
