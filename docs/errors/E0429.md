# E0429: A web.Asset path that names no static file

`web.Asset("/static/…")` and `web.AssetURL(ctx, "/static/…")` link a file
an `app.Static` mount serves. `vuka build` and `vuka vet` check each
literal path against the mounts of embedded directories, and this path
names none of their files: a typo, a file that was moved, or a prefix no
mount has. The help names the nearest file.

A path built at run time isn't checked, and neither is one under a mount
that reads the disk at run time (`os.DirFS("uploads")`).

See [Static Files](/web/static-files).

Reported by `vuka build` and `vuka vet`.

## Wrong

```html
<img src={web.Asset("/static/images/lgo.png")} alt="Logo" />
```

## Right

```html
<img src={web.Asset("/static/images/logo.png")} alt="Logo" />
```
