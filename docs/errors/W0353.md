# W0353: A loader sets a field that isn't deferred to its group

A `@ui.Loads("group")` method runs after the page's first render, and the
page receives only the fields marked `@ui.Defer("group")` for that group. A
field the loader sets that isn't deferred to the group keeps its old value
in the page: the loader runs and returns no error, and the page renders as
if it had set nothing.

`vuka vet` warns when a `@ui.Loads` method assigns a field of its receiver
that isn't deferred to the method's group, whether it is deferred to another
group or not at all. Only assignments in the method's own body are seen; one
made by a helper it calls isn't.

## Wrong

```html
<script lang="go">
type Index struct {
	ui.Live
	ready bool   @ui.Defer("rows")
	rows  []Row
}

@ui.Loads("rows")
func (p *Index) load(ctx context.Context) error {
	p.rows, p.ready = fetch(ctx), true
	return nil
}
</script>

<ui.Suspense for={ready}>
  for _, r := range rows { <p key={r.ID}>{r.Name}</p> }
</ui.Suspense>
```

The boundary resolves and the list is empty.

## Right

```html
<script lang="go">
type Index struct {
	ui.Live
	ready bool   @ui.Defer("rows")
	rows  []Row  @ui.Defer("rows")
}
</script>
```

Or, for a value the page needs from its first render, set it in `@ui.Mount`.

See [Parts of a Page](/web/parts#suspense-live).
