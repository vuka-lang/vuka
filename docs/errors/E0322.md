# E0322: Bad bind: tag

`bind:` marks a field of a page backed by a component as one the component
sets (`live.q.set(v)`). It goes on an exported field of a JSON value (not a
function, node, JS chain or state); its name, when given, is the field's
handle (its json name, first letter lower-cased); live's own handles
(`pending`, `error`, `subscribe`) can't be bound; the one option is
`debounce=` in milliseconds or as a duration<span class="go-only"> —
in Go, the attribute `ui.Bind{Debounce: d}` in the page's `LiveSchema`</span>. Reported by `vuka vet`, the
editor, and at boot, and by
[vukavet](/tools/vukavet).

## Wrong

::: vuka
```vuka
type Orders struct {
	ui.Live
	Q      string `json:"q" bind:"query"`
	Status string `bind:"status,wait=1s"`
}
```
:::

::: go
```go
type Orders struct {
	ui.Live
	Pending bool `json:"pending"`
	refresh func()
}

func (o *Orders) LiveSchema(l *ui.LiveSchema) {
	l.Field(&o.Pending, ui.Bind{}) // live.pending is live's own
	l.Field(&o.refresh, ui.Bind{}) // not a prop: unexported, a func
}
```
:::

## Right

::: vuka
```vuka
type Orders struct {
	ui.Live
	Q      string `json:"q" bind:"q"`
	Status string `bind:"status,debounce=1s"`
}
```
:::

::: go
```go
type Orders struct {
	ui.Live
	Waiting bool `json:"waiting"`
	refresh func()
}

func (o *Orders) LiveSchema(l *ui.LiveSchema) {
	l.Field(&o.Waiting, ui.Bind{Debounce: time.Second})
}
```
:::
