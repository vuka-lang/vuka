# E0348: A fallback that stands in for no part

`<ui.Fallback for={Stats}>` is what the parts of `Stats` show until it
returns, and `<ui.Fallback for={Stats} error>` what they show if it fails.
It names a deferred method of the struct the markup renders — the method
itself, not a call — and the struct has one of each at most. It may not
call a deferred method: it shows while they run.

A misspelt name gets a suggestion. Reported by the compiler. See
[Parts of a Page](/web/parts#fallbacks).

## Wrong

```html
<p>{Stats(ctx).Open} open</p>
<ui.Fallback for={Stat}><span class="skeleton"></span></ui.Fallback>
```

## Right

```html
<p>{Stats(ctx).Open} open</p>
<ui.Fallback for={Stats}><span class="skeleton"></span></ui.Fallback>
```
