# E0159: A model or for attribute names a field the form lacks

`model={…}` on a control, `for={…}` on a label and the `for` of a form
component (`<ui.Field>`, `<ui.Error>`, `<ui.Fieldset>`) name a field of a
form by its path: `Form.Email`, `Form.Address.City`. Every step of the path
is a field of the struct before it; the compiler says which one isn't, and
the field it most likely meant.

## Wrong

```html
<script lang="go">
package pages

import (
    "example.com/app/forms"
    "github.com/vuka-lang/ui/v2"
)

// forms.Signup declares Name and Email.
type Join struct {
    ui.Live
    Form forms.Signup
}
</script>

<ui.Form for={Form}>
  <label for={Form.Emial}>Email</label>
  <input model={Form.Emial}/>
</ui.Form>
```

## Right

```html
<script lang="go">
package pages

import (
    "example.com/app/forms"
    "github.com/vuka-lang/ui/v2"
)

// forms.Signup declares Name and Email.
type Join struct {
    ui.Live
    Form forms.Signup
}
</script>

<ui.Form for={Form}>
  <label for={Form.Email}>Email</label>
  <input model={Form.Email}/>
</ui.Form>
```
