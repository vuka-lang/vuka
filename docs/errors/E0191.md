# E0191: A Call of a component that cannot be sent

`ui.JS.Call(component)` opens a component in the page's overlay host
([Opening Components](/ui/call)). The step carries the component's name
and its props, signed for the page's session, and the server builds the
component again from them when the browser opens it. So:

- the component is a value of a struct type with a `Render` method — a
  component — that isn't generic; its package is imported by name in the
  file;
- its props are values JSON carries, element reads in a prop of type
  `any`, and `ui.Action` props: a prop holding markup — a `ui.Node`, a slot
  (a func returning one, a slice of structs with them), `Children` — can't
  be sent, nor can a func that isn't a `ui.Action`, or a channel;
- what follows the component among `Call`'s arguments is `CallOption`s
  (`ui.As`, `ui.Into`, `ui.CallKey`) and a `ui.Size`;
- `.Closed(…)` follows a component's `Call`, not a `Push` or a `Call` of a
  script's function.

Reported by the compiler.

## Wrong

```html
<button onClick={ui.JS.Call(components.ProductCard{Body: <p>{p.Name}</p>})}>Preview</button>
<button onClick={ui.JS.Call(components.ProductCard{OnPick: func() { pick(p.ID) }})}>Pick</button>
```

## Right

```html
<button onClick={ui.JS.Call(components.ProductCard{ID: p.ID, Name: p.Name})}>Preview</button>
<button onClick={ui.JS.Call(components.ProductCard{ID: p.ID, OnPick: Pick})}>Pick</button>
```

with the card's `OnPick` declared `ui.Action`, and the markup it shows
written in the card itself.
