# E0170: An element read outside a method call

In an `on…` attribute, `this` is the element the event is on, and
`this.value`, `this.checked` and `this.<attr>` are reads the browser makes
when the event fires. They are sent to the server as the arguments of a
call of one of the shape's exported methods, which the event
[pushes](/ui/events#calling-a-method). Anywhere else — an argument of a
function, inside another call, a hole — no Go can read them: the markup
renders on the server, before the event.

A name a letter or two away from `value` or `checked` (`this.valeu`) is
this error too, since it is likely that read misspelt.

See [Reading the Element](/ui/events#element-reads).

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

import (
	"strings"

	"github.com/vuka-lang/ui/v2"
)

type Search struct {
	ui.Live
	q string
}

func (p *Search) Find(q string) { p.q = q }
</script>

<input onInput={Find(strings.TrimSpace(this.value))} />
<input onChange={Find(this.valeu)} />
```

## Right

```html
<script lang="go">
package pages

import (
	"strings"

	"github.com/vuka-lang/ui/v2"
)

type Search struct {
	ui.Live
	q string
}

func (p *Search) Find(q string) { p.q = strings.TrimSpace(q) }
</script>

<input onInput={Find(this.value)} />
<input onChange={Find(this.value)} />
```
