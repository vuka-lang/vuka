# E0211: Type decorator on a generic type

A type's decorator receives the type, and a generic type isn't one until
it is instantiated. Decorate an alias naming an instantiation.

## Wrong

```vuka
@reg
type Box[T any] struct{ v T }
```

## Right

```vuka
type Box[T any] struct{ v T }

@reg
type IntBox = Box[int]
```
