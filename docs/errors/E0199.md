# E0199: An event calling a markup func

A call in an `on…` attribute of one of the shape's exported methods is a
[push](/ui/events#calling-a-method) of it, made when the event fires. A
markup func is no method: its call renders markup, which an event can't
run. Render it in a hole, and give the event the method it should push.
See [Markup Funcs](/ui/templates#markup-funcs).

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Order struct {
	ID     int
	Number string
}

type Orders struct {
	ui.Live
	Open []Order
}

func (p *Orders) Approve(id int) error { return nil }
</script>

row := func(o Order) { <li>{o.Number}</li> }

<ul>
  for _, o := range Open {
    <button onClick={row(o)}>{o.Number}</button>
  }
</ul>
```

## Right

```html
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Order struct {
	ID     int
	Number string
}

type Orders struct {
	ui.Live
	Open []Order
}

func (p *Orders) Approve(id int) error { return nil }
</script>

row := func(o Order) {
  <li>{o.Number} <button onClick={Approve(o.ID)}>Approve</button></li>
}

<ul>
  for _, o := range Open {
    {row(o)}
  }
</ul>
```
