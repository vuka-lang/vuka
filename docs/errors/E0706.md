# E0706: A name vuka declares for a page is taken

vuka declares each page's URL function, `<Page>URL`, in the package's `routes_gen.go`, and for a template-only page (a `.vuka.html` file whose type isn't declared) the type and its `New<Page>` constructor too. The package declares one of those names already.

## Wrong

```go
// pages/orgs/urls.go, beside the page New
func NewURL() string { return "/orgs/new" }
```

## Right

```go
// pages/orgs/index.go
href := NewURL() // the one vuka declares
```
