# E0706: A name vuka declares for a page is taken

For each page `T` the generator writes `func <T>URL(…) string` in the
page's package. The package already declares that name — a helper, a
variable, a hand-written URL function — so the generated file wouldn't
compile. The same for a template-only page: `about.vuka.html` with no
`About` type gets one declared by vuka, so another declaration named
`About` (a function, a variable) is in the way — declare the page's type
itself, or rename the other. Reported at the existing declaration.

## Wrong

```go
package employer

func EditURL(id int) string { return fmt.Sprintf("/employers/%d/edit", id) }
```

## Right

```go
package employer

// Delete the hand-written function: vuka gen writes EditURL(employer int).
```
