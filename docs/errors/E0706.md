# E0706: A name vuka declares for a page is taken

The package `urls` gives each folder a value whose fields and methods are
named after what the folder holds: a static subfolder (`job-permits/` →
`JobPermits`), a page other than `Index` (its type's name, `New`), a
parameter subfolder (a method, `Employer(…)`), and `Path` when the folder
has an `Index`. Two of them share a name — a folder `new/` beside a page
`New`, say — so the value can't have both. The same goes for a template-only
page: `about.vuka.html` with no `About` type gets one declared by vuka, so
another declaration named `About` (a function, a variable) or `NewAbout` is
in the way. Reported at the second of the two.

## Wrong

```
pages/employers/new.go         type New …      → urls.Employers.New
pages/employers/new/draft.go   type Draft …    → urls.Employers.New.Draft
```

## Right

```
pages/employers/new.go         type New …      → urls.Employers.New
pages/employers/drafts/new.go  type New …      → urls.Employers.Drafts.New
```
