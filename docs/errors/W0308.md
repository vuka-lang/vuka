# W0308: A script names a ref, state or event its shape lacks

A shape's `<script lang="ts">` reaches its instance by name: `ctx.ref("box")`
finds the element of its markup with `ref="box"`, `ctx.state("open")` its
`ui.State` field `open`, `ctx.on("saved", fn)` the event its Go sends with
`PushEvent("saved", …)`, and `ctx.emit("picked", v)` the handler of the
`onPicked` attribute on its root. A name the shape doesn't have finds
nothing at run time: the ref is `null`, the state throws, the listener never
runs, the emit is refused. A page has no parent tag, so `ctx.emit` on a page
reaches nothing either.

The editor flags these as you type, through the types `vuka` generates
for the script; `vuka vet` reports them too, so CI catches them without an
editor. See [Component Scripts](/ui/scripts#troubleshooting).

## Wrong

```html
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Index struct {
	ui.Live
	open ui.State[bool]
}

func (p *Index) Save() { p.PushEvent("saved", nil) }
</script>

<main><input ref="search" /></main>

<script lang="ts">
import { component } from 'vuka:component'
export default component<Index>((el, props, ctx) => {
  ctx.ref('serch')?.focus()
  ctx.on('sved', () => {})
})
</script>
```

## Right

```html
<script lang="ts">
import { component } from 'vuka:component'
export default component<Index>((el, props, ctx) => {
  ctx.ref('search')?.focus()
  ctx.on('saved', () => {})
})
</script>
```
