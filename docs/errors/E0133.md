# E0133: An innerHTML value that is not a ui.RawHTML

An element's [`innerHTML={…}`](/ui/templates#raw-html) is its content,
written as is. It takes a `ui.RawHTML` and nothing else: a string, even a
quoted constant, would be markup nobody said was safe. A string a user
wrote goes through `ui.Sanitize`, which keeps formatting, links and images
and drops scripts, handlers and styles; HTML the app trusts as it is, from
its own templates or files, is converted with `ui.RawHTML(s)`, the place a
review looks for. A `ui.Node` is markup already: it goes in as a child.
A `ui.State` changes in the browser, where its value is text, so the HTML
belongs in a field the server renders.

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

type Post struct {
	Title string
	Body  string
}
</script>

<article>
  <h1>{Title}</h1>
  <div innerHTML={Body} />
</article>
```

## Right

```html
<script lang="go">
package pages

import "github.com/vuka-lang/ui/v2"

type Post struct {
	Title string
	Body  string
}
</script>

<article>
  <h1>{Title}</h1>
  <div innerHTML={ui.Sanitize(Body)} />
</article>
```

A field that holds the HTML can be typed so, sanitized once when it is
set: `Body ui.RawHTML`, then `<div innerHTML={Body} />`.
