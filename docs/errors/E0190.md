# E0190: A ui.Meta that describes no field

A member of type `ui.Meta` in a form type (a struct embedding
`ui.FormFor[T]`) describes T's field of the same name in that form: the
attributes written after it are the field's there. A `ui.Meta` whose name
is no field of T, or in a struct embedding no `ui.FormFor`, describes
nothing, and is an error.

## Wrong

```vuka
type ProductForm struct {
    ui.FormFor[Product]
    Nmae ui.Meta @ui.Spec{Placeholder: "e.g. Blue mug"}
}
```

## Right

```vuka
type ProductForm struct {
    ui.FormFor[Product]
    Name ui.Meta @ui.Spec{Placeholder: "e.g. Blue mug"}
}
```
