# E0609: The islands have no frontend build to go into

`vuka build-islands` writes the islands into the `.vuka/` directory of the
frontend's build, the root `web.Frontend` serves, so `//go:embed` picks them
up. The app calls no `web.Frontend`. A build of islands alone, with no
`index.html`, is served as one.

## Wrong

```go
//go:generate go tool vuka build-islands

func main() {
	app := web.New()
	app.Live("/", NewDashboard)
	app.Run("")
}
```

## Right

```go
//go:generate go tool vuka build-islands

//go:embed all:web/dist
var dist embed.FS

func main() {
	app := web.New(web.Frontend(dist, "web/dist"))
	app.Live("/", NewDashboard)
	app.Run("")
}
```
