# E0177: A write to a ui.Derived

A [`ui.Derived`](/ui/state#derived) field is computed by the browser
from the states its `@ui.From` reads, so nothing writes it: not an `on…`
attribute's statements, not a live component's method, not `ui.JS.Set`.
Write one of the states it reads instead, and it follows.

## Wrong

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Cart struct {
	count ui.State[int]
	price ui.State[int]
	total ui.Derived[int] @ui.From(count * price)
}
</script>

<button onClick={total = 0}>Clear</button>
```

## Right

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Cart struct {
	count ui.State[int]
	price ui.State[int]
	total ui.Derived[int] @ui.From(count * price)
}
</script>

<button onClick={count = 0}>Clear</button>
```
