# E0117: Can't infer a static's type

A static's type comes from its value. `nil`, or a value whose type depends
on statics not yet known, gives none.

## Wrong

```vuka
type Box[T any] struct {
	static cache = nil
}
```

## Right

```vuka
type Box[T any] struct {
	static cache map[string]T = nil
}
```
