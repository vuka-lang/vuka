# W0320: A form component named by its former name in ui

A form's components come from package `widget`: the controls
(`widget.Text`, `widget.Select`, …) and the rest of the form —
`widget.Field`, `widget.Error`, `widget.Summary`, `widget.Fieldset` and
`widget.Choices`. Their former names in `ui` still work, as the same
components, and vukavet notes each use.

## Wrong

```html
<form for={Form} onSubmit={save}>
  <ui.Field for={Form.Name}/>
  <ui.Error for={Form.Email}/>
  <input model={Form.Email}/>
</form>
```

## Right

```html
<form for={Form} onSubmit={save}>
  <widget.Field for={Form.Name}/>
  <widget.Error for={Form.Email}/>
  <widget.Email model={Form.Email}/>
</form>
```
