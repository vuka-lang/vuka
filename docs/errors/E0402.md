# E0402: A frontend serves a route a handler serves

`web.Frontend` serves the built pages of a frontend (Vite) on GET, and one
of them has the path of a GET route declared in Go. Reported at boot.

## Wrong

```vuka
app := web.New(web.Frontend(site, "dist"))   // the frontend has about.html

@web.Get("/about")
func About() ui.Node { … }
```

## Right

```vuka
app := web.New(web.Frontend(site, "dist"))

@web.Get("/about-us")
func About() ui.Node { … }
```
