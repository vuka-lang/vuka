# E0186: A plain form tag's for= that names no form or field

`for=` on a `<form>` names the form it renders, and on a `<fieldset>` the
field of a form it groups: both take a reference, not text. A `<form
for>` takes no attribute set (`{attrs...}`): it is a component, and its
other attributes are passed as `attrs={…}`.

## Wrong

```vuka
<form for="signup">…</form>
<fieldset for="address">…</fieldset>
```

## Right

```vuka
<form for={Form}>
  <fieldset for={Form.Address}>
    <legend/>
    <input model={Street}/>
  </fieldset>
</form>
```
