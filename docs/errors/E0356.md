# E0356: A stream's Delete given another type than its key

`Delete` takes the keys of the rows to remove: the values the rows' `key`
attribute renders, which the browser matches by their text. A value of
another type — the record's name where the key is its ID — matches no row,
and the delete does nothing. The compiler knows the key's type from the
markup and checks `Delete`'s arguments have it (an untyped constant of the
same kind is fine). Reported by the compiler, `vuka vet` and the editor.

## Wrong

```go
// the rows are <li key={m.ID}>, an int64
func (c *Chat) Unsay(m models.Message) { c.messages.Delete(m.Text) }
```

## Right

```go
func (c *Chat) Unsay(m models.Message) { c.messages.Delete(m.ID) }
```
