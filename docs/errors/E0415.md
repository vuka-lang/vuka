# E0415: An environment variable is missing or invalid

A variable the app requires (`web.Require`, `web.Env[T]`, a config struct)
isn't set, or its value isn't of its type (a number, a boolean, an absolute
URL, a list). Reported at boot.

## Wrong

```sh
# .env
PORT=eighty
```

## Right

```sh
# .env
PORT=8080
DATABASE_URL=postgres://localhost/pets
```
