# E0364: A Suspense timing that isn't a duration

A `<ui.Suspense>` of a live component takes three timings that keep a fast
load from flashing its fallback: `wait`, `delay` and `minShow`
([Parts of a Page](/web/parts#suspense-timings)). Each is a string Go's
`time.ParseDuration` reads, not negative: `"150ms"`, `"1s"`. An expression,
an unreadable string or a negative one is reported, and so is a timing on a
boundary of a page that isn't live, which has no deferred group to hold for.

Reported by the compiler.

## Wrong

```html
<ui.Suspense for={tiles} wait="soon" delay={150} minShow="-1s">
  <p>{len(tiles)} tiles</p>
</ui.Suspense>
```

## Right

```html
<ui.Suspense for={tiles} wait="200ms" delay="150ms" minShow="400ms">
  <p>{len(tiles)} tiles</p>
</ui.Suspense>
```
