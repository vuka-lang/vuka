# E0723: A name in parentheses that names no route group

A folder in parentheses under `pages/` is a route group, and its name is a
Go identifier: `(admin)`, `(site)`, `(console_v2)`. The go command sees the
group as `group_<name>`, so the name is part of an import path. A folder
whose parentheses hold anything else, `(admin-area)` or `()`, or a file
named in parentheses, `(help).vuka.html`, names no group: a group is a
folder of pages, never a page.

## Wrong

```text
pages/(admin-area)/index.vuka.html
pages/admin/(help).vuka.html
```

## Right

```text
pages/(admin_area)/index.vuka.html
pages/admin/help.vuka.html
```
