# E0134: An innerHTML where it cannot be the content

An element's [`innerHTML={…}`](/ui/templates#raw-html) is all of its
content, so the compiler reports it where it can't be:

- beside children: the element would have two contents;
- as a quoted value or with no value: it takes a `ui.RawHTML`, in braces;
- on an element that holds no markup: a void element (`<img>`, `<br>`,
  `<input>`, …), or one whose content is text (`<script>`, `<style>`,
  `<textarea>`, `<title>`, …).

## Wrong

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Comment struct {
	Author string
	Body   ui.RawHTML
}
</script>

<div innerHTML={Body}>
  <b>{Author}</b>
</div>
```

## Right

```html
<script lang="go">
package components

import "github.com/vuka-lang/ui/v2"

type Comment struct {
	Author string
	Body   ui.RawHTML
}
</script>

<div>
  <b>{Author}</b>
  <div innerHTML={Body} />
</div>
```
