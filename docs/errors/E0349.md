# E0349: A part naming another type's method

In Go, `ui.Part(p.Stats, …)` is the part of `Stats` in the markup of the
type declaring it: the page's or component's own `Render` or `View`. A
`ui.Part` in another type's markup, naming a method of a value it holds,
would send that type's part as its own. Give the type rendering it a
deferred method of its own, or render the part in its type.

Reported by [`vukavet`](/tools/vukavet). See
[Parts Written in Go](/web/parts#in-go).

## Wrong

```go
func (c *Card) View() ui.Node {
	return ui.Part(c.Page.Stats, nil, func(n int) ui.Node { return ui.Textf("%d open", n) })
}
```

## Right

```go
func init() { vuka.RegisterFunc((*Card).Open, ui.Defer("")) }

func (c *Card) Open(ctx context.Context) (int, error) { return c.Page.Stats(ctx) }

func (c *Card) View() ui.Node {
	return ui.Part(c.Open, nil, func(n int) ui.Node { return ui.Textf("%d open", n) })
}
```
