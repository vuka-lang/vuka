# E0414: Implementation[T] finds no one type

`web.Implementation[T]` asks the container for the one provided type
implementing the interface `T`. `T` isn't an interface, nothing provided
implements it, or several do.

## Wrong

```go
store, err := web.Implementation[PetStore](app)   // PetStore is a struct
```

## Right

```go
type Store interface{ Find(id int) Result[Pet] }

store, err := web.Implementation[Store](app)
```
