# E0404: A route's attribute needs what the app doesn't have

An attribute on a route (`@auth.Required`, a rate limit, a custom gate)
needs something from the app's container that nothing provides, often the
module that implements it. Reported at boot.

## Wrong

```go
@web.Get("/account")
@auth.Required
func Account(ctx context.Context) ui.Node { … }

app := web.New()
```

## Right

```go
app := web.New(auth.Module(auth.Config{…}))
```
