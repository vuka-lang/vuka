# E0708: A folder's Layout or Guard is malformed

A folder's `Layout` wraps the pages below it: a struct with a field
`Children ui.Node`, where the page (or the next layout) renders, that is
itself a `ui.Node` — a `Render` method, or a `layout.vuka.html` template. A
`Load` method, when it has one, takes `context.Context` and then what the
container provides, and returns an `error`. A folder's `Guard` checks the
routes below it and renders nothing: a struct whose `Load(ctx
context.Context, deps…) error` it must have. Reported at the type, the
field or the method.

## Wrong

```go
package employer

type Layout struct {
	Params
	Body ui.Node
}

func (l *Layout) Load(s *Store) Employer { … }
```

## Right

```go
package employer

type Layout struct {
	Params
	Children ui.Node
	employer Employer
}

func (l *Layout) Load(ctx context.Context, s *Store) error { … }

func (l Layout) Render(ctx context.Context, w io.Writer) error { … }
```
