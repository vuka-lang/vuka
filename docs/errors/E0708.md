# E0708: A Layout doesn't fit

A folder's `Layout` wraps every page in it and below. It is a struct rendering markup (a `layout.vuka.html` template or a Render method), with a field `Children ui.Node` where the page renders, and optionally a `Load(ctx context.Context, deps…) error` method run before it renders.

## Wrong

```go
type Layout struct{ Body string }
```

## Right

```go
type Layout struct {
	Children ui.Node
}
```
