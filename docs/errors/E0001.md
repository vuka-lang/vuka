# E0001: Internal compiler error

Vuka produced Go that doesn't parse, or lost track of a construct it was
rewriting. This is a bug in vuka, not in your code. Report it with the
smallest file that shows it; meanwhile, rewriting the construct the error
points at in plain Go usually gets past it.

## Wrong

```vuka
// any source: the message names the construct vuka failed on
x := f()?
```

## Right

```vuka
// the same, in plain Go, until the bug is fixed
x, err := f()
if err != nil {
	return err
}
```
