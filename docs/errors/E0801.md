# E0801: web.GraphQL has nothing to serve

`web.GraphQL("/graphql")` serves the operations the program's packages
declare with `@graphql.Query` and `@graphql.Mutation`. The app fails to
build when there is no operation to serve: no package declaring one is
linked into the program, the schema has mutations but no query (GraphQL
needs at least one), or an option given to `web.GraphQL` isn't one of
package graphql's.

## Wrong

```vuka
// main.vuka: the app mounts GraphQL, and nothing declares an operation.
func main() {
	app := web.New(web.GraphQL("/graphql", "v2"))
	log.Fatal(app.Run(""))
}
```

## Right

```vuka
// pets/pets.vuka
@graphql.Query
func Pets(ctx context.Context, first int, store *Store) ([]Pet, error) { … }

// main.vuka
func main() {
	app := web.New(web.GraphQL("/graphql", graphql.Limits{Depth: 8}))
	app.Service(pets.NewStore)
	log.Fatal(app.Run(""))
}
```

The vuka command links a package declaring operations into the program by
itself; see [GraphQL](/web/graphql#mounting).
