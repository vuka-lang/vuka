# W0502: A join read as the model's rows

`All`, `First` and `Iter` without `Values` read the queried model's rows:
one per joined row. A `Join` that can match several rows per row — a
relation holding many, or conditions that don't pick the joined model by
`ID` — gives the same category, say, once per product. Read the columns
you want with `Values`, where an aggregate groups them, or add `Distinct`.
Reported by [vukavet](/tools/vukavet).

## Wrong

```go
Category.Objects.Join(Category.Links).All(ctx)
```

## Right

```go
Category.Objects.
	Join(Category.Links, orm.Left).
	Values[CategoryLinks](Category.Name, orm.Count(ProductCategory.ID)).
	All(ctx)
```
