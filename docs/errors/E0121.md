# E0121: Ambiguous or unresolvable overload

No overload fits the arguments, or several fit equally well (an untyped
constant fits `int32` and `int64` alike), or an overloaded function is used
as a value, which names no one overload.

## Wrong

```vuka
func g(x int32) {}
func g(x int64) {}

func main() { g(1) }
```

## Right

```vuka
func g(x int32) {}
func g(x int64) {}

func main() { g(int64(1)) }
```
