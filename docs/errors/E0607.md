# E0607: vite.config doesn't use the vuka plugin

Islands built through the project's Vite need the vuka plugin, which
injects their entries and writes the manifest the app reads.

## Wrong

```ts
// vite.config.ts
export default defineConfig({ plugins: [vue()] })
```

## Right

```ts
// vite.config.ts
import vuka from './vuka/vite.js'   // vuka run and vuka build copy it here

export default defineConfig({ plugins: [vue(), vuka()] })
```
