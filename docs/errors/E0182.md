# E0182: A FormFor saved whose type is not a model

`Form.Save(ctx)` on a `ui.FormFor[T]` saves the row the form edits: it
inserts a new one and updates only the form's fields of a loaded one, so
`T` needs `Save(ctx)` and `SaveFields(ctx, fields…)` methods, as every
`orm` model has. A `FormFor` of any other struct is checked and handed to
its submit handler, which takes the checked `T` as a parameter and does
with it what it needs.

## Wrong

```vuka
type Signup struct {
    Email string @ui.Email
    Plan  string @ui.OneOf("free", "pro")
}

type SignupPage struct {
    ui.Live
    Form ui.FormFor[Signup]
}

func (p *SignupPage) submit(ctx context.Context) error {
    return p.Form.Save(ctx)
}
```

## Right

```vuka
func (p *SignupPage) submit(ctx context.Context, in Signup, users *Users) error {
    return users.Create(ctx, in)
}
```
