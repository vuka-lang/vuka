# E0100: Go statements in a markup func's body

A markup func's body is the markup it renders, not Go statements: the
compiler returns that markup for it. So the body has no `return`, and a
call standing alone on one of its lines — `log(o)`, `fmt.Println(o)` —
would render as text. What renders only sometimes goes in an `if`; a value
goes in a hole, `{label(o)}`; work belongs in an event or a method. Text
inside an element, or a sentence that only starts like Go, is markup and
never this error. See [Markup Funcs](/ui/templates#markup-funcs).

A func literal whose body really is Go statements is written where a
literal is Go: in the script, or on a prop whose type isn't a func
returning `ui.Node`.

Reported by the compiler.

## Wrong

```html
<script lang="go">
package pages

type Order struct {
	ID     int
	Number string
}

type Orders struct{ Open []Order }
</script>

row := func(o Order) {
  if o.ID == 0 { return }
  <li>{o.Number}</li>
}

<ul>
  for _, o := range Open { {row(o)} }
</ul>
```

## Right

```html
<script lang="go">
package pages

type Order struct {
	ID     int
	Number string
}

type Orders struct{ Open []Order }
</script>

row := func(o Order) {
  if o.ID != 0 {
    <li>{o.Number}</li>
  }
}

<ul>
  for _, o := range Open { {row(o)} }
</ul>
```
