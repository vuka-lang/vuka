# E0152: A template file declares no struct above its markup

A `.vuka.html` file is a struct and its markup. The struct is declared in
the file's `<script lang="go">`, with its hooks and methods, or — for a
file of markup alone — in its [script file](/ui/templates#script-file): a
`.go` or `.vuka` file beside it, named as it is (`counter.go` for
`counter.vuka.html`). This file has neither: its script declares no struct,
or it is markup alone and no file beside it is named for it.

Declare the struct in the script, or move the script out to the script
file and leave the template its markup. A script file's name is the
template's: a struct in `state.go` isn't `counter.vuka.html`'s.

## Wrong

```go
// counter_state.go
package components

type Counter struct {
	ui.Live
	n int
}

func (c *Counter) Inc() { c.n++ }
```

```html
<!-- counter.vuka.html -->
<script lang="go">
package components
</script>

<button onClick={Inc}>{n}</button>
```

## Right

```go
// counter.go
package components

import "github.com/vuka-lang/ui/v2"

type Counter struct {
	ui.Live
	n int
}

func (c *Counter) Inc() { c.n++ }
```

```html
<!-- counter.vuka.html -->
<button onClick={Inc}>{n}</button>
```
