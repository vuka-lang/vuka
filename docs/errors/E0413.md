# E0413: Bad TrustedProxies entry

`web.TrustedProxies` lists the proxies whose forwarded headers the app
believes, as CIDRs or IP addresses. Reported at boot.

## Wrong

```go
web.New(web.TrustedProxies("proxy.internal"))
```

## Right

```go
web.New(web.TrustedProxies("10.0.0.0/8", "fd00::/8"))
```
