# W0503: A method named like an ORM hook with another signature

The ORM finds a model's hooks by their methods: `Indexes`, `Checks` and
`Generated`, which declare the model's indexes, checks and generated
columns, and `BeforeCreate`, `AfterCreate`, `BeforeSave`, `AfterSave`,
`BeforeDelete`, `AfterDelete` and `Validate`, which run around its writes.
A method of a model with one of these names but another signature is not
the hook: the ORM ignores it, and the indexes it returns are never made, the
hook never runs. The signatures are the orm package's hook interfaces'
(`orm.IndexesDeclarer`, `orm.BeforeSaver`, …); the receiver, value or
pointer, doesn't matter. Reported by [vukavet](/tools/vukavet) and the
editor.

## Wrong

```go
func (User) Indexes() []orm.IndexKey {
	return []orm.IndexKey{orm.Key("email")}
}

func (u *User) BeforeSave() {
	u.Email = strings.ToLower(u.Email)
}
```

## Right

```go
func (User) Indexes() []orm.Index {
	return []orm.Index{orm.IndexOf("email").Unique()}
}

func (u *User) BeforeSave(ctx context.Context) error {
	u.Email = strings.ToLower(u.Email)
	return nil
}
```
