# E0155: Tracked state used in a .go file

A `.vuka.html` struct's unexported fields that aren't a `ui.State` or a
dependency are tracked server state. The compiler lowers what reads and
writes them — `p.rows = v`, `len(p.rows)`, `p.n++` — wherever it compiles
the code: in the shape's header and in every `.vuka` file of the package.
A `.go` file is plain Go, compiled as written, so there the field is not
its declared type and the code reading or writing it would not compile.
The error names the field, the shape file declaring it and the function
using it.

Keep the method with the shape: in a `.vuka` file beside it (the compiler
lowers it there exactly as in the header), or in the header itself. A `.go`
file can still hold everything else — services, models, helpers the
methods call with plain values.

## Wrong

```go
// rows.go
package app

func (r *Rows) load(all []string) {
	r.rows = all
}
```

## Right

```go
// rows.vuka
package app

func (r *Rows) load(all []string) {
	r.rows = all
}
```
