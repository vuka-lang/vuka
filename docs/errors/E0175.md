# E0175: An enum variant with two causes

A variant of an enum with data whose one field of type `error` is its cause
gets a generated `Unwrap() error` returning it, so `errors.Is` and
`errors.As` see through the variant. With two fields of type `error`
neither is plainly the cause: declare the variant's `Unwrap` to say which.

See [Errors with a Cause](/features/enums#errors-with-a-cause).

Reported by the compiler.

## Wrong

```vuka
enum SyncError {
	Offline
	Conflict{Local, Remote error}
}

func (SyncError.Offline) Error() string  { return "offline" }
func (SyncError.Conflict) Error() string { return "conflict" }
```

## Right

```vuka
enum SyncError {
	Offline
	Conflict{Local, Remote error}
}

func (SyncError.Offline) Error() string    { return "offline" }
func (SyncError.Conflict) Error() string   { return "conflict" }
func (e SyncError.Conflict) Unwrap() error { return e.Remote }
```
