# W0305: A hook declared outside the page's constructor

`OnMount`, `Loads` and `OnChange` on a page's `ui.Live` belong in its
constructor, a function returning the page: that is what builds every
routed instance, so the hooks are set before the first one mounts. Declared
anywhere else, a page built before that code runs has none. Reported by
[`vukavet`](/tools/vukavet).

## Wrong

```go
func setup(l *Login) {
	l.OnMount((*Login).mount)
}
```

## Right

```go
func NewLogin() *Login {
	l := &Login{}
	l.OnMount((*Login).mount)
	return l
}
```
