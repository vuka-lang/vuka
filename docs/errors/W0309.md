# W0309: A form method names no field of the form

A struct form's `Clean<Field>` method checks one field, and its
`<Field>Choices` method gives one field's options. The form finds them by
name, so one whose name doesn't spell a field — a typo, a field renamed
since — is never called: its check never runs, its options never show.
A field of a group is named by its path without the dots:
`CleanAddressCity` for `Address.City`.

## Wrong

```go
type Signup struct {
    ui.FormState
    Email string `validate:"required,email"`
}

func (f *Signup) CleanEmial(ctx context.Context, users *Users) error {
    return nil
}
```

## Right

```go
type Signup struct {
    ui.FormState
    Email string `validate:"required,email"`
}

func (f *Signup) CleanEmail(ctx context.Context, users *Users) error {
    return nil
}
```
