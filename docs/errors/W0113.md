# W0113: A pushed method assigning the fields of a page that is not live

On a page that isn't live, a [push](/ui/js#push) runs on a fresh copy of
the page over HTTP, and that copy is thrown away when the call ends. A
field the method assigns is lost: the next push starts from a new copy, and
the page in the browser never sees it.

Return what changed and put it `Into` its place, or keep the state where
the next request finds it. A page that needs fields kept between events
embeds `ui.Live`. Reported by the compiler: `vuka vet`, `vuka build` and the
editor show it.

## Wrong

```vuka
func (p *Cart) Add(ctx context.Context, sku string) error {
	p.count++
	return nil
}
```

## Right

```vuka
func (p *Cart) Add(ctx context.Context, sku string, carts *Carts) (int, error) {
	return carts.Add(ctx, sku)
}
```

```html
<button onClick={ui.JS.Push(Add, item.SKU).Into("#count")}>Add</button>
```
