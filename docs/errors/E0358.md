# E0358: A handler in a stream row isn't a push of a method

The server keeps nothing of a [stream](/web/streams)'s rows once they are
sent, so a row's handler must say which row it is for by itself. A Push of
a method of the stream's owner does: it names the method, and its
arguments — the row's key — travel in the row's markup. A closure, a plain
method value (`onClick={Remove}`), statements, or a func prop set to one,
would be a handler the session keeps for the row, for every row ever shown.
A func prop taking `ui.Commands` is fine. Reported by the compiler, `vuka
vet` and the editor, and when a row renders one.

## Wrong

```html
<li key={m.ID}>
  {m.Text}
  <button onClick={func() { Remove(m.ID) }}>Delete</button>
</li>
```

## Right

```html
<li key={m.ID}>
  {m.Text}
  <button onClick={ui.JS.Push(Remove, m.ID)}>Delete</button>
</li>
```
