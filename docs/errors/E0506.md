# E0506: A SQL fragment's template or arguments

`orm.SQLOf` and `orm.SQLFor` take a constant template: values reach the
database only as bound arguments, through `?`, so a template built with `+`,
`fmt.Sprintf` or a variable — which could carry a value into the SQL — is
refused. `{n}` writes argument n as SQL, `?` binds the next argument no
`{n}` names: the counts must match the arguments, and `{n}` must name one.
Reported by the query when it is built and by [vukavet](/tools/vukavet).

## Wrong

```go
orm.SQLOf[time.Time](fmt.Sprintf("DATE_SUB(CURDATE(), INTERVAL %d DAY)", days))
orm.SQLOf[bool]("{0} >= ? AND {0} < ?", Product.RevisedAt, since)
```

## Right

```go
orm.SQLOf[time.Time]("DATE_SUB(CURDATE(), INTERVAL ? DAY)", days)
orm.SQLOf[bool]("{0} >= ? AND {0} < ?", Product.RevisedAt, since, until)
```
