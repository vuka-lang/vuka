# E0606: Two pages share an asset scope

A page's styles are scoped by an id made from its type, and two types make
the same one.

## Wrong

```vuka
// modules/a/home.vuka and modules/b/home.vuka
@web.Live("/a", web.Style("home.css"))
type Home struct{ ui.Live }
```

## Right

```vuka
@web.Live("/a", web.Style("home.css"))
type AHome struct{ ui.Live }
```
