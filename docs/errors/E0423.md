# E0423: A context processor variable read without a context

A processor variable is read from the request being served, which a
function knows through its `ctx`. Markup always has one. A function of a
`.vuka` file, or a method in a shape's script, has one only when it takes
`ctx context.Context`; this one doesn't. Reported by the compiler.

## Wrong

```vuka
func (h *Header) greeting() string {
	return "Hello, " + user.Name
}
```

## Right

```vuka
func (h *Header) greeting(ctx context.Context) string {
	return "Hello, " + user.Name
}
```

See [context processors](/web/context-processors).
