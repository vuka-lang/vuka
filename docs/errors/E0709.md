# E0709: A page's method handler doesn't fit

A page's methods named `Post`, `Put`, `Patch` and `Delete` handle those methods on its path. `Get` is the page itself, so no method is named `Get`; a handler takes a context, the request, provided dependencies and one struct bound from the request (a scalar binds by name, and a method's parameters have none), and returns nothing, an error, a value, or a value and an error.

## Wrong

```go
func (e *Edit) Post(ctx context.Context, name string) error
```

## Right

```go
type EditForm struct{ Name string }

func (e *Edit) Post(ctx context.Context, f EditForm) error
```
