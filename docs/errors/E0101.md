# E0101: JSX syntax error

The JSX in the file doesn't parse: an element isn't closed, a closing tag
names another element, or a control-flow block (`if`, `for`, `match`) is
missing its `{ … }`.

## Wrong

```vuka
func Card(title string) ui.Node {
	return <div class="card">
		<p>{title}</div>
}
```

## Right

```vuka
func Card(title string) ui.Node {
	return <div class="card">
		<p>{title}</p>
	</div>
}
```
