# E0310: Island component not found

A bare `@ui.Island` — in Go, `ui.RegisterIsland[Type]()` or a route's
`ui.Island()` — finds its component at `islands/[<module>/]<Type>.<ext>`
under the frontend root (`.vue`, `.tsx`, `.jsx`, `.svelte`, `.ts`, `.js`);
`@ui.Island("path")` names it. No file is there. Reported by the build
(`vuka build-islands` for Go), `vuka vet` and the editor.

## Wrong

```vuka
// web/islands/ has no Chart.* file
@ui.Island
type Chart struct{ Series []float64 }
```

## Right

```vuka
// web/islands/Chart.vue exists, or:
@ui.Island("charts/Revenue.vue")
type Chart struct{ Series []float64 }
```
