# E0188: form= on a control naming a value that isn't a form

`form={Form}` on a button or a control outside a form associates it with
that form: it compiles to the form element's id. The value must be a
form (a struct embedding `ui.FormState`, or a `ui.FormFor`), or a string
holding an element's id.

## Wrong

```vuka
<button form={count}>Save</button>
```

## Right

```vuka
<form for={Form} onSubmit={save}>…</form>
<button form={Form}>Save</button>
```
