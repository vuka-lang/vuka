# W0311: A form embeds a database model

A form's exported fields are the allow-list of what a submit may set.
Embedding a database model (a struct embedding `orm.Model[T]`) makes every
column of it part of the form — an `Admin` flag, an owner's id — so a
visitor can set them by adding a field to the post. Declare the fields the
form edits, and copy them to the model in the submit handler — `Load` and
`Apply` do it by field name — or edit the model with
`ui.FormOf[models.User]("Name", "Email")`, which names the fields it edits.

## Wrong

```go
type ProfileForm struct {
    ui.FormState
    models.User
}
```

## Right

```go
type ProfileForm struct {
    ui.FormState
    Name  string `validate:"required,max=80"`
    Email string `validate:"required,email"`
}

func (p *Profile) Save(ctx context.Context, f ProfileForm, db *DB) error {
    f.Apply(&p.user) // Name and Email
    return p.user.Save(ctx, db)
}
```
