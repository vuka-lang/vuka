# W0803: A GraphQL argument's attribute above its function

`@graphql.AsID`, `@graphql.AsInt`, `@graphql.AsString` and `@graphql.Arg`
are about one argument each, and go before its parameter. Written above
the function or method, naming the parameters — the form earlier releases
had — they still work, and `vuka vet` warns: the attribute is away from
what it is about, and a renamed parameter leaves it naming nothing. The
editor's quick fix, and `vuka fix graphql-params` for the whole module,
write each one before its parameter. The schema doesn't change.

## Wrong

```vuka
@graphql.Query
@graphql.AsInt("lastID")
@graphql.Arg("after", "cursor")
func Orders(ctx context.Context, lastID int, after *string) ([]Order, error) { … }
```

## Right

```vuka
@graphql.Query
func Orders(ctx context.Context, @graphql.AsInt lastID int, @graphql.Arg("cursor") after *string) ([]Order, error) { … }
```

See [Arguments](/web/graphql#arguments).
