# Status

[[toc]]

## Introduction

This page says how mature Vuka is, how often it is released, who maintains it
and where to report a security problem.

## Maturity {#maturity}

v2.0.0 was released on 2026-10-23, and every release since is under the
[Compatibility Promise](/project/compatibility): an app that builds and passes
its tests on v2.x keeps doing so on every later v2 release.

v1 has ended. It receives no releases, security fixes included; the
compatibility page says why.

## Release Cadence {#cadence}

Between 2026-10-23 and 2026-11-18, 23 v2 releases were tagged: v2.0.0 to v2.22.0
(v2.7.0 was never released) and one patch release, v2.16.1. The
cadence the project aims for, and what each kind of release may change, is in
[Versions](/project/versions#release-cadence). Every release has
[notes](/releases).

## Maintainers {#maintainers}

Vuka is maintained by [paulmanoni](https://github.com/paulmanoni).

## Production Use {#production-use}

Vuka runs in production on several systems.

## Reporting Security Issues {#security}

See [SECURITY.md](https://github.com/vuka-lang/vuka/blob/main/SECURITY.md)
for the versions that get fixes and how to report a vulnerability privately.
